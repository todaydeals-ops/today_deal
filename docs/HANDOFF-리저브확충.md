## 2. 파이프라인 (한 사이클 = 8편)

```
주제 발굴(수요 실측 + 중복대조) → 조사 → ★출처 감사 → 집필 → ★검증 → 적재 → 택소노미 등록
```

**동시 3팀까지만.** 사장님 지시로 PC 부담을 낮게 유지한다.

### 도구
| 명령 | 용도 |
|---|---|
| `node scripts/magazine-topics.mjs --check "a,b,c"` | 주제 중복 대조. 강한 충돌이면 exit 3 |
| `node scripts/magazine-topics.mjs --gaps` | 조사만 되고 집필 안 된 주제 |
| `node scripts/magazine-srcaudit.mjs --scope=영양` | 출처 감사(배제·세탁·허용목록) |
| `node scripts/magazine-verify.mjs <원고.json>` | 분량·구조·부정묘사·em-dash·출처개수 |
| `node scripts/magazine-srccheck.mjs <원고.json>` | 원고 URL 이 facts 에 실재하는지 |
| `node scripts/magazine-draft-add.mjs <원고.json>` | 리저브 적재(is_published=false) |
| `node scripts/magazine-catcheck.mjs` | 택소노미 미등록 확인 |
| `node scripts/magazine-gap.mjs` | 카테고리별 부족분 |

검색 수요 실측(주제 발굴용):
```js
import { research } from 'C:/Users/user/.claude/fleet.mjs';
await research('눈 영양제 부작용')   // 네이버·카카오
```

### 원고 규격
본문 **2,300~3,200자**(태그 제거 후 **공백까지 전부 제거**). p 14~18 · h2 7~9 · table 1~2 · numlist 1 · dtree 1 · summary 정확히 3 · FAQ 5 · callout 160자+ · sources 3개+.
**목표를 2,400~2,500 으로 잡아라.** 2,300 에 맞추면 재작업이 난다.

`field` 값은 기존 글을 DB 에서 조회해 확인하고 쓴다(자동차는 `자동차`, AS 기기류는 `가전`·`리빙·주방`·`디지털·IT`). 이전 세션에서 이걸 추측했다가 틀렸다.

## 3. ★반드시 지킬 것 · 전부 실제로 사고가 났던 것들

### 자체 보고를 믿지 마라
이번 세션에서 **에이전트 자체 보고가 실제와 다른 경우가 8회 이상** 나왔다.
- "배제 대상 0건" 보고 → 감사 돌리니 29건
- "4편 폐기 처리 완료" 보고 → 실제로는 1편만 처리
- "글 자체 미작성" 보고 → DB 조회하니 4편 전부 발행돼 있었음
- "공식 출처 43건" 보고 → 도메인 세어보니 25건이 비공식

**결과를 받으면 항상 직접 스크립트를 돌려 확인한다.** 예외 없다.

### 출처 규율
**"그 사이트가 제품을 팔거나 시술·수리를 파는가? 팔면 배제한다."**

이번 세션에 새로 막은 것:
1. **출처 세탁** · `source` 에 "ACOG 공식 지침"이라 적고 `source_url` 은 acne.org. 기관명을 적으려면 URL 이 그 기관이어야 한다
2. **자사 사이트 순환 참조** · `todaydeals.co.kr` 을 근거로 쓴 건이 있었다
3. **문제의 해법을 파는 곳** · 엔진오일 경고등 기준을 오일 브랜드(Kixx)에서, 실내 냄새 원인을 세정제 판매사(3M)에서
4. **건강 매체·비대면진료앱·Q&A 커뮤니티** · 하이닥·닥터나우·아하
5. **제품 판매 페이지·사이트 루트** · augment 용

`공통_` 접두어는 건강 버티컬 허용목록 대상이 아니라 **DENY 로만 걸러진다.** 그래서 기기·자동차 쪽이 계속 뚫렸다. 새 도메인이 나오면 DENY 에 추가한다.

**봇에 404 를 주는 사이트**: `www.fda.gov` · `www.samsung.com` · `www.lg.com`. 루트까지 404 인 것을 확인했다. 안 열린다고 죽은 링크로 판단하면 안 된다. 삼성은 `samsungsvc.co.kr` 이 정상 응답한다.

### 부정묘사 금지
다루는 성분·제품은 **앞으로 판매하거나 광고를 유치할 대상**이다. "효과 없다 / 돈 낭비 / 과대광고" 금지. 근거가 약하면 **"무엇의 보조인가"로 위치를 잡아준다.**
근거가 부정적으로 나오는 주제는 **주제 자체를 바꾸는 게 낫다**(셀룰라이트를 폐기하고 주부습진으로 교체한 전례).

### 안전은 흐리지 않는다 (톤 예외)
상한섭취량 · 약물상호작용 · 임부 금기 · 감전 · 화재 · 화상 · 차량 경고등. **단정형 유지하되 "하지 마세요"로 끝내지 말고 대신 할 행동을 준다.**
질환을 다루면 **"진료가 기본, 보조가 영양"** 으로 착지시킨다.

### 폐기할 때
파일을 **지우지 마라.** `declined_facts[]` 에 이유와 "어디서 다시 찾아야 하는지"를 남긴다. 다음 사람이 같은 주제를 또 판다.
**편당 사용가능 팩트 4건이면 집필 가능.** 못 채우면 그 편은 빼되 기록은 남긴다. **8편을 다 채울 필요 없다.**
