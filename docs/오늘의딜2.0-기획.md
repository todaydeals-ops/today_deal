## 2. 사까마까가 네이버를 잡는 방식 7가지

1. **제목 앞머리 = 검색어 그대로.** `[검색어] 추천 2026, [판정 질문]`. 쉼표 앞이 사람들이 치는 말이고 쉼표 뒤가 클릭 이유다.
2. **커뮤니티 은어를 그대로 쓴다.** 지슈스·바브삼·데브사(마우스), 애사비(사과식초), 식세기. 구매 직전 사람은 이 말로 검색하고, 공식 명칭으로 쓴 글은 여기서 못 걸린다.
3. **영상 속 그 제품 (/youtube-pick).** "백지영 발크림" 같은 검색어는 영상이 뜬 직후 갑자기 생기고 경쟁 문서가 없다. 먼저 쓰면 1위다. 단순 소개가 아니라 **"그게 정확히 어느 회사 제품인지"**를 뚜껑 색·라벨·제조원으로 가려 준다(유사품이 여럿인 경우가 많다). 영상 타임스탬프 인용 + VideoObject 구조화 데이터.
4. **정확일치 도구 페이지를 대량으로.** 삼성·LG TV 모델명 해독기 86쪽(`KQ65QNG90AFXKR` 한 개가 한 페이지), 전기요금 kWh별 페이지. 검색어가 고유해서 경쟁이 0이다.
5. **구매결정 허브 (/buy/제품).** "식기세척기 추천 2026, 살까 말까부터 우리 집에 들어갈 한 대까지". 같은 제품 글들을 묶는 정본 페이지.
6. **시즌 수요.** 세일 달력(코리아세일페스타·빅스마일데이·십일절·쓱데이·블프 기간), 관계×나이 선물(60대 아빠 생일선물·칠순선물·상견례 선물). 해마다 같은 시기에 다시 터진다.
7. **잡음이 없는 사이트.** 모든 페이지가 공백 제외 3,500~6,200자, 구조화 데이터(Article·ItemList·FAQPage·BreadcrumbList), 날짜 박은 가격("10월 10일 쿠팡 5천 원대"). 얇은 페이지가 없다.

글 내부 틀은 우리 상담가 톤과 거의 같다. "먼저 결론부터 → 내 상황 한 줄 찾기 → 제품별 이런 분 / 근거 / 알고 쓰세요 → FAQ → 근거 자료". **톤은 이미 우리가 맞다. 다른 건 주제·제목·사이트 위생이다.**

## 3. 따라 하지 않을 것

| 사까마까가 하는 것 | 왜 안 하나 | 대신 |
|---|---|---|
| 가상 에디터 9명이 "친정엄마는 겨울만 되면…" 같은 1인칭 경험을 쓴다 | 지어낸 경험담이다. 표시광고법상 체험 위장 리스크이고 우리 원칙(날조 0)과 정면 충돌 | 편집팀 데스크 이름 + 판정 기준 공개("이렇게 고릅니다"). 경험은 출처 있는 후기만 `[후기]`로 |
| 연예인 이름을 제목에 넣고 바로 쿠팡 판매로 연결 | 부정경쟁방지법 제2조 제1호 타목(유명인 성명·초상의 무단 상업 사용, 2022 시행)에 걸릴 여지. 판례가 쌓이는 중이라 단정은 못 하지만 "광고 효과에 무임승차"로 읽히면 위험 | 영상에서 **실제로 한 말**만 인용하고 원 영상 링크·임베드. 연예인 사진 쓰지 않음. "OO 추천템"이 아니라 "OO 영상 속 그 제품, 정체와 가격"으로. 법률 검토 1회 받고 시작 |
| "이거, 안 사도 됩니다" 모음 | 우리 원칙(부정 묘사 금지, 나중에 팔 제품) | "이런 집엔 아직 이르다, 이런 집은 지금 사도 된다"로 대상을 나눠 쓴다 |

**협찬연구소와의 충돌을 반드시 정리해야 한다.** 협찬연구소는 "방송에서 소개 → 홈쇼핑에서 판매"를 기록하는 매체다. 2.0 의 "영상 속 그 제품"은 구조가 같다("영상에서 소개 → 쿠팡에서 판매"). 같은 지붕 아래 두면 협찬연구소의 신뢰가 깎인다.
→ 해법이 오히려 차별점이 된다. **영상마다 "유료광고 포함" 표시가 있었는지 적는다.** 사까마까에는 없는 정보이고, 협찬연구소의 전문성을 그대로 쓰는 것이다.

## 5. 2.0 포지션

> **오늘의딜 = 오늘 사도 되는지 알려주는 곳.**
> 살까 말까(사까마까가 하는 것) + **지금 이 값이면 사도 되나**(우리만 하는 것).

브랜드 이름 "오늘의딜"이 이 포지션과 글자 그대로 맞는다. 사까마까는 판정을 날짜로 박제하고, 우리는 판정이 매일 움직인다.

구조 (**www 하나에 전부. 10-17 중앙 집중 결정**)
- **오늘의딜(www)** = 구매 결정 미디어. 제휴 고지 상단 표기. 2.0 의 모든 신규 트랙이 여기 들어간다
- **5개 연구소** = 중립 근거 매체. 제휴 없음 원칙 유지. 광고주 랜딩 + 성과 보고서 사업도 그대로
- 구매글은 연구소 글을 근거로 링크하고, 연구소 글은 구매글로 링크하지 않는다(중립성 보호)

## 6. 트랙 4개

### T1. 영상 속 그 제품 (사까마까 /youtube-pick 대응)
- **감시**: 연예인·살림·리뷰 채널 목록(안나픽·누구템·제로비·송미니·자유부인 한가인 등에서 시작) + kontents-index 화제성 상위 인물
- **흐름**: YouTube Data API(무료 쿼터) 신규 영상 → 자막·설명란 → 제품 언급 추출(Haiku) → 쿠팡·네이버 쇼핑 검색으로 제품 특정 → 유사품 구분 → 집필(Sonnet) → 발행
- **속도가 전부다.** 영상 공개 후 48시간 안. 검색어가 새로 생기는 순간 먼저 있는 문서가 1위다
- **우리 추가분**: 유료광고 포함 표시 여부 / 지금 가격 판정 / 유사품 구분표
- 하루 3~5편

### T2. 구매결정 허브 + 실시간 판정
- `/buy/<제품>` 정본 페이지. 제목 공식 `[제품] 추천 2026, [판정 질문]`
- 각 허브에 **가격 판정 엔진 결과를 붙인다**("오늘 나비엔 EQM352 23만 원대, 네이버 최저 대비 추천")
- 연구소 기존 글을 근거로 묶는다(재작성 없이 링크)
- 1차 30개: 계절 순서. 겨울 가전(온수매트·전기요 · 가습기 · 히터 · 제습기) → 상시 고관여(식기세척기 · 로봇청소기 · 건조기 · 공기청정기 · 매트리스)

### T3. 정확일치 페이지 (모델명·에러코드)
- **에러코드 사전**: 브랜드 × 제품 × 코드 한 개 = 한 페이지("삼성 세탁기 4C", "LG 세탁기 UE", 보일러 에러코드). AS연구소 팩트에서 생성, 해당 AS 글로 연결
- **모델명 해독기**: TV·냉장고·세탁기·에어컨 모델코드 → 연식·등급·크기. 사까마까는 TV 위주로 86쪽이고 다른 가전은 비어 있다
- 템플릿 + 데이터 테이블로 만든다. 글 집필 비용이 거의 없다
- ★얇은 페이지 대량 생산이 되면 2번에서 본 "게시판 4,914건 효과"를 우리가 다시 만든다. **페이지마다 고유 정보가 5개 이상** 없으면 만들지 않는다

### T4. 시즌 달력 + 선물
- **세일 달력**: 빅스마일데이·십일절·쓱데이·코리아세일페스타·블프·크리스마스. 날짜 + 출처 + **그날 실제 딜(타임딜 수집기)**
- **선물 가이드**: 관계 × 나이 × 예산(60대 아빠 생일선물, 칠순, 상견례, 수능, 빼빼로데이, 크리스마스)
- ★11월 세일이 2주 뒤다. 색인 시간을 감안하면 **이번 주에 나가야 한다**

## 7. 0단계 · 네이버 수집부터 살린다 (모든 트랙의 전제)

2.0 콘텐츠를 아무리 써도 네이버가 안 가져가면 0이다. 지금이 그 상태다.

- **사이트 색인 수**: 도메인명 자체로 검색한 `total`
