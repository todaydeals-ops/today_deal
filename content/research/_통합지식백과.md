# ★ 통합 지식백과

이 폴더의 팩트는 **D:\지식백과** 에 통합돼 있다.
전 매거진(도시전설 · 닥스노트 · 오늘의딜 · 공공정보알리미 · 포천 · 미디어하우스 6개)이 같은 저장소를 쓴다.

## 조사 전에 반드시

**새로 조사하기 전에 통합 백과를 먼저 검색한다.** 다른 프로젝트가 이미 조사해둔 것이 있다.

```
cd C:\Users\user\Desktop\클로드코드_개발\trendfeed\mediahouse

node build/kb.mjs find <찾을 말>      동의어까지 확장해 검색
node build/kb.mjs topics <주제>       관련 주제 목록
node build/kb.mjs check               품질 점검
node build/kb.mjs stats               현황
```

"잠 안 올 때" 처럼 자연스러운 말로 찾아도 된다. 동의어가 붙어 있다 — 잠 → 수면, 눈밑 → 다크서클.

## 왜

전역 원칙 §1 — **한 번 조사한 사실은 다시 조사하지 않는다. 그리고 글끼리 어긋나지 않게 한다.**

진짜 값은 조사 시간 절감이 아니라 **모순 방지**다.
같은 팩트를 참조했다는 기록이 남으므로 매체 간 수치가 어긋나지 않는다.
발췌하면 경고도 같이 나온다 — "인도 표본이라 한국인 데이터 아님", "상관관계지 인과 아님" 같은 것.

## 이 폴더는 원본이다

**지우지 않는다.** 통합본은 복사본이고 여기가 원본이다.
새 팩트는 여기에 만들고, 아래로 통합본을 갱신한다.

```
node build/kb-merge.mjs      원본 → D:\지식백과 복사
node build/kb-build.mjs      색인 재구축
```
