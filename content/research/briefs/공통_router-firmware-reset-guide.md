# 공유기 펌웨어 업그레이드·초기화·설정 백업 가이드

## 조사 목표
공유기 펌웨어 업그레이드와 공장 초기화의 안전성·준비 과정·복구 방법 정리

## 조사 결과

### 펌웨어 업그레이드 주의사항
1. **업그레이드 후 초기화 위험**: 일부 설정이 초기화될 수 있음
2. **백업 필수**: 업그레이드 전 설정 파일 백업 필요
3. **연결 방식**: PC를 랜선으로 직접 연결하여 진행
4. **전원 안정성**: 업그레이드 중 전원 차단 시 벽돌화 위험

### 공장 초기화 전 체크리스트
1. 전원 재부팅 먼저 시도
2. 랜선 연결 확인
3. 통신사 임대 공유기 → 고객센터 문의 필수
4. 관리자 정보(주소, 아이디, 비밀번호) 미리 기록
5. 설정 백업 (SSID, 비밀번호, IP, DHCP, 포트 포워딩 등)

## 백업에 포함되는 항목
- SSID(네트워크 이름), 와이파이 비밀번호
- 내부 IP 대역, DHCP 예약
- 포트 포워딩, DDNS, 게스트 네트워크 등

## 소스
- 공유기 펌웨어 업그레이드 안전 가이드
- 공유기 초기화 체크리스트

## 주의점
- 통신사 공유기는 IPTV 설정에도 영향을 줄 수 있음
- 벽돌화 발생 시 제조사 복구 모드 필요
