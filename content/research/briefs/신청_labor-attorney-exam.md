# 공인노무사 시험 — 신청 브리프 (2026-10-27 조사)

- 힌트 점검(candidates.txt 4|a|시험·자격|labor-attorney-exam): 표제어·검색어 맞음. 시행기관은 **힌트 정정 있음**.

## ★출처부족 (보강 권장)
- 법령 1건(공인노무사법) + 큐넷 시험일정 페이지 1건. **개별 공고문(시행계획)은 확보하지 못했다.**
- 게이트 기준으로는 개수 2곳이 채워지지만, 큐넷 시험일정 페이지는 표 형식 메뉴 페이지라 약한 근거다. 집필 전 2026년 35회 시행계획 공고문(큐넷 공고 게시판) 확보를 권장한다.

## ★힌트 정정
- 힌트: "시행기관 Q-Net". 원문 기준으로 정정이 필요하다.
  - **법적 실시 주체: 고용노동부장관**(공인노무사법 제3조의2 제1항).
  - **관리 업무 위탁: 한국산업인력공단**(제26조 제2항 "위탁할 수 있다"). 큐넷은 공단이 운영하는 접수·일정 사이트다.
- 글에는 "고용노동부가 시행하고 한국산업인력공단(큐넷)이 접수·관리한다"로 쓸 것.

## 현행 여부
- 공인노무사법 본문은 `[시행 2022.12.11] [법률 제18923호]` 표기. 2026-10-27 기준 현행으로 본다.
- 2026년 회차 = **제35회**(힌트에는 회차 번호 없음). 제33회는 2024년 시험이라 혼동 주의.
- 2026년 35회 1·2·3차 일정이 큐넷 표에 있다. **3차시험(11.27)은 시험 전이지만 접수는 마감**됐다.

## 확인 못 한 것 (글에 쓰지 말 것)
- 2026 35회 **시행계획 공고 본문**(접수 방법·응시자격·응시료·과목)은 미열람.
- 제36회(2027년) 1차 일정: 큐넷 일정표에 없음 → `labor-attorney-exam-2027-36-not-found`(확인실패). "미공고 확정"이 아니다.
- 검색 결과에 있던 인터넷 공공입찰 게시물(land-it.co.kr, 사전공고 PDF)은 공식 출처가 아니므로 쓰지 않았다.
- 검색 결과에 있던 "2026 제35회 1차 접수 3.30~4.3" 같은 블로그 표기는 큐넷 표로 교차 확인했다.

### 열어서 본 개별 공식 문서 (이번 세션에서 직접 열람)
1. `https://q-net.or.kr/crf002.do?id=crf00201&gSite=L&gId=05` — Q-Net **시행공고** 목록. 공고 제2026-103호 「2026년도 제35회 공인노무사 국가자격시험 시행계획 공고(수정)」가 인라인으로 뜨며, 발행 2026년 6월 23일 한국산업인력공단 이사장.
2. 같은 페이지 「시행공고 다운로드」 버튼 → 첨부 PDF(27쪽, 공고 본문 전체). 이 PDF가 응시료·시행지역·과목·응시자격의 근거다. PDF 텍스트는 PyMuPDF로 추출(pdftotext는 한글 깨짐).
3. `https://q-net.or.kr/crf005.do?id=crf00503&gSite=L&gId=05&gbnn=gbnSubtab1` — Q-Net 자격상세정보. 응시자격(차수별), 시험과목 및 방법, 응시수수료 탭을 클릭해 확인.
4. `https://www.law.go.kr/법령/공인노무사법` — 기존 팩트 그대로(실시 주체·위탁 근거).

### 이번에 확인한 사실(확실·공식)
- 응시수수료: 1차 40,000원 · 2·3차 55,000원(공고 전 30,000·45,000원에서 각 10,000원 인상). 자격상세 탭과 공고 PDF 양쪽 일치.
- 응시자격: 결격사유(공인노무사법 제4조) 없는 자. 2차는 당해년도 또는 전년도 1차 합격자, 3차는 당해년도 또는 전년도 2차 합격자. 결격사유 심사기준일은 3차 합격자 발표일 2026.12.9.
- 1차 과목: 필수 5(노동법1·노동법2·민법·사회보험법·영어 대체) + 선택 1(경제학원론·경영학개론 택1), 과목당 100점.
- 2차 과목: 노동법·인사노무관리론·행정쟁송법 + 선택 1(경영조직론·노동경제학·민사소송법). 3차는 면접.
- 1차 시행지역 6곳(서울·부산·대구·인천·광주·대전), 수험자 직접 선택. 3차는 서울.
- 2차·3차 접수 마감이 7.17에서 **7.20**으로 조정됐다(제헌절 공휴일, 민법 제161조). 기존 팩트의 7.20은 이 수정 공고 기준이다.

### 36회(2027) 일정
