# 아이 영양제, 정말 먹여야 할까?

## 조사 개요
소아(1-18세) 면역력 영양제의 근거, 연령별 권장량·상한섭취량, 안전성 기준 조사.

**출처 등급**: 1차 권위(한국 KDRI 2020, NIH ODS, 소아과 임상 지침), 2차 Cochrane

---

## 핵심 팩트

### 1. 건강한 아이의 종합비타민: 근거 없음

#### 임상 현실
- **Cochrane 메타분석**: 영양 결핍이 없는 건강한 아이의 감염 예방 효과 불입증
- **결론**: 일반적 면역력 증진 목적의 무분별한 보충 비권장

#### 통상의 오류
- "비타민 C 먹으면 감기 안 걸린다" → **거짓**
- "종합비타민은 예방"→ **근거 약함**
- "아이 성장에 필수" → **균형잡힌 식사면 충분**

#### 실무안
- **필수 검사 없이 보충 X**
- 결핍 진단 후에만 투여

---

### 2. 진짜 필요한 경우: 특정 결핍

### 비타민D 결핍
- **흔한 이유**: 햇빛 노출 부족, 음식 섭취 적음
- **진단**: 혈중 25-hydroxyvitamin D <30 ng/mL
- **증상**: 약한 뼈, 구루병(심한 경우)
- **검사 필수** (무분별한 보충 금지)

### 아연 결핍
- **흔한 이유**: 육류·견과류 섭취 부족
- **증상**: 감염 빈번, 상처 회복 지연, 탈모
- **검사 필수** (혈청 아연)

### 철분 결핍성 빈혈
- **흔한 대상**: 1세 이후 우유 과다 섭취 아이
- **발생 기전**: 우유는 철분 거의 없고, 칼슘이 철분 흡수 방해
- **진단**: 혈중 헤모글로빈, 페리틴 검사
- **치료**: 철분제 + 유제품과 시간 분리

---

### 3. 연령별 권장량 및 상한섭취량

#### 비타민D (1-18세)

| 연령 | 권장 섭취량 | 상한섭취량 |
|---|---|---|
| 1-3세 | 600 IU(15μg) | 3,000 IU(75μg) |
| 4-8세 | 600 IU(15μg) | 3,000 IU(75μg) |
| 9-18세 | 600 IU(15μg) | 4,000 IU(100μg) |

**주의**:
- ★4세 이하 과다 섭취 위험(고칼슘혈증, 신장 손상)
- 겨울/실내활동 많은 아이만 보충 고려

#### 아연 (1-18세)

| 연령 | 권장 섭취량 | 상한섭취량 |
|---|---|---|
| 1-3세 | 3mg | 7mg |
| 4-8세 | 5mg | 12mg |
| 9-13세 | 8mg | 23mg |
| 14-18세 | 9-11mg | 34mg |

**주의**:
- ★상한 초과 시 구리 결핍(신경 손상)
- 로젠지는 감기 초기 용도(예방 X)

#### 철분 (1-18세)

| 연령 | 권장 섭취량 | 상한섭취량 |
|---|---|---|
| 1-3세 | 7mg | 40mg |
| 4-8세 | 10mg | 40mg |
| 9-13세(여) | 8mg | 45mg |
| 9-13세(남) | 8mg | 45mg |
| 14-18세(여) | 15mg | 45mg |
| 14-18세(남) | 11mg | 45mg |

**주의**:
- ★우유 1L/일 이상 마시는 아이는 철분 결핍 위험
- 철분제와 유제품은 최소 2시간 간격 필수

---

### 4. 아이 영양제 안전성: 축적 독성

#### 지용성 비타민(A, D, E, K) 위험

- **축적 메커니즘**: 간과 지방 조직에 저장됨 → 과다 섭취 시 독성
- **특히 위험한 연령**: 4세 이하
- **증상**: 두통, 피부 건조, 뼈 통증, 심한 경우 신경 손상

#### 권고
- **절대 금지**: 일반인용 "부스트" 고함량 제품
- **안전한 선택**: 의료진 처방 소아용 표준 용량
- **병력 확인 필수**: 혈중 비타민 수치가 정상인지 확인 후

---

### 5. 실제 효과: 결핍이 없으면 0

#### 임상 경험

| 상황 | 기대 효과 | 현실 |
|---|---|---|
| 영양 충분한 건강 아이 + 종합비타민 | 감기 예방 | 효과 없음 |
| 비타민D 결핍 아이 + 보충 | 뼈 건강 회복 | 효과 있음 |
| 아연 결핍 아이 + 아연 | 감염 감소 | 효과 있음 |
| 철분 결핍 아이 + 철분 | 피로 회복 | 효과 있음 |

---

### 6. 식이로 충분한 경우

#### 비타민D
- **음식원**:
  - 기름진 생선(연어, 고등어): 1회 150g = 약 500-1,000 IU
  - 계란 노른자: 1개 = 약 20 IU
  - 우유(강화 제품): 200ml = 약 100-200 IU
- **햇빛**: 정오 15-20분 야외활동 = 약 500 IU

#### 아연
- **음식원**:
  - 굴: 100g = 약 17mg
  - 소고기: 100g = 약 5-7mg
  - 치즈: 30g = 약 1-2mg
  - 견과류: 한 줌 = 약 1-2mg

#### 철분
- **음식원** (육류 철분은 흡수율 높음):
  - 소고기 적색육: 100g = 약 2-3mg
  - 굴: 100g = 약 5-7mg
  - 두부: 150g = 약 1-2mg

## 실무 의사결정 트리

```
아이 영양제 필요한가?

├─ 정기 검진에서 성장·발달 정상
│  └─ 혈액 검사 정상 (헤모글로빈, 비타민D, 아연)
│     └─ 식이 다양하고 충분
│        └─ 결론: 보충 불필요 ✓
│
├─ 편식 심함 또는 식이 제한(채식·불소화)
│  └─ 정기 검진·혈액 검사 실시
│     ├─ 결핍 확인 안 됨
│     │  └─ 식이 개선 시도(3개월)
│     │     └─ 다시 재검사
│     └─ 결핍 확인됨
│        └─ 의료진 처방 용량 + 식이 개선
│
└─ 특정 질환·불내증(선천성 소화 불량 등)
   └─ 의료진 처방 필수
```

## 부모가 피해야 할 오류

### 오류 1: 검사 없이 "예방적" 보충
- "만약 모자라면 어쩌지" 심리로 고함량 제품 투여
- 결과: 축적 독성 위험

### 오류 2: 광고에 흔들림
- "면역 강화", "성장 부스터" 마케팅 신뢰
- 현실: Cochrane은 증거 없음

### 오류 3: 종합비타민이 보험 같다고 생각
- "먹으면 해로울 것 없겠지" 오류
- 현실: 상한 초과 가능성 높음

### 오류 4: 미네랄 상호작용 무시
- 철분 + 유제품 동시 투여
- 칼슘 + 철분 동시 투여
- 결과: 흡수 방해, 효과 반감

## 권장 실무 프로세스

### 1단계: 의료진 평가
- 성장곡선 정상 여부
- 식이 다양성 평가
- 증상(피로, 감염 빈도) 확인

### 2단계: 필요한 검사만
- 비타민D (겨울/실내 많은 아이)
- 혈중 아연 (감염 빈번, 탈모)
- 혈중 철분 (우유 과다, 편식)
- **검사 생략 시 보충 금지**

### 3단계: 결핍 확인 후 처방
- 의료진 권고 용량만 사용
- 의료진 상한 교육
- 3-6개월 후 재평가

### 4단계: 병행 식이 개선
- 영양제는 보조, 주 치료 아님
- 음식 다양화 필수

## 확인 실패한 항목

- 건강한 아이의 특정 비타민 조합(예: D+아연) 상승 효과 → 근거 미확보
