# 내 신용정보 무료 조회 — 조사 전문 (2026-10-27)

## 범위
`credit-report-free`. 개인 신용정보 무료 열람 경로, 신용정보법상 열람 청구권, 신용조회 사실 통지 요청, 그리고 "연 3회 무료" 주장의 근거 확인.

## 열어서 확인한 1차 출처
- 한국신용정보원 본인신용정보 열람서비스 메인 (credit4u.or.kr, 렌더링 열람) — "무료 조회서비스", 본인인증 후 조회, 상담 1544-6640·1544-1040. 조회 횟수 문구 없음.
- 국가법령정보센터 신용정보의 이용 및 보호에 관한 법률 제38조 — 제1항 교부·열람 청구권(본인확인 후), 제2항 정정청구. 무료·횟수 조항 없음.
- 국가법령정보센터 신용정보법 제38조의2 — 제1항 신용조회사실 통지 요청(개인신용평가회사·개인사업자신용평가회사 대상), 제2항 명의도용 의심 조회 시 제공 중지·통지.
- 아시아경제 2020-10-04 기사 (WebFetch 열람) — "연 3회 무료" 보도. **기사 자체에 법적 근거·시행일 없음.**

## 검색
- 연 3회 무료 근거 검색 — 2020 기사 외 확인 없음.
- 시행령 조문 검색(law.go.kr 검색 페이지) — JS 검색 결과가 열리지 않아 실패.
- 금융위 보도자료 검색 2회 — 횟수 관련 보도자료 찾지 못함(2013 신용조회 등급 통보 보도자료만 확인, 무관).

## 확인 실패
- **연 3회 무료 조회 횟수** — 법령 본문·시행령(미확인)·금융위·신용정보원 페이지 어디서도 확인 못 함. `credit-free-3-per-year-unverified`로 확인실패 기록. 글에 숫자로 쓰지 말 것.
- 열람 수수료 면제 여부 — 미확인.
- 본인인증 수단(휴대폰·인증서 등)의 현행 목록 — 페이지 본문 확인 못 함.
- 상업 신용평가사 유료 조회서(나이스지키미·KCB 등) 가격 — 검색 스니펫 수준이라 팩트화하지 않음.

## 현행 여부
- 법 제38조·제38조의2 원문은 열람 시점 현행 표기(개정 2020.2.4 등). 신용정보원 메인 페이지는 2026-10-27 열람 시 정상 운영 중.

## 집필 시 주의 (2줄)
1. "무료 조회"는 쓰되 "연 몇 회 무료"는 쓰지 말고, 횟수는 "각 기관 안내를 확인하라"로 넘긴다.
2. 신용정보 조회 사실 통지 요청은 신용평가사 대상이다. 신용정보회사 전체에 적용되는 것처럼 쓰지 말 것.
