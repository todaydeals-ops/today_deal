## 확인 못 한 것 (확인실패로 남김)

1. **근거 조문(지방세법 제116조·제118조 등)**: 법령 페이지에서 본문을 얻지 못함. → `property-tax-statutory-article` 확인실패. 글에서 조문 번호를 쓰지 말 것.
2. **분할납부 신청 기간(납기 당월 16~25일)**: 블로그·검색 발췌에만 있음. → `property-tax-split-application-window` 확인실패.
3. **분할 나머지 납부 기한(납기 다음날부터 3개월 이내)**: 블로그만. 110 답변에는 없음. → `property-tax-split-payment-deadline` 확인실패.
4. **위택스 일부납부 기능의 재산세 제외**: 검색 발췌만. → `property-tax-ilbu-exclusion` 확인실패.
5. **과세기준일(매년 6월 1일 현재 소유자)**: 블로그만. 지방세법 본문 미확인. → `property-tax-taxable-date` 확인실패.
6. **가산금율·추가 가산 주기**: 블로그만. → `property-tax-late-surcharge` 확인실패. 숫자 금지.
7. **2027년 납기 일정**: 위택스 일정 페이지에 연도 표기가 없어 2027년 확정 일정 확인 못 함. → `property-tax-2027-schedule-unknown` 확인실패.
8. **위택스 조회·납부 메뉴 경로**: 위택스 메인 페이지 본문을 열지 않음. 검색 결과 URL도 열지 않았으므로 메뉴 경로는 글에 쓰지 말 것.
9. **분할납부 신청의 온라인 경로(위택스·정부24)**: 110 답변에 신청 경로 문구 없음. 확인 못 함.

## 충돌 및 주의

- 블로그 "재산세 분할은 본세 250만 원 초과" → 110 답변과 일치. 다만 110 답변은 2024-12-17 작성분. 지자체별 기준 차이 가능성을 caution에 명시.
- 세종시 자료의 "250만 원 초과 500만 원 이하는 250만 원까지 1차, 500만 원 초과는 50%" 방식은 2023년 자료·지자체 기준이라 채택하지 않음.
- 2026년 7월·9월 납기는 이미 지났다(2026-10-26 기준). 글에서 "지금 납부하라"는 식으로 쓰지 말 것.
- 7월 16~31일, 9월 16~30일은 2026년 기준 주말이 끼지 않는다(달력 계산: 7/31 금, 9/30 수).

## 글 쓸 때 주의

- "주택분은 연간 세액의 절반씩 7월과 9월에 나눠 낸다"는 구조는 위택스 일정 안내 기준이다. 세액 계산 공식과 특례(세액이 적은 경우 등)는 쓰지 말 것.
- 분할 기준 250만 원은 2024년 110 답변 기준이다. "관할 지자체 확인"을 함께 안내한다.
