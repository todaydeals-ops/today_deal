# 아르기닌·시트룰린 조사 전문

## 조사 목표
- 아르기닌 vs 시트룰린의 약동학적 차이와 혈중 아르기닌 농도 상승
- NO(일산화질소) 생성 경로와 혈관내피 기능 개선 근거
- 운동수행력에 대한 임상 효과

## 핵심 발견사항

### 1. 약동학적 우월성: 시트룰린 > 아르기닌

**경구 투여 후 혈중 아르기닌 농도**
- **L-시트룰린**: 간 대사를 거치지 않고 신장으로 수송 → 새로운 아르기닌 합성(de novo synthesis)
- **L-아르기닌**: 소장 벽과 간에서 아르기나제에 의해 광범위하게 대사 → 혈중 도달량 감소

결론: **시트룰린이 아르기닌보다 혈중 아르기닌을 더 효과적으로 올린다.**

**임상 수치 (시트룰린 3g 1일 2회)**
- L-아르기닌/ADMA 비율: 186±8 (기초) → 278±14 (투여 후)

**시트룰린-말레이트(citrulline malate)**: 순수 L-시트룰린과의 직접 비교 연구가 부족하나, 추가 효과를 주장하는 제품이 많다.

### 2. NO 생성 경로와 혈관 기능

**기전**
- 아르기닌/시트룰린 → 산화질소 합성효소(eNOS) → 일산화질소(NO) 생성
- NO → 혈관 확장, 혈류 개선, 혈압 조절

**임상 근거**
- 2024년 연구: L-시트룰린 보충은 고혈압 폐경기 여성의 다리 혈관 내피 기능 개선, 운동 중 혈류 반응 증가
- 안정시 대혈관 기능 개선이 관찰됨

**제약**: 임상 효과의 규모와 지속 기간에 대한 대규모 연구 필요

### 3. 운동수행력: 메타분석 결과와 비판

**메타분석 결과 (15개 RCT, 2020)**
- 유산소 성능 개선: 효과크기 0.84
- 무산소 성능 개선: 효과크기 0.24
- 운동 양식(유산소 vs 무산소)에 따라 효과 다름

**최근 비판 (2024~2025)**
- 이전 메타분석에 방법론적 오류 지적: 데이터 선택적 분석, 다중 비교 문제
- 2025년 새로운 연구: 아르기닌+시트룰린 급성 투여는 고강도 반복 운동 중 NO(NOx) 증가, 심폐 지표, 인지된 운동 강도 개선 보고
  - 표본: 대학 축구 선수, 무작위 이중맹검 병렬 설계
  - 주의: 젊은 훈련 선수 특정, 급성 효과만 측정

### 4. PGC-1α 경로: 근력과 피로 저항성

**발견**
- L-시트룰린 보충 → 골격근 PGC-1α 발현 상향조절
- PGC-1α ↑ → 미토콘드리아 생성, 산화 능력 증가 → 근력·피로 저항성 개선

**임상 결과**
- 피로까지의 시간(time to exhaustion) 개선
- 근육 무게 증가 경향

**제약**: 동물 모델 기초 연구 포함, 인체 임상 효과 규모는 추가 확인 필요

### 5. 용량 및 부작용

**권장 용량**
- **아르기닌**: 운동 60~90분 전, 체중 kg당 0.15g (예: 70kg 체중 → 10.5g)
- **시트룰린**: 3~6g/일 범위 (연구 프로토콜 기준)

**부작용**
- 고용량 아르기닌(6g 이상): 소화기 부작용(복통, 설사)
- 혈압 저하 경향 → 저혈압 환자 주의
- 신질환·저혈압·헤르페스 바이러스 감염 병력 있으면 의료 전문가 상담 필수

## 집필 기준

### DO
✓ 시트룰린의 약동학적 우월성 명확히 할 것
✓ 운동 성능 효과는 "연구 결과 혼합"으로 표기
✓ NO 생성 메커니즘 설명 후 혈관 건강 맥락 제시
✓ 용량과 타이밍의 중요성 강조

### DON'T
✗ "반드시 근력을 높인다" 같은 절대 표현
✗ 시트룰린-말레이트의 추가 효과를 입증된 사실로 표현
✗ 고용량이 더 효과적이라고 가정
✗ 임상 환자군에 적용 가능성을 일반화
