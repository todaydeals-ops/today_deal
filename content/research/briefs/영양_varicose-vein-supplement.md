# 하지정맥류 영양제: 증상은 개선되지만 근본은 아니다

## 핵심 질문
정맥류가 있을 때 디오스민이나 말밤종자 영양제로 치료할 수 있을까?

## 주요 발견

### 1. 정맥류의 근본 원인은 판막 손상

**질환 기전**
- 다리 정맥의 판막(valve)이 손상
- 판막 역류 방지 기능 상실
- 혈액이 역류하면서 정맥 팽창·구불거림

**핵심**: 손상된 판막은 약이나 영양제로 복구되지 않음
→ 영양제는 **증상 완화에만** 도움 (치료 아님)

### 2. 디오스민 (Diosmin)

#### 임상 근거

**대규모 국제 임상** (23개국, 5,052명, 6개월)
- 투여: 디오스민 450mg + 헤스페리딘 50mg
- 결과: 다리 부종·통증·피로 지속적 개선, 삶의 질 향상

**증상 개선 시간표** (389명)
- 4주: 다리 통증 30% 이상 감소
- 12주: 다리 통증 85.4% 감소

#### 작용 기전
- 항염증 작용
- 부종 감소
- 정맥 긴장도 개선

#### 한계
- **근본 치료 아님**: 손상된 판막 복구 불가
- **치료 목표**: 증상 완화만 가능
- **장기 효과**: 6개월 이상 추적 데이터 부족
- **진행**: 정맥류 자체는 시간에 따라 진행될 수 있음

### 3. 말밤종자추출물 (Aesculus hippocastanum)

#### 임상 근거

**Cochrane 체계적 문헌고찰**
- 모든 위약대조 임상에서 증상 개선 확인
- 효과: 압박 치료(compression therapy)와 유사

**증상 개선**
- 다리 부종 감소
- 통증·피로 완화
- 다리 둘레(ankle/calf circumference) 감소

**특별 가치: 정맥 궤양(venous leg ulcer) 환자**
- 상처 드레싱 빈도 ↓
- 치료 비용 절감

#### 성분
- 표준화 aescin 함유
- 항염증·항부종 작용

#### 한계
- 디오스민과 유사하게 **증상 완화 역할**
- 정맥 판막 손상 치료 불가

### 4. 비교: 영양제 vs 시술

| 접근법 | 장점 | 단점 |
|--------|------|------|
| **영양제** (디오스민/말밤) | 증상 완화, 비침습적, 비용 낮음 | 근본 치료 아님, 진행 가능 |
| **압박 스타킹** | 증상 완화, 장기 사용 안전 | 미용상 문제, 착용 불편 |
| **최소침습 시술** (RFA, 레이저) | 정맥 폐쇄율 90~100%, 재발률 <10% | 비용 높음, 부작용 가능성 |
| **수술** | 근본 치료, 장기 효과 | 회복 기간 길, 비용 높음 |

### 5. 한국 식약처 승인 현황

**현실**: 정맥류 전문 고시형 원료 없음

- 디오스민·말밤종자: 개별인정형 또는 의약품일 가능성
- 제품 구입 시: 허가 분류(의약품 vs 건기식) 반드시 확인
- 개별인정형이면: 해당 기업이 임상 근거 제출했을 것

### 6. 임상 의사결정 경로

```
정맥류 증상 발생
    ↓
초음파 검사 (duplex ultrasound)
    ↓
심각도 평가
    ├─ 경증: 증상 없거나 경미함
    │   └─ 압박 스타킹 + 영양제 보조
    │
    ├─ 중등증: 중등도 증상 (부종, 통증, 피로)
    │   └─ 영양제 시도 → 효과 없으면 시술 검토
    │
    └─ 중증: 심한 증상 또는 궤양
        └─ 시술/수술 고려
```

## 독자 안내 원칙

### 정맥류 진단받으면

1. **초음파 검사로 심각도 확인** (경증/중증 구분 필수)

2. **경증 정맥류** (증상 경미)
   - 먼저 해보기: 영양제 + 압박 스타킹
   - 4~8주 후 효과 평가
   - 증상 개선되면 지속, 안 되면 시술 검토

3. **중등도~중증 정맥류** (증상 심함, 미용 문제)
   - 영양제보다 시술이 더 실질적
   - 최소침습 시술: 회복 빠르고, 폐쇄율 90~100%
   - 비용·회복·장기 효과 고려하여 의료진과 상담

4. **정맥 궤양 있으면**
   - 말밤종자 추출물 고려 가능 (코스트 베네핏)
   - 의료진 판단 필수

### 금지
- "영양제로 정맥류를 완치한다"는 마케팅 신뢰 금지
- 정맥류 진단 후 의료진 상담 없이 영양제만 의존 금지
