# 실업인정 (신청·환급 달력) — 조사 브리프

- 슬러그: unemployment-recognition (표제어: 실업인정(구직활동) / 검색 키워드: 실업인정 방법)
- 조사일: 2026-10-27 · 근거 힌트: 고용24
- facts: `content/research/facts/신청_unemployment-recognition.json`

## 1. 저장소 확인
- facts 원본 확인. 구직급여 관련 기존 팩트 `신청_unemployment-benefit.json`(고용보험법 전반)을 읽음.
- 재사용 2건:
  - `unemployment-benefit-status`(논쟁): 고용보험법 표시본 시행일 2028.1.1 문제. 이번 주제에도 그대로 적용.
  - `ui-apply-where-how`(확실): 이직 후 지체 없이 직업안정기관에 출석해 실업 신고(고용보험법 제42조 제1항). 이번 실측에서도 제42조 원문 일치 확인.
- 거부 0. 기존 팩트에 "실업인정" 항목은 없었다.

## 2. 직접 연 공식 페이지 (실측)
| URL | 확인 내용 |
|---|---|
| https://www.law.go.kr/법령/고용보험법/제44조 | 제2항 실업인정일 1주~4주 지정, 직전 실업인정일 다음 날부터 인정, 제3항 출석 불가 시 증명서 |
| https://www.law.go.kr/법령/고용보험법/제42조 | 실업 신고 출석 원칙 (표시본) |

## 3. ★현행 여부 — 최우선 확인 사항
- 두 조문 모두 국가법령정보센터 표시가 "[시행 2028. 1. 1.] [법률 제21473호, 2026. 3. 17., 일부개정]"이다.
- 즉 2026.10.27 현재 효력이 있는 고용보험법 본문과 같은지 **확인하지 못했다.** 표시본은 2028년 시행 예정 문언이다.
- 그래서 실업인정 주기("1주~4주")와 출석 불가 사유는 tier "논쟁"으로 남겼다.
- 해결 방법: 현행(2026.10.27 시행) 연혁본을 법제처에서 열어 비교하거나, 고용24·고용센터 공식 안내를 확인. 확인 전에는 주기 숫자를 글에 단정하지 말 것.

## 4. 확인 못 한 것 (확인실패)
- 고용24 온라인 실업인정 경로와 증빙 파일 첨부 방식: 블로그 요약뿐, 공식 페이지 확인 실패. → `unemployment-recognition-online-unverified`
- 실업인정 주기 "28일마다", "월 2회 이상 구직활동" 등 블로그 설명: 공식 근거 없음. 법령의 1~4주 범위 안에서 지정된다는 것까지만.
- 증명서 서식 명칭: 확인 못 함.

## 5. 집필 시 주의
- 실업인정은 실업 신고 후 "지정된 실업인정일에 출석해 구직 노력을 신고"하는 절차다. 신고(제42조)와 인정(제44조)을 한 단계로 합치지 말 것.
- "대기기간" 같은 기간 숫자는 이번 주제 범위 밖이며, 기존 팩트 `ui-waiting-period-unverified`(확인실패)를 따른다.
- 독자가 "온라인으로 어떻게 하나"를 묻는 경우: 고용24 공식 화면과 관할 고용센터 문의를 안내. 메뉴 경로는 쓰지 말 것.
