# 그래픽 태블렛(와콤·펜타블렛) 펜 인식 안 됨·필압·커서 어긋남 자가점검

## 조사 범위
- 분야: 디지털·IT(그래픽 태블렛 특화)
- 대상: 와콤(Wacom), 펜타블렛(XP-Pen), 휴이온(Huion) 등 USB 펜 입력 방식 그래픽 태블렛
- 증상: 펜 인식 안 됨, 필압 미작동, 커서 어긋남, 선 끊김, 펜촉 마모
- 주의: iPad와 같은 태블릿 PC는 별도 범위(이번 조사 제외)

## 주요 조사 결과

### 1. 펜 인식 안 됨 (가장 흔한 증상)

**근본 원인 Top 3:**
1. **드라이버 문제** (70% 이상): 제조사 공식 드라이버가 최신이 아니거나, Windows 업데이트와 호환되지 않음
2. **USB 연결 문제** (15%): 케이블 접촉 불량, 포트 이물질, 포트 손상
3. **배터리 부족** (무선/배터리식 펜): 배터리 표시등 확인 필수

**진단 순서:**
1. 먼저 드라이버 버전 확인 → 최신 버전이 아니면 업데이트
2. USB 케이블·포트 물리적 상태 확인
3. USB 포트 변경해보기 (특정 포트 불량일 수 있음)
4. 드라이버 완전 제거 후 재설치
5. 장치 관리자에서 "알 수 없는 장치" 확인 → 있으면 드라이버 수동 지정

### 2. 필압 미작동 (그림 그릴 때 필압이 먹히지 않음)

**핵심 원인 3가지:**

**① 입력 방식 불일치** (가장 흔함)
- 싱글 모니터: WinTab 방식으로 설정 권장
- 듀얼 모니터: Windows Ink 방식 필요
- 드라이버 설정에서 입력 방식 변경 후 **반드시 재부팅**

**② Windows Ink 충돌**
- 와콤 드라이버와 Windows Ink 시스템이 충돌
- 해결: 타블렛 드라이버 설정 > "Windows Ink 사용" 체크 해제

**③ 그래픽카드 드라이버 충돌** (NVIDIA 사용자 주의)
- 선이 떨리거나 필압이 불규칙할 때 발생
- 해결: NVIDIA 드라이버 설정 > V-Sync 끄기

### 3. 커서 어긋남 (펜을 터치한 위치와 커서 위치가 다름)

**원인:**
- Windows Ink 활성화 상태
- 듀얼 모니터 설정에서 활성 디스플레이 지정 안 됨

**해결:**
1. Windows Ink 비활성화
2. 타블렛 드라이버 > 디스플레이 매핑 > 현재 사용 중인 모니터로 명시적 설정
3. 해결 안 되면 드라이버 완전 재설치

### 4. 선 끊김·지터 (선이 떨리거나 끊김)

**직접 원인:**
- NVIDIA 그래픽카드와 타블렛 드라이버 간의 프레임 동기 충돌
- 해결: NVIDIA 드라이버 설정에서 V-Sync 끄기

**부차 원인:**
- 드라이버 버전 호환성 문제 → 최신 버전으로 업데이트
- 다른 USB 기기와의 대역폭 경쟁 → USB 포트 변경

### 5. 펜촉 마모 (선이 점점 희미해짐)

**확인 방법:**
1. 먼저 드라이버 재설치로 인식 개선 여부 확인
2. 개선 없으면 펜촉이 물리적으로 마모된 것
3. 제조사에서 교체용 펜촉(니브) 구매 필요

## 실전 문제해결 흐름도

```
펜이 인식 안 됨?
  ├─ 드라이버 최신 버전 확인 → 아니면 업데이트
  ├─ USB 케이블·포트 물리적 상태 확인
  ├─ 다른 USB 포트에 연결해보기
  ├─ 드라이버 완전 제거 후 재설치
  └─ 여전히 안 되면 → 하드웨어 결함일 가능성

필압이 먹히지 않음?
  ├─ 입력 방식 확인 (WinTab vs Windows Ink)
  ├─ Windows Ink 비활성화 시도
  ├─ NVIDIA: V-Sync 끄기
  └─ 드라이버 완전 재설치

커서가 어긋남?
  ├─ Windows Ink 비활성화
  ├─ 듀얼 모니터 경우 활성 디스플레이 설정
  └─ 드라이버 재설치

선이 끊김/떨림?
  ├─ NVIDIA: V-Sync 끄기
  ├─ 다른 USB 포트 시도
  └─ 드라이버 최신 버전으로 업데이트
```

## 팩트 구조화 시 주의사항

### scope 명시
- **브랜드:** 와콤, 펜타블렛, 휴이온 등 공통 제조사 기준이 아니라, "USB 펜 입력 방식"이라는 기술 기준으로 통합
- **연식:** 현행(드라이버 기반이므로 연식 구분 의미 없음)
- **지역:** 드라이버는 글로벌이나, 사용자 보고는 주로 한국 커뮤니티 기반

### tier 판정
- **확실:** 와콤·제조사 공식 문서, 또는 복수 독립 커뮤니티 일치
- **논쟁:** 특정 모델이나 설정에서만 통하는 경우 (예: NVIDIA 사용자만 V-Sync 문제)
- **확인실패:** 원인으로 추정되지만 공식 근거 없는 경우

### evidence 유형
- **공식:** 와콤·펜타블렛·휴이온·Microsoft 공식 문서
- **후기:** 사용자 커뮤니티, 기술 포럼, 블로그
- **실측:** 직접 접근 확인

### caution 필요 케이스
- 드라이버 변경 후 재부팅 필수
- V-Sync 해제 시 화면 티어링 가능
- 펜촉 교체 전 반드시 드라이버 재설치 우선
