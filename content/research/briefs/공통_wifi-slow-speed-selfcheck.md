# 와이파이 느려짐 진단: 속도측정·채널 간섭·대역 선택

## 조사 목표
인터넷은 되는데 속도가 느릴 때 사용자가 직접 진단할 수 있는 방법 파악

## 조사 결과

### 1단계: 속도 측정
- **NIA 스피드테스트**: https://speed.nia.or.kr/
- **측정 시간**: 1-2분
- **결과 항목**: 다운로드 속도, 업로드 속도, 지연시간
- **비교**: 전국 통신사별 평균과 자신의 측정값 대조 가능
- **공식성**: 통신사 민원·품질 보증 요청 시 인정됨

### 2단계: 채널 간섭 확인
- **도구**: WiFi Analyzer(안드로이드), Airport Utility(iOS)
- **2.4GHz 권장 채널**: 1, 6, 11번 (이들은 서로 겹치지 않음)
- **간섭 원인**: 전자레인지, 블루투스 기기, 이웃 공유기

### 3단계: 대역 선택
- **2.4GHz**: 범위 넓음, 간섭 많음, 느림
- **5GHz**: 범위 좁음, 간섭 적음, 빠름

## 소스
- 한국인터넷진흥원 공식 페이지
- 와이파이 기술 표준 및 커뮤니티

## 주의점
- 2.4GHz와 5GHz는 기기 성능·위치·주변 환경에 따라 선택
- 공유기 자동 채널 선택 기능도 효과적
