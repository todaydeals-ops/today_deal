## 1. 힌트와 원문의 차이
- 총괄 힌트는 "소방청 공식 기준"이었다. 실제로는 소방청 안내 페이지와 국가법령정보센터 시행령 원문을 열어 확인했다.
- 힌트와 달랐던 점: 소화기 사용기한 10년은 소방청 안내와 시행령 제15조의4 양쪽에서 확인됐다. 다만 시행령은 특정소방대상물 관계인 기준이라 일반 가정에는 "안내상 기준"으로 쓰는 것이 맞다.
- 단독경보형 감지기의 "배터리 교체 연한"은 소방청이 약 10년으로 적고 있다. 본체 교체 연한은 공식 원문에 없었다.

## 2. 공식 확인 항목 (열어 본 원문)

| 항목 | 내용 | 출처 |
|---|---|---|
| 감지기 배터리 수명 | 약 10년 | 소방청 주택용 소방시설 안내 (열어 확인) |
| 감지기 점검·리셋 | 주기적 점검, 오작동 시 리셋 버튼 | 같은 페이지 |
| 감지기 설치 | 구획된 실마다 설치 | 같은 페이지 |
| 소화기 사용기한 | 10년 | 같은 페이지 |
| 소화기 압력게이지 | 녹색 범위 확인 | 같은 페이지 |
| 소화기 설치 | 세대별, 층별 1개 이상 | 같은 페이지 |
| 분말 소화기 내용연수 | 10년, 2017.1.28 시행 제15조의4 | 국가법령정보센터 시행령 원문 (열어 확인) |
| 경과조치 | 시행 후 1년 안에 교체 또는 성능확인 | 같은 원문 부칙 제3조 |

## 3. 후기·기사 항목 (evidence "후기")
- 위키트리 "소화기 압력계부터 보세요" 기사: 녹색 벗어나면 업체 문의, 육안 점검 항목(핀·봉인·호스·노즐·용기), 시험 방출 금지, 한 번 작동한 소화기는 재충전 또는 교체, 열원 근처 피하기.
- 위키트리 "삐 소리 난다고 배터리 빼지 마세요" 기사: 배터리를 빼면 경보가 꺼짐, 같은 자리에서 새 배터리 교체, 월 1회 테스트(NFPA 권고 인용), 본체 연한은 모델마다 다름.
- 기사 원문에서 국민재난안전포털을 근거로 든 부분은 포털 원문을 열어 확인하지 못했다. 그래서 귀속은 위키트리 기사로만 적었다.

## 4. 확인실패 · 제외한 항목
- **소화기 성능확인 연장 기간(10년 미만 3년, 이상 1년, 1회 한정)**: 검색 발췌에만 있고 원문을 열지 못했다. 팩트에서 제외했다. 집필 시 "연장 검사로 쓸 수 있는 경우가 있다"까지만 쓰고 기간은 쓰지 말 것. 확인 경로는 국가법령정보센터 「소방용품의 품질관리 등에 관한 규칙」 현행 조문과 한국소방산업기술원.
- **제조연월 위치(소화기 옆면)**: 지방 소방서 보도자료 발췌에만 있었다. 원문 미확인이라 팩트화하지 않았다. 집필 시 "제조연월은 라벨에서 확인"처럼 위치를 특정하지 말 것.
- **지시압력계 없는 가압식 소화기의 1999년 이후 생산 중단·즉시 교체**: 검색 요약에만 있었다. 확인 실패, 제외.
- **감지기 천장·벽 이격 거리(0.6m, 1.5m)**: 소방청 FAQ 검색 결과에만 나왔고 원문을 열지 못했다. 제외.
- **소방시설 외관점검표(세대점검용)의 "수동식 분말소화기 내용연수(10년) 적정 여부" 항목**: 법령 검색 결과에만 있었다. 원문 미확인. 제외.

## 5. 집필 시 주의
- 10년 수치 셋은 출처가 다르다. 소화기 사용기한과 감지기 배터리 수명은 소방청 안내, 소화기 내용연수 법적 근거는 시행령이다. 한 문단에 섞어 "소방법상 10년"이라고 쓰지 말 것.
- 감지기 본체는 10년이라고 단정하지 말 것. 기사 수치는 참고치, 본체는 제품 표기 우선.
- 소화기를 직접 작동시켜 보는 시험은 금지로 쓰고, 대신 압력계·외관·라벨 확인을 안내할 것. 재충전은 업체 몫.
- "AS를 부를 기준": 녹색 벗어남, 외관 손상·누설·부풀음, 한 번 작동한 경우, 10년 초과 시 교체 또는 성능확인. 전화 접수 경로와 보증은 공식 출처를 확인하지 못해 쓰지 말 것.
- 어조는 상담가 톤으로, "여기까지 해봤는데 안 되면 소방서·업체"로 끝낼 것.

## 6. 검색 사용 내역
- 웹 검색 5회 사용(한도 6회 이내). 원문 열기 WebFetch 4회(위키트리 2건, 소방청 안내, 국가법령정보센터 시행령 개정문).
- 소방청 원문에서 감지기 설치 위치 세부 규격과 점검 주기 숫자는 확인되지 않았다.
