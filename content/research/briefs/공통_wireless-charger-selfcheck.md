# 무선충전기(Qi·MagSafe) 충전 안 됨·느림·발열 자가점검 조사보고

## 조사 범위

무선충전기의 일반적인 자가점검 문제를 다룬다:
- 충전 안 됨 (정렬 어긋남, 코일 위치, 어댑터 문제)
- 충전 느림 (어댑터 W수, 비인증, 효율 저하)
- 발열 (케이스 두께, 금속, 마그넷, 정렬 오류)
- 충전 자꾸 끊김 (진동, 미세정렬, 호환성)
- 외부 요소 간섭 (두꺼운 케이스, 카드, 금속 링)
- Qi vs MagSafe 선택 기준
- 밤새 충전 안전

**제외:** 기기 배터리 내부 문제, 충전 포트 하드웨어 고장, 특정 모델 펌웨어 이슈

---

## 주요 발견

### 1. Qi 충전의 핵심 메커니즘 — 코일 정렬

무선충전기는 송신 코일이 발생한 자기장을 스마트폰 내부 수신 코일이 받아 전류로 변환하는 원리다. 
이 과정에서 **두 코일의 중심이 1~2cm만 어긋나도 에너지 전달 효율이 절반 이하로 떨어진다.**

- 구형 Qi 충전기: 수동 정렬 필요 → 위치가 조금만 틀어도 끊김 위험
- Qi2: 자석 정렬(MPP, Magnetic Power Profile) 추가 → 구형 대비 20% 효율 향상
- MagSafe: Apple 자석 기술 → 자동 정렬, 최대 25W 충전

**대책:**
- Qi/Qi2 패드는 **중앙에 정확히 배치**하고, 기기가 움직이지 않도록 고정
- Qi2 또는 MagSafe 선택 시 자석 정렬의 안정성 이득 고려

### 2. 어댑터와 케이블 — "충전 느림"의 50% 이상이 여기서 나온다

Qi2 25W 이상 충전 환경에서는:
- **어댑터 부족:** 25W 충전기를 샀는데 5W 어댑터로 연결하면 충전이 5W 수준으로 제한됨
- **케이블 정격 문제:** 같은 45W 어댑터도, 정품 5A 케이블과 저가 3A 케이블 사이에 20분 이상의 충전 속도 차이 발생
- **PD(Power Delivery) 인증:** USB PD 미인증 어댑터는 호환 기기에서 제대로 된 고속충전 프로토콜을 지원하지 않음

**케이스별 최소 사양:**
- 10W 무선충전: 5V/2A 어댑터(10W) + 정품 케이블
- 15W 무선충전(MagSafe): 9V/2A 또는 PD 18W 이상 어댑터
- 25W 무선충전(Galaxy Qi2): PD 45W 이상 어댑터 + 5A 케이블

### 3. 발열 — "정상 범위" vs "주의 필요"

#### 정상 발열
- Qi 충전 중 기기 뒷면 37~43°C: 정상 (배터리 60°C 미만이면 OK)
- MagSafe 충전 중 약간 따뜻함: 정상 (고속 충전이므로)

#### 주의 필요한 발열
- 충전기 패드가 너무 뜨거움 (손을 댈 수 없을 정도): 비인증 제품 의심, 어댑터 점검
- 금속 링/카드 주변이 '뜨거움': **즉시 제거 필요** — 금속은 유도 전류로 인해 과열되어 화재 위험

#### 발열 원인과 대책
| 원인 | 증상 | 대책 |
|---|---|---|
| 코일 정렬 오류 | 충전기 한쪽만 뜨거움 | 기기 재정렬, Qi2/MagSafe 고려 |
| 금속 케이스/링/카드 | 그 부위만 과열 | **즉시 제거**, 제거 후 식힐 때까지 대기 |
| 두꺼운 케이스(3mm 이상) | 충전 느려짐 + 발열 | 케이스 제거 또는 교체(3mm 이하 소재) |
| 저품질 충전기 | 지속적 고온 | WPC/Qi 인증 제품으로 교체 |
| 밤새 충전 + 고온 환경 | 아침에 기기가 뜨거움 | 통풍 좋은 곳에서 충전, 배터리 보호 기능 활성화 |

### 4. 케이스의 영향 — 3mm 기준선

**무선충전 가능한 케이스:**
- 일반 플라스틱·실리콘 케이스 (3mm 이하): 대부분 정상 작동
- Qi 인증 케이스: 충전 손실 최소화 설계

**충전 불가 또는 느려지는 케이스:**
- 금속 부분 포함 (카드 슬롯, 링 장착부, 고리 부착부)
- 지갑형 케이스 (카드 삽입)
- 3mm 초과 두꺼운 러기드 케이스
- 자석 클로저 포함 케이스 (일부 호환 문제)

**카드 매장 시스템 문제:** 신용카드, 교통카드, 철제 성분 카드는 무선충전 중 **금속 부분이 유도 전류를 받아 화재 위험 가능**

### 5. 충전 자꾸 끊김 — 호환성과 정렬 문제

#### 원인 분석
- **비인증 충전기:** 내부 코일 배치가 표준을 벗어나 호환성 불안정
- **미세 정렬 오류:** 기기 진동·움직임으로 코일 위치 어긋남 → 끊김 반복
- **충전기 성능 저하:** 시간이 지나 내부 회로 부식·열화로 인식 불안정

#### 해결 순서
1. **충전기 인증 확인:** WPC 정식 인증(QI 마크) 또는 Qi2 마크 확인
2. **정렬 재점검:** 기기를 중앙에 정확히 배치, 기기 움직임 없도록 고정
3. **기기 청소:** 스마트폰 뒷면의 먼지·이물질 제거 (충전 패드도 함께)
4. **다른 충전기 시도:** 다른 WPC 인증 Qi 충전기로 테스트 → 끊김 여부 확인
   - 다른 충전기에서 정상 → 원래 충전기 불량
   - 모든 충전기에서 끊김 → 기기 수신 코일 문제 가능성(서비스센터)

### 6. Qi vs Qi2 vs MagSafe — 선택 기준

| 항목 | Qi(구형) | Qi2 | MagSafe(Apple) |
|---|---|---|---|
| **정렬 방식** | 수동(중앙에 올려두기) | 자석 기반(MPP) | 자석 기반 |
| **최대 충전 속도** | 7.5W | 15W (표준), 25W (고출력) | 15W (iPhone 15), 25W (iPhone 16) |
| **호환 기기** | 모든 Qi 지원 스마트폰 | Qi2 지원 기기 + 일부 기존 Qi | iPhone 12 이후 + MagSafe 액세서리 |
| **효율** | 100% 기준 | 120% (20% 향상) | 120% (20% 향상) |
| **정렬 안정성** | 낮음 (수동) | 높음 (자석) | 높음 (자석) |
| **케이스 호환** | 3mm 이하 모두 | DFS/Qi2 인증 우대 | MagSafe 링 필수 |
| **평균 가격** | 10,000~20,000원 | 25,000~40,000원 | 30,000~50,000원 |

**선택 권장:**
- 저가 선택: 구형 Qi (단, WPC 정식 인증 제품만)
- 안정성 우선: Qi2 (특히 자주 쓰는 충전 환경)
- Apple 에코시스템: MagSafe (자동 정렬, 최고 효율)

### 7. 밤새 충전의 안전 조건

**배터리 관점:** 기존 조사(battery-charging-myth-factcheck)에서 PMIC 과충전 보호로 안전이 보장됨.

**무선충전 특화 주의:**
- 무선충전 중 발열이 발생하므로, **통풍이 좋은 곳에서 충전할 것**
- 고온 환경(35°C 이상)에서 밤새 충전 + 100% 유지 시 배터리 열화 가속 (기존 팩트와 동일)
- 스탠드형 무선충전기: 기기를 비스듬히 놓아 화면이 켜진 상태(알람·알림 표시)로 밤새 두면 기기도 뜨거워지고 배터리 부담 증가
  → **배터리 보호 모드(Apple 최적화 배터리 충전 / Samsung 배터리 보호)를 켜두고 충전할 것**

### 8. 정품 어댑터·케이블의 중요성

비인증 어댑터의 위험:
- 과전압 전송 가능성 → 스마트폰 충전 IC 손상
- 부정확한 전류 제어 → 배터리 충전 회로 스트레스
- 온도 센싱 부재 → 고온에서도 계속 고속 충전 (배터리 열화 가속)

**최소 인증 기준:**
- USB PD 또는 QC 공식 인증 (Amazon·Apple·Samsung 공식 스토어에서 구매)
- KC 인증 (국내 제품) 또는 동등 인증
- 관련 제품 설명서에 규격과 인증 마크 명시
