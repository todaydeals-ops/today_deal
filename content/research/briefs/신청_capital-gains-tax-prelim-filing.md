# 양도소득세 예정신고 — 조사 전문 (2026-10-27)

## 목표
부동산·주식 등을 팔았을 때 예정신고 기한, 예정신고 방식, 미신고 시 불이익, 확정신고 기간을 공식 근거로 정리.

## 확인 못 한 것
- 분납 제도: 검색 요약에 "1천만 원 초과 시 기한 후 2개월 분납"이 있었으나 열어 본 국세청 표·안내 페이지와 조문에서 확인하지 못함 → `capital-gains-prelim-installment-unverified`(확인실패).
- 신고처(양도자 주소지 관할): 검색 요약에만 있고 원문 미확인. 팩트로 올리지 않음.
- 제94조 가·나목의 구체 요건(대주주 기준 등)은 시행령 위임 사항이라 열지 않음. 글에서는 "주식 등"까지만 쓸 것.
- 확정신고 시 1건만 양도한 경우 확정신고 면제 여부: 검색 요약에만 있고 원문 미확인.

## 재사용·거부
- 재사용: `law-deadline-weekend-next-day-national`(국세기본법 제5조, 기존 신청_법정기한-공식근거.json). 국세 기한 원칙으로 적용.
- 거부: `law-income-tax-final-return-may`(종합소득세 확정신고 조문 제70조. 양도소득세 확정 기간은 국세청 표로 직접 확인). `law-deadline-weekend-next-day-local`(지방세 기한, 양도소득세는 국세).

## 현행 여부
- 소득세법 제105조·제106조: 시행 2026.1.1 현행본 열람. 종료·개편 의심 없음.

## 집필 시 주의
1. 기한은 "양도일이 속하는 달의 말일부터 2개월"(부동산)과 "반기 말일부터 2개월"(주식)을 자산 종류별로 나눠 쓸 것. 한 줄로 뭉치지 말 것.
2. 가산세는 "20%가 붙는다"까지만 쓰고 계산 예시는 만들지 말 것(감면·중복 규정이 있음). 분납 조건은 단정 금지.
