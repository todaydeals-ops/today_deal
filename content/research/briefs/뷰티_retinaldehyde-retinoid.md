# 조사: 레티날데하이드 (레티노이드 강도 스펙트럼 상 자리)

## 조사 배경

레티놀과 처방 트레티노인 사이에 자리한 중간 강도의 레티놀계 성분 레티날데하이드(retinaldehyde, retinal)에 대한 임상 근거.

## 조사 결과 요약

### 1. 생체이용률과 강도 계층

- **기존**: 레티날데하이드는 기초 레티놀보다 생체이용률이 약 10배 높음 (2026-08-10 확인)
- **강도 순서**: 레티놀 → 레티날데하이드 → 트레티노인 (처방)
- 레티날데하이드는 천연 변환 경로의 중간체로서, 레티놀을 트레티노인으로 변환하는 한 단계

### 2. 임상 효능 (0.1% 농도)

**시험**: 32명 여성, 8주 도포, 0.1% 레티날데하이드 + 펩타이드·세라마이드
- 얼굴 주름: 12% 개선 (8주)
- 흉부 주름: 11% → 19% 점진적 개선
- 과다색소: 19% 감소
- **patch test: 자극 없음** (보조 성분의 영향 가능)

**시험**: 3개월 도포, 비교
- 0.1% 그룹: 광손상 95% 개선
- 0.05% 그룹: 광손상 95% 개선
- **결론**: 두 농도 간 통계적 유의한 차이 없음

### 3. 자극도 프로파일

- 트레티노인(처방) 대비 국소 자극(burning, dryness, erythema) **훨씬 적음**
- 동등한 효능에 더 나은 내약성 (tolerability)
- 초기 적응 기간(retinization) 여전히 발생 가능 → 점진적 도입 권장

### 4. 제형 과제

**안정성 문제**:
- 수용성 낮음, 산화에 취약
- 저농도 포함 제품도 경시 변화 발생

**해결 기술**:
- 나노 리포솜
- 에토솜 (ethosomes)
- 지질 캡슐화
- 최근 정보: 이 기술들이 피부 전달성과 안정성을 개선 중

### 5. 국내 규제 현황

조사에서 확인되지 않음 (기능성화장품 고시 농도 미검증).

## 집필 시 활용 포인트

1. **자극도 기대치**: 트레티노인처럼 초기 적응이 있을 수 있지만, 더 견딜 수 있음
2. **농도**: 0.05% ~ 0.1% 모두 효과 입증됨 → 민감성 피부는 저농도 추천
3. **제형 확인 필수**: 나노 기술 포함 여부가 실제 효과와 안정성을 좌우
4. **경시 변화**: 개봉 후 산화 속도가 빠를 수 있으니, 밀폐 보관과 개봉 후 사용 기한 주의

## 확인실패 / 미확인

- 국내 기능성화장품 고시 농도 미확인
- 0.05%, 0.1% 모두 동등한 효과라는 결과의 메커니즘 추가 분석 필요

## 웹 검색 횟수

3회 (총 예산 6회 중 사용)
