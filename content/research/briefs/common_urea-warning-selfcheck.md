# 조사 브리프 — 디젤 차량 요소수 경고등 (urea-warning-selfcheck)

- 코너: repair / 분야: 자동차 / 조사일: 2026-11-03
- 산출 팩트: `content/research/facts/common_urea-warning-selfcheck.json` (14건)

## 1. 저장소 확인 (0단계)
- `facts/` 전수 검색(요소수·AdBlue·urea) 결과 요소수 관련 기존 팩트는 없음.
- 재사용 0건. 기존 `common_car-*` 팩트는 엔진 경고등·오일 경고등 주제라 겹치지 않음.
- `declined_facts`: 2021년 요소수 대란 당시 한시 긴급조치(승용 10L 구매 한도 등)는 현재 시행 여부를 확인하지 못해 제외.

## 2. 핵심 출처 (실제로 열어 확인한 것)
- [공식] 현대 오너스 매뉴얼 — 요소수 시스템 (디젤 엔진, LX2 2024판)
  https://ownersmanual.hyundai.com/full_webhelp/LX2/2024/ko_KR/id511f93966a5.html
  - 4단계 경고 문구, 1차 경고 기준 약 2,400km 이하, 보충 주의(연료 주입구 금지·50℃·-11℃·정격 용량선·ISO 22241 또는 DIN 70070), 재시동 불가 시 직영 하이테크센터·블루핸즈 문의.
- [공식] 기아 오너스 매뉴얼 — 요소수 시스템 (SCR, HM 2024판)
  https://ownersmanual.kia.com/full_webhelp/HM/2024/ko_KR/topics/t00870.html
  - 4단계 경고 문구(1단계 "요소수가 부족합니다"), 1차 기준 약 1,200km 이하, 약 3,000km 보충 안내(소모량 가변), 시동 OFF 후 약 2분 펌프 동작, 고장 경고 시 서비스센터 점검, 재시동 불가 시 긴급출동지원센터.
- [공식] 기아 오너스 매뉴얼 — 경고등 판 (HM 2024판)
  https://ownersmanual.kia.com/full_webhelp/HM/2024/ko_KR/topics/t00348.html
  - "요소수 레벨이 E를 가리키기 전에 보충" 안내. 경고 문구·거리 수치는 없음.

## 3. 힌트와 달랐던 점
- 총괄 힌트는 "공식 기준 환경부·한국환경공단"이었으나, 사용자용 보충·보관 지침은 환경부·한국환경공단 검색에서 찾지 못함. 나온 자료는 2021~2022년 대란 보도자료뿐이고 현행 소비자 지침이 아니었음. 따라서 보충 요령은 제조사 매뉴얼을 1순위로 씀.
- 경고 기준 거리가 브랜드별로 다름: 현대 LX2 2024판 약 2,400km, 기아 HM 2024판 약 1,200km. 힌트에 없던 사항이며 "차종·연식별 확인" 문구로 처리해야 함.
- 요소수 규격: 현대·기아 매뉴얼 모두 ISO 22241 또는 DIN 70070 기준을 명시. 국가표준(KS) 번호와 시험 기준은 이번 조사에서 확인하지 못함(국가기술표준원 확인 필요). 업계 보도로 KS-WEI 평가 1위 소식은 있었으나 규격 내용은 아니므로 쓰지 않음.
- 보충 후 재시동: 두 매뉴얼 모두 ON 상태로 경고문이 사라질 때까지 기다린 뒤 재시동을 안내.

## 4. 후기 자료
- 웹 검색에서 "보충했는데 경고가 안 꺼짐" 류의 실사용 후기는 확인하지 못함. 검색 결과는 전부 공식 매뉴얼 페이지였음. 독자 안내는 매뉴얼 절차(ON 대기 후 재시동 → 그래도 안 되면 센터)로 구성.

## 5. 확인 한계
- WebFetch는 요약 모델을 거치므로 거리 수치(1,200·2,400·3,000km)와 용량 문구는 원문 대조를 한 번 더 권장.
- 현대 매뉴얼 LX2 판과 기아 HM 판이 어떤 차종에 해당하는지는 이번 조사에서 특정하지 않음(scope.line에 판본만 기재).
