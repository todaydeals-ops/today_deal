# 스마트TV 스트리밍 앱 자가점검 조사 보고서

**주제:** Netflix·YouTube·Tving 등 스트리밍 앱 안 켜짐·버퍼링·로그인 오류
**조사기간:** 2026-07-24 ~ 2026-07-28
**조사 범위:** 삼성·LG 스마트TV, 소프트웨어·앱 전용 (하드웨어 TV 에러와 분리)

---

## 1. 스트리밍 앱 안 열림

### 1-1. 기본 제공 앱은 삭제 불가, 재설치만 가능

**근거:** 삼성전자서비스 공식 문서
- Netflix, YouTube, Tving 등 TV에 기본 제공되는 스트리밍 앱은 완전 삭제가 불가능하다
- 앱 오작동 시에는 **재설치만** 가능
- 삼성 TV: 홈 → 앱(Apps) → 설정 → 원하는 앱 선택 → 재설치
- LG TV: 앱이 설치 불가로 표시되면 먼저 서비스 국가 설정을 확인해야 함

### 1-2. LG TV 지역·OS 버전 제약

**근거:** LG전자 고객지원
- **서비스 국가 설정 필수:** 가입한 국가 ≠ TV 설정 국가 → 앱 사용 불가
- **webOS 버전별 지원:** 앱마다 지원 버전이 다름
  - Netflix: webOS 1.0(2014년형) 이후 지원
  - 다른 앱은 더 신형만 지원 가능
- 앱 스토어에서 "이 제품에서 사용할 수 없음"으로 표시되면 모델이 미지원

### 1-3. 콜드 부팅 (전원 재연결)

**근거:** 삼성·LG 공식 문서
- TV가 먹통이거나 앱이 계속 오류 → 전원 코드 분리 후 **30초 이상 대기** → 재연결
- 이 과정에서 TV를 켜려고 하면 안 됨
- 효과: 소프트웨어 일시적 오류 해결

### 1-4. 앱 캐시 삭제 (부분 검증)

**근거:** 사용자 보고 및 공식 가이드
- 앱이 반복적으로 오류를 일으키면 캐시 삭제 후 재로그인 시도
- **삼성:** 설정 → 앱(또는 애플리케이션) → 저장공간/메모리 → 캐시 삭제
- **LG:** 설정에서 해당 앱을 선택 후 삭제 → 재설치
- **주의:** 메뉴 경로가 모델·OS 버전마다 불일치 (확인실패 항목 없으나, tier: 논쟁)

## 2. 스트리밍 버퍼링·느림

### 2-1. 최소 필요 인터넷 속도

**근거:** Netflix·YouTube 공식 사양
| 화질 | 최소 속도 | 권장 속도 |
|---|---|---|
| HD | 5 Mbps | - |
| 4K | 25 Mbps+ | 50~100 Mbps |

- 속도 확인 방법: TV 설정 → 네트워크(또는 일반 → 네트워크) → 인터넷 속도 테스트
- 같은 네트워크에 다른 기기가 여럿 연결되면 합산 속도가 필요

### 2-2. WiFi vs 유선 인터넷

**근거:** 스트리밍 서비스 권장사항
- **유선(이더넷)의 이점:**
  - 신호 간섭 제거
  - 속도 안정성 향상
  - 특히 스포츠 중계 등 중요할 때 효과
- **필수 확인:** TV가 이더넷 포트를 지원하는가? (구형·저가형 모델 미지원 가능)

### 2-3. WiFi 신호 최적화

**근거:** 공유기 재부팅 가이드 (기존 facts 참고)
- TV와 공유기 사이 거리/장애물 확인
- 필요하면 공유기 재부팅: 전원 분리 1~2분 후 재연결
- 공유기 채널 변경 (2.4GHz vs 5GHz, 채널 간섭 확인)

## 3. 로그인 오류·HDCP

### 3-1. HDCP(저작권 보호) 오류

**근거:** Netflix 공식, LG전자 고객지원
- HDCP: High-bandwidth Digital Content Protection
- 원인: TV ↔ 셋톱박스 간 신호 인증 실패
- 증상: "HDCP 무효", "콘텐츠 재생 불가" 메시지
- 해결책:
  1. HDMI 케이블 양쪽 끝 완전 분리
  2. 케이블 핀 손상/휘어짐 육안 확인
  3. 단단히 재연결
  4. 여전히 오류 → HDMI 케이블 교체 (정품 '울트라 하이스피드' 인증)

### 3-2. 로그인 실패 (복합 원인)

**근거:** Netflix·YouTube 공식 에러 코드
- 가능한 원인:
  1. HDCP 인증 실패 (위 참고)
  2. 계정 인증 서버 문제 (일시적 → 재시도)
  3. 앱 버그 (캐시 삭제 후 재로그인)
  4. 네트워크 연결 불안정 (콜드 부팅)
  5. 지역 제한 (해외 구매 TV, 서비스 국가 설정 확인)

## 4. 리모컨 버튼 미동작

### 4-1. 점검 순서

**근거:** 삼성·LG 공식 리모컨 가이드
1. **배터리 확인:** 극성 올바른지, 잔량 충분한지
2. **배터리 교체:** 새 배터리로 교체, LED 켜짐 확인
3. **리모컨 페어링:** 배터리 교체 후에도 작동 없으면 다시 페어링
   - 삼성: Back + Play/Pause 또는 Back + Guide (모델·연식별 다름)
   - LG: 휠 버튼 누르기 (매직리모컨)
4. **TV 재부팅:** 콜드 부팅

### 4-2. 특정 앱에서만 미작동

- 일반 기능(채널 전환, 볼륨)은 되는데 Netflix·YouTube의 특정 버튼만 안 됨
- 가능성: 앱 UI 업데이트로 버튼 매핑 변경 (앱 재설치로 해결 가능)

## 5. 앱 목록에 안 나타남

### 5-1. 지역/펌웨어 지원 부족

**근거:** LG전자 고객지원
- LG: 앱 스토어 검색 결과에서 "이 제품에서 사용할 수 없음" 표시
- 해결 불가 (TV 하드웨어/펌웨어 지원 안 함)
- 대신: 다른 스트리밍 앱 확인 (Netflix·YouTube 등 대부분 지원)

### 5-2. 펌웨어 업데이트 확인

**근거:** LG전자 고객지원
- 앱 미지원 → 먼저 펌웨어 최신 버전인지 확인
- LG: 설정 → 전체 설정 → 고객지원 → 소프트웨어 업데이트
- 자동 업데이트 설정 가능 (네트워크 연결 필수)

## 6. 주의점 (scope 혼동 방지)

### 하드웨어 TV 에러와 구분

이 조사는 **소프트웨어·앱 전용**이므로 다음과는 분리:
- TV 화면 안 나옴 / 신호 없음 / HDMI 연결 문제 (별도 facts: samsung-tv-error, lg-tv-error)
- 셋톱박스 연결 문제
- 전원 문제

하지만 HDCP는 앱 로그인 오류와 연관되어 있으므로 포함함.

### 공유기 재부팅

기존 iptime-router-selfcheck.json과 중복되지 않도록, 여기서는 **증상 → 인터넷 속도 측정 → 문제 확인**까지만 다룸. 공유기 채널 변경, 펌웨어 업데이트 등 세부 사항은 별도 facts 참고.
