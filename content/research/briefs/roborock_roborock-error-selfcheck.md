## 1. 저장소 대조 (0단계)

- 기존 로보락 팩트: `에러코드_roborock-robot-vacuum.json`에 공식 메시지 페이지 기반 오류 1·4·5·7·8·9·10·13·18, 내부 오류, 팬 속도 저하, 고객지원 문의 경계, 한국 AS 1566-5534가 이미 있다.
- 이번 글은 이 팩트를 `reused_facts`로 재사용했다. 새 팩트는 보증·AS 접수 경로와 Wi-Fi 연결 쪽만 추가했다.
- `declined_facts`: 팅크웨어모바일 Saros Z70 CS 번호(판매 주체가 달라 일반 AS 번호로 쓸 수 없음), 스마트폰 공장 초기화 문구(로봇 Reset에 적용 안 됨).
- 힌트 범위 중 "센서·휠·브러시·먼지통·물탱크·충전"은 기존 팩트에 이미 공식 근거가 있다. 물탱크는 오류 8 항목의 "물탱크 분리 후 재시도" 문구로만 확인된다.

## 2. 조사 결과

### 공식 확인 (kr.roborock.com 서비스 및 보증 페이지, 2026-11-03 열람)
- 보증: 구매일로부터 1년, 결함 보증. 로봇청소기 전용 기간 없음.
- 보증 제외: 소모품(배터리), 액세서리(필터·브러시), 외부 충격, 침수, 정상 마모·외관, 무단 개조, 타사 제품 병용.
- 접수 증빙: 구매 날짜가 보이는 영수증 등. 없으면 공장 출하일 기준.
- AS 전화: 1566-5534. 운영 시간 미표기. 푸터에 카카오톡 문의 채널이 있음(주소 미확인).
- AS 이메일: 본문은 support@roborock.com, 항목은 support@roborock.co.kr로 깨져 있어 불일치. 이메일은 단정하지 않는다.

### 공식 메시지 페이지 (기존 팩트, 재확인)
- Qrevo 메시지 페이지를 다시 열어 오류 1·4·5·7·8·9·10·13·18, 내부 오류, 팬 속도 저하 항목을 확인했다. 기존 팩트와 일치.
- 오류 13은 두 가지 안내가 공존한다(독 전원 2분 분리 / 표시등이 꺼질 때까지 위치 조정). 두 단계 모두 순서대로 제시한다.

### 제3자 (후기 등급)
- Hjalp.ai 앱 연결 가이드: 2.4GHz 전용 안내, 전원+스팟 청소 버튼 길게 눌러 "Resetting WiFi" 안내. 본문에 AI 일부 작성·제3자 가이드라고 명시. 모델 미특정.
- 로보락 공식 Wi-Fi 2.4GHz 문구와 재설정 버튼 조합은 공식 페이지에서 찾지 못했다(확인실패 성격). 글에서는 '시도해볼 방법'으로 쓰고 단정하지 않는다.

## 3. 확인 못 한 것 (글에 단정하지 말 것)

- 앱 강제 종료·재부팅·재설치, 위치 권한 허용 순서: 로보락 공식 근거를 찾지 못했다. 기타 브랜드 페이지 한 건은 404로 열리지 않아 인용하지 않았다. 글에 쓴다면 "일반적으로 해볼 것" 수준으로만 쓰고 출처를 붙이지 않는다.
- 제3자 코드표(18=충전독, 8=먼지통 미장착)는 검색 요약에만 있었고, 해당 페이지를 열어 보니 내용이 없었다. 팩트에서 제외했다.
- 모델·연식별 차이: 공식 페이지의 메시지 항목은 연식을 명시하지 않는다. 기존 팩트의 scope는 "미명시"다.
- 한국 판매 모델의 오류 코드 체계가 미국 지원 페이지와 동일한지는 확정하지 못했다.
