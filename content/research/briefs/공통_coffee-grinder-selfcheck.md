# 커피 그라인더 분쇄 불량·안 갈림·소음 자가점검

## 조사 범위

전동 커피 그라인더(핸드 그라인더 제외)의 자가점검 항목:
- 안 갈림 / 원두 걸림 / 날 막힘
- 굵기 불균일 / 날 마모 / 설정 문제
- 전원 안 켜짐 / 과부하 보호 작동
- 분쇄날 청소·교체
- 소음·발열
- 정전기로 가루 튐
- 코니컬 vs 플랫버 차이
- 원두 기름 찌꺼기

## 핵심 발견

### 1. 안 갈림/원두 걸림/날 막힘 — 대부분 청소로 해결

원두를 갈지 못하는 증상은 3가지 원인이 있다:
- **축축한 원두**: 수분 함량이 높거나 습도가 높은 환경에서 원두가 쉽게 뭉친다.
- **미분 축적**: 오래된 커피 가루와 찌꺼기가 그라인더 날을 막는다.
- **날 마모**: 극단적으로 마모된 날은 고르지 못한 분쇄를 일으킨다.

**해결책**: 생쌀을 그라인더에 넣고 갈아서 제거 → 청소 후에도 안 갈리면 날 마모 의심 → 교체 검토

### 2. 굵기 불균일 — 거의 모두 날 청소나 마모

**핵심 안심 항목**: 굵기 불균일 = 대부분 날 청소·마모 문제다. 

날의 마모 정도는 분리된 날에 손톱을 밀어 확인:
- **손톱에 자국 생김**: 멀쩡한 상태
- **손톱에 자국 안 생김**: 마모된 상태

**관리**: 정기적인 생쌀 분쇄 청소 → 마모 확인 → 필요 시 교체

### 3. 과부하 보호로 멈추는 건 정상

모터가 중간에 멈추면 **과부하 보호 기능이 작동하는 정상 현상**이다.

발생 원인:
- 딱딱한 원두(경도 높은 유형) 분쇄 시
- 호퍼에 원두를 과다하게 투입했을 때

**대응**: 호퍼의 원두를 줄이거나 제거 → 버 나사를 풀어 찌꺼기 청소 → 재시작

### 4. 코니컬 vs 플랫버 — 장단이 다름

| 구분 | 플랫버 | 코니컬버 |
|------|--------|----------|
| 분쇄 입자 | 비교적 균일 | 불균일 |
| RPM | 높음 | 낮음 |
| 발열 | 높음 | 낮음 |
| 맛 특성 | — | 향미·산미톤 극대화 |

**판단 기준**: 입자 균일성 우선 → 플랫버 / 저발열 우선 → 코니컬버. 우위는 없고 취향 차이다.

### 5. 원두 기름 찌꺼기 — 방치하면 곰팡이·향미 저하

그라인더 날 주위의 커피 기름 찌꺼기는:
- 시간이 지남에 따라 산화·부패
- 불쾌한 냄새 발생
- 커피의 본래 향미 저하
- 습도 높은 환경에서 곰팡이 발생 위험

**관리**: 원두 교체 시기마다 생쌀 청소 또는 분해 청소 수행

### 6. 정전기 가루 튐 — RDT 물 분사로 80% 이상 감소

**RDT (Ross Droplet Technique)**: 원두에 물을 뿌려 정전기 방지

**사용법**:
- 분무기나 숟가락으로 원두에 물 한두 방울
- 원두 1g당 약 20마이크로리터 (매우 소량)
- 과다 물 사용 금지 (녹슬음·떡짐)

**효과** (과학적 검증됨):
- 정전기 발생량 대폭 감소
- 커피 추출량 8.5% 증가
- 커피 농도 10% 향상
- 전체 맛 개선

### 7. 소음·발열 — 베어링 문제 또는 무리한 작동

**원인**:
- 베어링 윤활 부족 또는 과다
- 베어링 마모
- 축 정렬 불량
- 무리한 힘으로 분쇄

**주의**: 무리하게 분쇄하면 모터 과부하 및 소손 위험. 소음이 지속되면 서비스센터 문의.

### 8. 청소·교체 안전 — 전원 코드 분리 필수

**⚠️ 필수 안전사항**: 분쇄날 청소나 분해 시 반드시 전원 코드를 분리할 것.

- 전원이 연결된 상태 → 손가락 부상 위험
- 뜻밖의 모터 작동 → 상해 위험
- 생쌀 분쇄 청소 시 → 전원 분리 필수 아님 (외부 접근이 없으므로)
