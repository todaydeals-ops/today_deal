# KT 인터넷 모뎀 LED 색상 진단

## 조사 목표
KT 모뎡의 LED 색상을 읽어 인터넷 끊김의 원인이 집 안인지 회선인지 구분하는 방법 파악

## 조사 결과

### 주요 발견
- **전원 LED**: 초록색 = 정상
- **인터넷 LED**: 초록/파랑/보라색(속도별) = 정상
- **LAN LED**: 초록색 = 정상 연결
- **OPT LED**: 빨강(단선)/주황(신호미약) = 회선 문제

### 소스
- KT 공식 고객지원 페이지 (help.kt.com)
- 통신 기술 커뮤니티 자료

## 구분 가능한 문제 유형
1. 전원 미공급 → 콘센트 확인
2. 모뎀 LED 정상 + 공유기 LED 빨강 → 공유기 문제
3. OPT 빨강/주황 → 회선 단선/신호미약 (사용자 해결 불가, 고객센터 신고)

## 주의점
- LED 색상은 모뎀 모델에 따라 다를 수 있음
- 구형 모뎀은 현행 기준이 적용 안 될 수 있음
