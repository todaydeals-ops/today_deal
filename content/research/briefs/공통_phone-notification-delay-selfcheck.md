# 휴대폰 알림 안 오거나 늦을 때 조사

## 개요
휴대폰에서 알림이 안 오거나 지연될 때의 자가점검 순서를 정리했다. 실제로는 제품 고장이 아니라 설정 누적으로 발생하는 경우가 대부분이므로, 단계별 확인 사항을 명확히 했다.

## 조사 과정
- Google Android 공식 센터
- 삼성전자서비스 공식 가이드
- 사용자 커뮤니티 보고 및 경험담

## 주요 발견

### 알림 문제 자가점검 순서
1. **스마트폰 수준** — 앱별 알림 권한 확인
2. **OS 수준** — 방해금지/집중 모드, 절전 모드, 배터리 제한
3. **앱 수준** — 알림 카테고리/채널, 앱 내부 설정
4. **네트워크** — Wi-Fi/모바일 데이터 연결 상태
5. **앱 업데이트** — iOS/안드로이드 최신 버전 확인

### 흔한 오류 원인
- **방해금지 모드**: 야간이나 업무 중 자동 활성화 후 해제 안 함
- **절전 모드**: 배터리 부족 시 자동 활성화되면서 백그라운드 제한
- **세부 알림 채널**: 전체 ON이어도 특정 카테고리(결제·주문 등)만 꺼짐
- **앱 내부 설정**: 스마트폰 설정과 별개로 앱 자체에서 알림을 OFF 설정

### 지연 vs 누락
- **알림 지연**: 주로 네트워크 불안정
- **알림 누락**: 권한·설정·기기 문제

## 팩트 특성
- **tier**: 대부분 "확실", 1건 "논쟁" (지연 vs 누락 구분)
- **evidence**: 대부분 "공식", 일부 "후기"
- **재사용 처**: 모든 앱 알림 관련 글에 참고 가능

## 톤
알림 문제는 제품 결함이 아니라 설정 누적 문제임을 강조했다. 사용자가 자신도 모르게 여러 설정을 중첩해 켜거나 끈 경험은 흔하므로, "체크리스트 따라 확인하면 대부분 해결"이라는 긍정적 톤을 유지했다.
