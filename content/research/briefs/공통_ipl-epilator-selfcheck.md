# IPL 제모기 가정용 광 제모기 작동 불량·효과 자가점검 — 조사 전문

**조사일**: 2026-07-21  
**조사자**: Claude Code  
**대상 브랜드**: Philips Lumea, Braun Silk·Expert, 공통 기준  
**조사 항목**: 빛 미작동, 카트리지 수명, 효과 조건, 안전 제한, 사용 주기

## 1. 빛이 안 나감 — 원인과 대처

### 1-1. 피부 밀착 불완전 (가장 흔함)

**Philips 공식 안내**에서는 "5초 이상 완전히 피부에 접촉해야 작동"이라고 명시. 빛이 틈새로 새지 않도록 완전 밀착 필수.

- 각도 기울어짐: 90도 수직이 아니면 안 됨
- 들뜬 부분: 피부 곡선에 맞지 않으면 발동 불가
- **해결**: 위치 재조정, 90도 각도 확인

### 1-2. 센서 오염

Philips 공식에서는 "센서가 더러우면 빛이 작동 안 함"이라고 안내.

- 센서 위치: 발광 출구 창 위쪽
- **청소 방법**: Philips 공식 제공 청소포로만 (물티슈 X)
- 니코틴, 먼지 같은 잔여물 축적

### 1-3. 피부톤 센서 감지 실패

기기에 탑재된 센서가 안전상 어두운 피부에서 작동을 차단.

- **Skin Type 6 (검은 피부)**: IPL 자체 부적합 → Nd:YAG 레이저 권장
- Type 5 (진갈색)까지: 제한적 사용 가능하나 화상 위험
- **설명서 확인**: 자신의 피부톤이 기기 권장 범위에 있는지 필수

### 1-4. 악세사리 접촉 불량

발광 헤드(캡/악세사리)가 완전히 끼워지지 않거나 전자 접점 오염.

- **끼우는 법**: 딸깍 소리가 날 때까지 밀어 넣기
- **접점 청소**: 클렌징 클로스로 전자 접점 닦기

### 1-5. 과열로 인한 에러 모드

기기가 자동으로 과열 보호 모드 진입 → 전원 차단.

- **원인**: 연속 사용 중 라이트 온도 상승
- **해결**: 전원 끄기 → 냉각 → 청소 후 재시작
- **무리 사용 금지**: 에러는 기기 보호 신호

## 2. 카트리지 수명 — 발광 횟수 (공식 스펙)

### Braun
- **400,000번 발광** → 약 24년분 풀바디 트리트먼트 상당

### Philips Lumea 9900 (최신)
- **450,000번 발광** → 약 39년분 카트리지 수명

### Philips Lumea 7000 시리즈
- **250,000~400,000번** (모델별 편차)
- 구체적 수명은 모델명 확인 필수

### 발광 사용량 기준
- 풀바디 1회 트리트먼트: 약 300~500번 발광 소비
- 부분 트리트먼트(다리만, 팔만): 훨씬 적게 소비 → 실제 카트리지 수명은 더 김

## 3. 효과 조건 — 털색, 주기, 피부톤

### 3-1. 족색 제한: 검은 털만 반응

**핵심**: IPL은 검은색(멜라닌) 색소에만 반응하는 광.

- ✓ 검은 머리, 어두운 갈색, 진갈색: **효과 있음**
- ✗ 금발, 빨강머리, 하양머리, 회색머리: **효과 없음**

### 3-2. 초기 사용 주기: 주 1회, 3~12주

**Philips 공식**:  
"빈도와 일관성이 핵심. 처음은 자주(주 1회), 시간이 지나며 주기 늘림."

- 3회 치료 후 눈에 띄는 결과 나타나기 시작
- 첫 1~2회 후 "효과 없다" 판단은 조기 포기
- 일관된 사용이 누적 효과 결정

### 3-3. 유지 주기: 피부톤별 조정

**밝은 피부**: 1~2주 주기 가능  
**어두운 피부**: 2~3주 주기 권장 (피부 회복 시간 필요)

### 3-4. 어두운 피부의 위험 — 멜라닌 과도 흡수

**Braun 공식 경고**:  
"멜라닌이 풍부한 어두운 피부는 광을 과도하게 흡수해 화상, 물집, 색소 침착, 흉터 위험."

- Type 6 (검은 피부): IPL 부적합 → Nd:YAG 레이저 권장
- Type 5 (진갈색): 주의 깊은 사용 + 낮은 강도 + 2~3주 주기

## 4. 안전 제한 — 사용 금지 부위 & 금기 조건

### 4-1. 절대 금지 부위

**눈 주변 영역** (심각한 망막 손상 위험)
- 눈 바로 위 금지
- 이마선 근처 금지
- 눈꺼풀 위 금지
- 광에 직접 응시 금지

**문신 부위** (잉크가 광 흡수 → 화상·변형)

**점, 사마귀, 주근깨, 혹** (멜라닌 농축 → 화상·색소 침착)

**생식기 민감 부위**
- 여성: 음순 소음, 질 입구, 항문 주변 금지 (민감)
- 여성: 음순 대음, 회음부, 항문 주변은 주의 깊게 사용 가능
- 남성: 얼굴, 목, 생식기 전체 금지

**기타 손상/질환 부위**
- 화상, 상처, 활동성 감염 부위
- 정맥류 부위
- 만성 피부질환(건선, 백반증) 부위

### 4-2. 금기 의료 조건

**절대 금지**
- 18세 미만
- 임신 중 또는 수유 중
- 만성 피부질환 (건선, 백반증 등)
- 피부암 또는 전암성 병변 병력

**주의 필요**
- 최근 일광욕/인공 태닝 (태닝된 피부는 멜라닌 과다 → 위험)
- 충분한 시간 경과 후 사용

## 5. 통증·화끈거림 — 정상 반응 vs. 이상 신호

### 5-1. 정상 반응

**따뜻한 따끔거림**, **고무줄로 튕기는 듯한 느낌** — 정상  
**지속 시간**: 치료 직후 몇 시간~최대 1주일

### 5-2. 통증 관리

- **냉팩**: 치료 후 화끈거리는 부위 냉각 → 불편함 완화
- **냉각 기능 탑재 기기**: 통증 감지 신경(nociceptor) 활동 감소 → 고통 경감

### 5-3. 이상 신호 — 과도한 열, 타는 냄새

**원인**: **설정 오류** (피부톤·머리색 테이블 미확인)

- 자신의 피부톤·머리색에 맞지 않는 강도로 사용
- 따뜻함이 아니라 **통증 수준**의 열

**해결**: 설명서의 피부톤·머리색 테이블 재확인 → 강도 조정

## 6. 냉각 기능

최신 IPL 모델 중 일부는 냉각 기능 탑재.

- **작동 원리**: 통증 감지 신경 활동 감소
- **효과**: 통증 완화 (완전 제거 X)
- **고가 기능**: 모든 모델에 있는 건 아니고, 고급형 위주

## 7. 사용 준비 단계

### 7-1. 패치 테스트 (필수)

**언제**: 본격 사용 24시간 전  
**방법**: 선택한 강도로 작은 부위 1회 발광 → 피부 반응 관찰

**이유**: 피부 민감도·부작용 미리 확인

### 7-2. 면도 (필수)

**언제**: 치료 24시간 전  
**방법**: 면도기로 면도 (뽑기·왁싱 X)

**이유**: IPL은 피부 아래 머리뿌리 파괴. 털이 뽑혀 있으면 뿌리가 없어 효과 없음.
