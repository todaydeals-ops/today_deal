# 크레아틴 안전성 조사 전문

## 조사 목표
- 신기능 논쟁의 실제 근거 (혈청 크레아티닌 vs 신기능)
- 장기 안전성 데이터 (5년 이상)
- 로딩 프로토콜 및 수분 요구량
- 일반적 오해 (탈수, 경련, 암 위험) 해제

## 핵심 발견사항

### 1. 신기능 논쟁: 혈청 크레아티닌 ≠ 신기능

**광고에서 나타나는 오해**
- "크레아틴이 혈청 크레아티닌을 높인다" ✗ (이것은 나쁜 신호 아님)
- "혈청 크레아티닌 상승 = 신기능 악화" ✗ (잘못된 해석)

**실제 과학**
| 마커 | 변화 | 의미 |
|---|---|---|
| **혈청 크레아티닌** | ↑ 증가 | 근육 크레아틴 수치 상승의 반영 |
| **요소(urea)** | 변화 없음 | 신장 기능 정상 |
| **사구체 여과율(eGFR)** | 변화 없음 | 신장 기능 정상 |

**메타분석 결과 (19개 RCT)**
- 크레아틴 보충 후: 혈청 크레아티닌 증가
- 하지만: 요소·eGFR은 **유의한 변화 없음**
- 결론: **신기능 악화 없음**

**핵심 원리**
> 크레아틴 보충자는 근육 크레아틴 함량이 높아지므로, 대사산물 크레아티닌이 자연스럽게 증가한다. 이는 신장이 제 기능을 하고 있다는 증거다.

### 2. 장기 안전성: 5년 이상 데이터

**임상 추적 연구**
- **5년 만성 보충**: 건강한 운동선수의 신장 기능 유지 확인
- **12주 고용량 + 고단백식**: 저항 운동 훈련자의 신기능 정상 유지
- **여성 축구 선수 시즌 중 장기 보충(2024)**: 생화학 안전 마커 정상

**전문가 합의**
- 대부분의 문헌 검토 및 전문 패널: "건강한 성인에 크레아틴 안전"
- 단, 장기(1년 이상) 대규모 RCT는 여전히 부족

### 3. 고위험군: 신장질환자

**금기**
- 기저 신장질환 병력
- 신기능 저하 (eGFR <60 mL/min/1.73m²)
- 중증 신질환 (eGFR <30): **반드시 의료진 상담**

**이유**: 이미 신장에 스트레스가 있는 경우, 추가 크레아틴이 부담을 증가시킬 가능성

### 4. 일반적 오해 해제

| 주장 | 과학적 근거 | 평가 |
|---|---|---|
| "크레아틴이 탈수를 일으킨다" | 통제 연구로 미지지됨 | ✗ 거짓 |
| "근육경련을 유발한다" | 통제 연구로 미지지됨 | ✗ 거짓 |
| "암 발생 위험" | 인체 임상 증거 없음 | ✗ 이론만 있음 |
| "위약보다 부작용 많다" | 메타분석에서 부작용 동등 | ✗ 거짓 |

**현실**
- 탈수/경련 → 수분 섭취 부족이 원인 (크레아틴 아님)
- 소화기 불편 → 로딩 단계의 높은 용량 때문 (나누어 복용하면 완화)

### 5. 로딩 프로토콜 및 수분 전략

**로딩 단계 (5~7일)**
```
용량: 하루 20~25g (4회 × 5g)
  ├─ 예: 오전 5g, 오전 중반 5g, 오후 5g, 저녁 5g
  └─ 반드시 나누어야 함 (20g 한 번에 = 소화기 부작용)

수분: 하루 4~5리터 (16~20컵)
  └─ 평상시의 1.5~2배

기간: 5~7일 후 유지 단계로 전환
```

**유지 단계 (그 이후)**
```
용량: 하루 3~5g
수분: 하루 3~4리터 (12~16컵)
지속: 무기한 (안전 장기 데이터 확인)
```

**체중 증가 예상**
- 1~2kg 증가 (근육 세포 내 수분 저류)
- 지방 증가 아님
- 크레아틴 중단 시 원래대로 돌아옴

### 6. 특수 인구군

**임신·수유 중**
- 안전성 데이터 부족
- 보수적 접근: 피하기 권장

**여성**
- 남성과 동일한 안전 프로필
- 2024년 여성 축구 선수 연구에서도 안전 확인

**고령자**
- 단기 연구에서 안전 (1~3개월)
- 장기 안전성 데이터 부족 → 의료진 상담 권장

### 7. 용량 최적화

**로딩 없이 시작?**
- 가능함 (하루 3g, 3~4주 후 포화)
- 더 느리지만, 소화기 불편 최소화

**고용량이 더 효과적?**
- 아니다. 일일 3~5g로도 충분
- 고용량이 더 빠르게 포화시킬 뿐

## 집필 기준

### DO
✓ "혈청 크레아티닌 상승 ≠ 신장 손상" 명확히 할 것
✓ 신기능 검사(eGFR) 정상 근거 제시
✓ 수분 섭취의 중요성 강조
✓ 기저 신장질환자는 의료진 상담 강조

### DON'T
✗ "혈청 크레아티닌이 높아져서 위험하다" (오해)
✗ "탈수를 일으킨다" (근거 없음)
✗ "암 위험이 있다" (입증 안 됨)
✗ "부작용이 많다" (메타분석 반박)

## 핵심 메시지
> 크레아틴은 건강한 성인에게 **안전한 보충제**다. "혈청 크레아티닌 상승 = 신장 손상"은 거짓이며, 실제 신기능 마커(eGFR, 요소)는 정상이다. 5년 이상 장기 데이터도 안전함을 보여준다. 반드시 **충분한 수분 섭취**를 병행하고, 기저 신장질환이 있으면 **의료 전문가 상담** 필수다.
