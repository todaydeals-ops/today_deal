# 수면 부족과 체중: 그렐린, 렙틴, 그리고 악순환

## 조사 대상 및 핵심 질문

- **주제**: "잠이 부족하면 왜 살이 찔까?" 호르몬 기전 검증
- **각도**: 그렐린/렙틴 수치 변화 + 인슐린 저항성 + 대사 변화

## 1차 출처 현황

### PLOS Medicine - Wisconsin Sleep Cohort Study (1,024명)
- **역사적**: 수면-식욕 호르몬 연관성의 초석 연구
- **발견**: 수면 짧은 군 → 렙틴 ↓, 그렐린 ↑ (아침 공복혈액검사)
- **장점**: 대규모 인구집단, 실제 생활 데이터

### NIH PMC - Sleep Deprivation and Central Appetite Regulation (2023)
- **포괄성**: 그렐린·렙틴·오렉신·인슐린 통합 설명
- **신최기**: 2023년 종설 → 최신 메커니즘 정리

### Obesity 저널 (Wiley) - 2023
- **임상**: 급성 및 만성 수면 제한 후 체중 증가 추적
- **특이**: 마우스 + 인간 데이터 병렬 제시

### NIH - 5일 수면 제한 실험 (청년 남성)
- **엄격함**: 통제된 실험실, 포도당 대사 직접 측정

### NIH - 6일 4시간 수면 제한 (극단 실험)
- **극대화**: 렙틴 변화의 최대값 관찰 (일일 900kcal 결식 상당)

### Meta-분석 (최근)
- **주의**: 단기 수면 부족에서 렙틴·그렐린 변화 불일치 → 연구 설계 영향 크다

## 기전 상세: 4가지 경로

### 경로 1: 호르몬 신호의 뒤틀림 (렙틴-그렐린)

```
수면 부족 (6일 4시간)
  ↓
렙틴 ↓ (포만 신호 감소)
그렐린 ↑ (배고픔 신호 증가)
  ↓
뇌: "지금 기아 상태다" (잘못된 인식)
  ↓
식욕 ↑ (특히 고탄수화물)
야식 충동 (밤 11~1시)
```

**수치**: 6일 4시간 제한 시 렙틴 감소폭 = 일일 900kcal 결식 상당

**개인차**: 최근 메타분석은 "불일치"를 지적 → 아래 이유 참고

### 경로 2: 순환 시계 유전자 손상 (렙틴 저항성)

```
만성 수면 부족
  ↓
가설하부(hypothalamus) 순환 시계 유전자 손상
  ↓
렙틴 신호 경로 차단 (JAK2/STAT3 inhibition)
  ↓
렙틴이 많아도 뇌가 "포만" 신호를 못 받음
  ↓
끊임없는 식욕 (악순환 진입)
```

**시간대**: 야간 렙틴 감소가 낮 시간보다 크다 (순환 리듬 파괴)

### 경로 3: 오렉신 과활성화

```
수면 부족 중 각성 유지
  ↓
오렉신 (hypocretin) 과활성화
  ↓
각성 + 식욕 동시 증가
  ↓
깨어있는 시간 = 자동으로 음식 탐색 (호르몬 + 행동)
```

**특이**: 깨어있는 시간 증가 자체가 이미 식욕을 높인다 (칼로리 추적과 별개)

### 경로 4: 인슐린 저항성 & 대사 손상

```
수면 제한 (5일)
  ↓
혈중 인슐린 ↑ (직후 측정)
레지스틴 ↑
  ↓
포도당 처리 효율 ↓
  ↓
혈당 요동 큼 → 더 배고픔 (악순환)
  ↓
체중 증가 + 당뇨 위험 ↑
```

**타이미: 급성**: 5일 제한 직후부터 나타남 / **만성**: 누적 손상

## 칼로리 수지: 왜 깨어있는 시간이 체중증가의 원인?

### 일반적 가정: "깨어있는 시간 증가 = 에너지 소비 ↑"
- 잘못된 가정

### 실제: "깨어있는 시간 증가 + 호르몬 방해 = 에너지 소비 ↑보다 섭취 ↑↑"
- 수면 제한 → 칼로리 과다섭취
- 과다 섭취분 > 추가 에너지 소비분
- **결과**: 체중 증가 + 지방 축적

**마우스 실험**: 수면 제한 후 고지방 식이 제공 → 정상 수면 군보다 피하지방 증가량 ↑ (호르몬 민감화)

## 개인차와 불일치 문제

### 최근 메타분석 (2024)
- "단기 수면 부족에서 렙틴·그렐린 변화가 일관되지 않는다"
- **원인 분석**:
  1. 연구마다 수면 제한 정의 다름 (4시간 vs 5시간 vs 자연적 부족)
  2. 개인 기저 대사율 차이
  3. 단기 vs 만성의 생리적 반응 차이
  4. 성별·연령·체질량지수 층위 미분류
  5. 측정 시간대 (야간 vs 아침 공복)

### 따라서
- **명확한 것**: 만성 수면 부족 + 체중 증가 역학 관계 (역학 데이터)
- **메커니즘**: 호르몬 변화가 일부 설명하지만, 모든 변이를 설명하지는 못함
- **결론**: "렙틴·그렐린이 일부 원인"이지, "전부"는 아님

## 집필자를 위한 포인트

1. **역학 + 기전 이중 구조**: 
   - "수면 부족 → 체중 증가"는 강한 증거
   - 그 기전(호르몬)은 복잡하고 개인차 크다

2. **4가지 경로 모두 포함**: 렙틴·그렐린만 가 아니라 오렉신·인슐린도 설명하면 신뢰도 ↑

3. **악순환 구조**: "수면 부족 → 체중 증가 → 더 나쁜 수면 → 더 큰 체중 증가"

4. **렙틴 저항성**: "렙틴이 많아도 못 듣는 귀" 개념이 핵심 (호르몬 수치만 본 연구의 한계)

5. **소아·청소년 강조**: 성인보다 수면 개선의 효과가 크다 (호르몬 민감화)

6. **통합 중재**: 수면 + 식이 + 운동이 함께 필요 (수면만으로는 체중감량 한계)

## 실제 수치와 조심스러운 표현

| 수치 | 근거 | 표현 |
|-----|------|-----|
| 렙틴 감소폭 = 900kcal 결식 상당 | 6일 4시간 극단 실험 | "극단적 제한일 때 / 약간의 칼로리 감소와는 비교 불가" |
| 그렐린 증가 | 저용량도 증가 관찰 | "특히 저녁 시간에 증가" (순환 리듬) |
| 인슐린 저항성 | 5일 직후부터 | "급성 반응, 만성화되면 더 악화" |
| BMI ↑ | 역학 데이터 | "수면 시간과 역상관" (명확) |

## 주의사항

- **메타분석의 불일치**: "호르몬 변화 불일치"는 실패가 아니라 "기전이 복잡"의 증거
- **마우스 vs 인간**: 동물 모델의 지방 분포는 인간과 다름 (피하 vs 내장지방)
- **성별·호르몬·나이 미분류**: 대부분 연구가 이 층위를 구분하지 않아 모집단 특성 불명확
- **인과성 vs 상관성**: 수면 부족과 비만의 인과성은 명확하지만, 호르몬 경로 일부는 추론
