# 공기청정기 구매가이드 조사 전문
## 구매 결정 시 확인해야 할 7가지 기준

### 1. 필터 등급 — H13이 가정용 표준

**현황**
- 현행 가정용 공기청정기의 90% 이상이 H13 등급 헤파필터를 탑재
- H13은 0.3㎛ 입자를 99.95% 이상 제거
- H14는 0.3㎛ 입자를 99.995% 제거하지만 필터가 매우 촘촘해 풍량이 약해짐

**결론**
- H13으로 충분. H14는 산업·공업용
- H13이 가정용 효율성과 성능의 최적 밸런스
- 구매 시 H13 탑재 여부만 확인하면 충분

### 2. 소음 — 침실 30~35dB, 거실 40dB대

**취침 환경 (침실)**
- 권장: 30~35dB(A)
- 이 범위 초과 시 수면 방해 발생
- 저소음 모드라도 30dB 이상이므로 사양서 확인 필수
- 개인 수면 민감도에 따라 30dB도 방해 가능

**거실 환경**
- 권장: 40dB대 초중반
- 이 범위에서 대화·TV 시청 방해 없음
- 고풍량 운전 시 50dB 이상으로 상승

**한국 기준 CADR-소음 표준**
- 4m³/min 미만: 45dB
- 4~8 범위: 50dB
- 8~16 범위: 55dB
- 16m³/min 이상: 60dB

**결론**
- 침실: 30~35dB 제품 선택
- 거실: 40dB대 제품 후 자동모드 운전
- 사양표 dB 수치는 기준 환경 측정값이므로 실제 가정에서는 체감이 다를 수 있음

### 3. 유지비 — 필터 교체 가격 미리 확인

**정품 필터 가격 (2026년 기준)**
- 삼성: 약 5.5만 원
- LG: 약 6만 원
- 위닉스: 약 6만 원
- 샤오미: 2만 원대 (가장 저렴)
- **브랜드별 최대 2~3배 차이**

**교체 주기**
- 1일 24시간 사용 기준: 6~12개월
- 실제 필터 오염도는 실내 공기 질·사용 시간·오염원에 따라 변동

**연간 유지비 계산**
- 삼성·LG·위닉스: 연간 5~6만 원
- 샤오미: 연간 약 2~3만 원
- 2대 배치 시 비용 배수 증가

**선택 시 주의**
- 초기 구매가 저렴해도 필터 가격 확인 필수
- 온라인 비정품 필터는 정품 대비 절반 이하로 저렴하지만 성능·안전성 보장 없음
- 정품은 제조사 서비스센터 또는 정식 소모품샵에서 구입

**결론**
- 제품 구매 전에 필터 정품 가격·교체 주기 먼저 확인
- 장기 유지비를 계산해 초기 기계값과 함께 평가

### 4. 공간별 선택 — 원룸 vs 거실

**기본 원칙**
- 청정면적 선택 기준: 실제 사용 평수의 1.3~1.5배 추천
- 예: 20평 거실 → 26~30평 청정면적 모델
- 이 기준으로 소음 수준을 합리적으로 유지하면서 청정 효율 극대화

**침실·원룸용**
- 권장 청정면적: 33㎡(약 10평)
- 12평형(약 39.6㎡)도 적절
- 좁은 공간을 빠르고 경제적으로 정화 가능
- 소형이므로 저전력·저소음 모델 다수 존재

**거실용**
- 권장: 20~25평형 이상 대형 모델
- 가족 모두가 머무는 공간이므로 넓은 커버 필요
- 거실과 주방이 연결된 개방형 구조면 더 큰 모델 필요

**30평 이상 넓은 공간**
- 전략: 대형 1대보다 중소형 2대 배치 권장
- 공기 순환 효율이 대형 1대 운전보다 높음
- 개별 방별로 나눠 배치 가능
- **주의**: 필터 교체 비용·관리 부담 배수 증가

**결론**
- 공간 평수 먼저 파악 후 1.3~1.5배 청정면적 모델 검색
- 원룸은 10평 전후 소형, 거실은 20평 이상 대형 기본
- 30평 이상은 2대 배치 경제성 검토

### 5. 전기료 — 소비전력 비교

**24시간 연속 사용 기준**
- 40W 모델: 월간 약 4,320원
- 80W 모델: 월간 약 8,640원
- 기준: 가정용 전기요금 1kWh당 약 250원(기본료 포함, 2026년)
- 실제 전기료는 지역·계절·누진율에 따라 변동

**평균 소비전력 범위**
- 현행 모델: 40~80W 대부분
- 저가형·소형: 40~50W
- 고급형·대형: 60~80W
- 자동모드 운전 시 전력 소비 감소

**결론**
- 월 200시간 기준 운전(일 6시간 이상)이면 전기료 현저히 감소
- 자동모드 사용으로 추가 절감 가능

### 6. 부가기능 주의 — 가습 결합형의 함정

**분리 운영 시 주의**
- 가습기와 공기청정기 동시 사용 위험:
  - 가습 입자가 공기청정기 필터에 닿음 → 필터 젖음 → 세균 번식
  - 실내 습도 상승 → 필터가 수분 흡수 → 성능 저하·곰팡이 생성
  
**필수 거리 유지**
- 최소 1~2m 이상 떨어뜨려 배치
- 실내 습도를 40~60%로 유지
- 가습기 먼저 가동 후 공기청정기 켜거나 시간 분리 사용

**LG 하이드로타워 (2023.11~ 출시)**
- 통합형으로 설계돼 가습·정화 동시 수행 가능
- 구조적으로 필터 보호 설계 반영
- 다만 사용설명서의 가습 기능 방식 확인 필수

**결론**
- 기존 가습기+공기청정기 조합은 분리 운영 필수
- 필터 손상 위험이 크면 가습 기능은 포기하는 것이 낫다
- 통합형 구매는 제조사 설계 확인 후 선택

### 7. 센서·자동모드 신뢰도

**기존 자료에서 이미 확보한 항목**
- 센서 월 1회 이상 청소 필수 (A4 종이 찢는 자가진단)
- 삼성·LG 자가진단 방법 상이
- 센서 오염 시 자동모드 오작동
- 자동모드만 믿으면 센서 오염 놓칠 수 있음

## 구매 체크리스트

1. **필터 등급**: H13 탑재 확인 ✓
2. **소음 수준**: 사용 공간별 dB 확인 (침실 30~35dB / 거실 40dB대)
3. **청정면적**: 실제 평수의 1.3~1.5배 계산
4. **필터 가격**: 정품 가격과 교체 주기 확인 (연간 유지비 계산)
5. **소비전력**: 평균 40~80W 범위 확인
6. **가습 기능**: 필요 없으면 가습기 분리, 필요하면 LG 통합형 검토
7. **센서 청소**: 월 1회 청소 가능 여부 자가진단

---

## 결론

**구매 우선순위**
1. 공간 평수 파악 → 1.3~1.5배 청정면적 결정
2. 필터 정품 가격 확인 → 연간 유지비 계산
3. 사용 공간별 소음 기준 (침실 vs 거실)
4. 통합형 vs 분리형 선택
5. 가전사 A/S 및 필터 구매 편의성 확인

**과대 판매 주의**
- 높은 등급(H14), 없는 기능, 과도한 풍량 모델은 피한다
- H13, 1.5배 청정면적, 40~60W 저전력, 유지비 저렴한 모델이 가성비 좋음
