# 공인중개사 시험 — 보강 조사 (2026-10-27)

## 목적
기존 팩트 4건은 CQ-Net 메인과 Q-Net 메인에만 의존했고, 공고 상세 페이지에 도달하지 못했다. 개별 공식 문서 2개 이상 추가가 목표.

## 열어 본 개별 공식 문서 (실제 열람, 국가법령정보센터 렌더링)
1. https://www.law.go.kr/법령/공인중개사법시행령/제7조 — 시험의 시행·공고. 제2항(매년 2월 말일까지 개략 사항 공고), 제3항(시험시행일 90일 전까지 확정 공고).
2. https://www.law.go.kr/법령/공인중개사법시행령/제5조 — 시험방법. 1·2차 구분, 선택형/논문형 원칙.
3. https://www.law.go.kr/법령/공인중개사법시행규칙/제2조 — 응시원서 별지 제1호서식.
4. https://www.law.go.kr/법령/공인중개사법시행령 — 시행령 전문 목차(시행 2026.08.28, 대통령령 제36590호, 2026.8.18 일부개정) 확인.
5. https://www.law.go.kr/법령/공인중개사법/제6조 — 열었으나 결격사유 조문. 시험 팩트로 쓰지 않음.
6. https://c.q-net.or.kr/ — CQ-Net 메인(과정평가형 포털 성격). 공인중개사 시험 일정 항목 없음. 기존 팩트 참조용.

## 못 연 것 / 실패
- 제38회(2027년) 시험 공고 — 큐넷 공고 페이지 도달 실패, 검색으로도 공식 공고 미발견. 기존 확인실패 팩트 유지.
- 제37회(2026년) 시험 일정 — 블로그 2건이 2026.10.31 시행, 접수 8.3~8.7을 주장. 공식 미확인. 기존 팩트 유지(확인실패).
- 공단 보도자료(hrdkorea.or.kr) 공인중개사 관련 — 목록 열람 시도 HTTP 400, 검색으로도 발견 못 함.
- 큐넷 공인중개사 시험안내 개별 페이지 URL — 검색·메인 링크로 찾지 못함(gId 값 미확인).
- 참고: land-it.co.kr의 「2026년도 국가전문자격 시행일정(안)」 PDF는 민간 사이트 게시물이라 출처 제외.

## 집필 시 주의
- 법령 원문은 개별 조문 URL로 인용한다. 공인중개사 시험 "접수 기간·시험일"은 법령에 없으므로 Q-Net 공고로 안내하고, 이 조사에서 날짜를 확정하지 말 것.
- 출처 3곳 조건 충족용: 시행령 제7조(개별) + 시행령 제5조(개별) + 시행규칙 제2조(개별).
