# 출생신고 (birth-registration)

- 종류: apply / 묶음: 육아·가족 / 조사일: 2026-10-27
- 표제어: 출생신고 · 검색 키워드(후보표): 출생신고 기한 · 근거 힌트: 가족관계등록법, 대법원
- 팩트: `content/research/facts/신청_birth-registration.json` (5건: 확실 5 / 논쟁 0 / 확인실패 0, 공식 5)
- 재사용 0건 / 거부 0건.

## ★ 힌트 정정
- 법령 명칭: 힌트 "가족관계등록법"은 약칭이다. 정식 명칭은 **「가족관계의 등록 등에 관한 법률」**(제44조, 제122조, 제124조). 글에는 정식 명칭을 쓴다.
- 기관: 힌트의 "대법원"은 맞다(정부24 민원안내 '제도를 담당하는 기관: 대법원 가족관계등록과').

## 현행 여부
- 제44조 페이지 헤더 `[시행 2026. 10. 2.] [법률 제21857호, 2026. 8. 4., 타법개정]`. 2026-10-27 기준 현행. 시행 예정 개정 없음.

## 확인 못 한 것
- 정부24 페이지가 2024-07-11 갱신본이라 2026.10.2 시행 법 개정 후 서류 요건 변화 여부는 미확인.
- 온라인 출생신고 "가능 병원" 확대 공지(정부24 ntcItm/54619): 검색 요약만 보고 열지 않음. 팩트화하지 않음.
- 대법원 전자가족관계등록 페이지: scourt 주소가 전자소송포털로 넘어가 열리지 않음. 인터넷 신고 경로는 정부24 안내로만 확인.
- 검색 요약의 "출생일로부터 1개월" 표현은 법문("출생 후")과 다르게 옮겨질 수 있어 법문 표현을 씀.

## 집필 시 주의
1. 기한은 **출생 후 1개월 이내**. 날짜를 세어 "며칠까지"라고 단정하지 말 것.
2. 과태료는 "5만 원 이하"의 상한이다. 실제 부과액을 단정하지 말 것.
3. 신고 기한(1개월)과 처리기간("지체없이")을 섞지 말 것.
