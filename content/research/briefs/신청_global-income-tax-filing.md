## 확인 못 한 것 (확인실패로 남김)

1. **성실신고확인서 제출 기한 6월 30일**: 검색 발췌(블로그 다수)와 "소득세법 제81조의2 가산세" 소개 문장은 있었으나, 법령 본문을 열어 확인하지 못함. 소득세법 제70조 본문에는 6월 30일이 없음. → `income-tax-sincere-filing-deadline-june30` 확인실패, source_url 비움.
2. **모두채움 안내문 발송 시기(5월 1일 등)**: 검색 발췌에만 있음. 국세청 페이지 본문에는 발송 시기 문구 없음. → `income-tax-moducheum-send-date` 확인실패.
3. **기한 후 신고 기간·가산세율(무신고 20% 등)**: 블로그에만 있음. 국세기본법 가산세 조문 미열람. → `income-tax-late-filing-penalty` 확인실패. 글에서 세율 숫자 금지.
4. **모두채움 환급 대상자 안내 본문**: 연결 페이지(mi=41095&cntntsId=239072)는 이번 세션에서 열지 않음.
5. **ARS 신청 번호(1544-9944)의 종합소득세 적용 여부**: 근로·자녀장려금 페이지에서만 확인. 종합소득세에는 적용 여부 미확인이라 팩트에 넣지 않음.
6. **PC 홈택스 권장(금융소득·복식부기·간편장부 사업자)**: 검색 발췌에만 있었고 본문 확인 못 함. 팩트 제외.
7. **2027년 신고 일정**: 공식 공고 여부 미확인(2026-10-26 기준 확인 못 함).
