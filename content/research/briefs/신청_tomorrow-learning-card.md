## 2. 검색 결과에만 있고 열람하지 못한 것

- 검색 2회(카드 한도·자부담, 고용24 공식 안내). 결과는 전부 블로그·커뮤니티. 공식 고용24 카드 안내 본문 URL은 검색으로 찾지 못함.
- 블로그 수치(5년 한도 300만~500만 원, 자부담 0~55%, 일반 15~55%, 디지털 최대 10%, 2026.1.1 특화훈련 자부담 신설)는 전부 원문 미열람. 확인실패로만 기록.
- HRD-Net 연계는 블로그 설명으로만 있음. 열람하지 않음.

## 3. 확인 못 한 것

- 고용24 카드 안내 본문: 지원 한도, 자부담률, 발급 절차, 발급 영업일
- 내일배움카드와 직업능력개발계좌의 명칭 연결(공식 안내에서 확인 못 함)
- 국민평생직업능력개발법 제18조의 현행 개정 여부(표시 시행 2023.7.4 이후)
- 훈련 과정별 국비·자부담 구분 규정

## 4. 집필 시 주의

- 한도 금액과 자부담률은 쓰지 않는다. 독자에게는 고용24 카드 안내 페이지에서 본인 한도와 과정별 자부담을 확인하도록 안내한다.
- 법적 근거는 "국민 평생 직업능력 개발법 제18조(직업능력개발계좌)"까지만 쓴다. 명칭 연결은 고용24 본문 확인 후에 쓴다.
- 메뉴 경로(고용24 메인 '직업 능력 개발' → '국민내일배움카드 훈련과정')는 작성 시점에 다시 열어 확인한다.
