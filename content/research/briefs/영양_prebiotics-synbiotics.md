# 프리바이오틱스·신바이오틱스 조사 전문

**조사일**: 2026-08-10  
**담당**: 콘텐츠 리서처  
**대상 글**: 예정  

## 개요

프리바이오틱스와 신바이오틱스는 다른 개념이며, ISAPP의 최신 정의(2016, 2019)에 따라 명확히 구분된다. 일반 소비자가 혼동하기 쉬운 이 둘의 정의, 작용 기전, 함량 기준, 부작용을 정리한 조사다.

## 핵심 발견사항

### 1. 프리바이오틱스 정의 (ISAPP 2016)

**ISAPP 정의**: "사람의 위산과 소장의 효소에 의해 소화되지 않고 장내 미생물에 의해 선택적으로 분해되어 숙주 미생물의 생장과 활성을 촉진하는 물질"

- **핵심**: 유익 미생물의 기질(먹이)로서의 기능
- **필수 조건**: 선택성(selectivity) — 모든 식이섬유가 프리바이오틱스는 아님
- **예시**: 이눌린(치커리 추출물), 프락토올리고당(FOS), 갈락토올리고당(GOS), 난소화성말토덱스트린, 라피노스

### 2. 프리바이오틱스 일일 섭취량

- **ISAPP 권장**: 3~5g/일
- **한국 식약처**: 프락토올리고당 3~8g/일

### 3. 프리바이오틱스 초기 부작용: 가스·팽만감

**임상 관찰**:
- 초기 복용 시 배에 가스가 차거나 팽만감을 느낄 수 있음
- **원인**: 굶주렸던 유익균이 갑자기 주어진 먹이를 섭취하며 발효 활동을 시작
- **해결 기간**: 1~2주 꾸준한 복용으로 장이 적응하면서 증상 자연 소실

**대응 전략**:
- 초기 용량: 2~3g부터 시작
- 점진적 증량
- 과민성대장증후군(IBS) 보유자 주의 필요

**FODMAP 주의**:
- 이눌린은 포드맵(FODMAP)에 속하는 프락탄 성분
- FODMAP 민감성이 있는 사람은 더 주의가 필요

### 4. 신바이오틱스 정의 (ISAPP 2019)

**ISAPP 정의**: "살아있는 미생물과 기질이 혼합되어 있으며, 그 기질이 숙주 미생물에 의해 선택적으로 이용되어 숙주에게 건강 이익을 주는 제제"

**핵심 특징**:
- 프로바이오틱스 + 프리바이오틱스의 단순 혼합이 아님
- 상호협력적 기능을 전제
- 특정 균주가 해당 기질을 선택적으로 이용할 수 있도록 설계되어야 함

### 5. 신바이오틱스 두 가지 유형 (ISAPP 2019)

#### (1) 보완형 신바이오틱스 (Complementary Synbiotic)

- 프로바이오틱스 + 프리바이오틱스 단순 조합
- 각 성분이 독립적으로 기능
- 기질의 기능성 입증 불필수
- 개발 용이, 진입 장벽 낮음

#### (2) 협력형 신바이오틱스 (Synergistic Synbiotic)

- 기질이 동시투여 미생물에 의해 선택적으로 이용되도록 설계
- 협력 기능을 입증하는 임상 근거 필수
- 개발 난이도 높음, 비용 높음
- 과학적 혁신 가능성 높음

## 마케팅 구분점

### 상품 표기 읽는 법

- **"프리바이오틱스"만 표기**: 기질 제공 역할만
- **"신바이오틱스"로 표기**: 프로바이오틱스 + 프리바이오틱스 복합 제품
  - 보완형인지 협력형인지 확인 필요
  - 협력형이면 임상 근거 확인 필수

## 다음 집필 시 주의사항

1. **표현의 정확성**: "프리바이오틱스 = 프로바이오틱스의 먹이" 과단순화 금지
2. **부작용 표현**: 가스·팽만감을 "부작용"이라 하지 말고 "초기 적응 증상"으로 표현
3. **용량 근거 명시**: "3~8g"이라 쓸 때 "식약처 고시"임을 표기
4. **신바이오틱스 주의**: 모든 프로바이오틱스 + 프리바이오틱스 조합이 신바이오틱스는 아님
