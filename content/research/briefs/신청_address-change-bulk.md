# 이사 시 주소 일괄변경 — 조사 브리프 (2026-10-27)

## 조사 범위
전입신고 기한, 전입신고가 다른 법령 신고를 대신하는 범위(법정 간주), 미이행 시 과태료, 정부24 원클릭·원스톱 등 일괄변경 서비스의 실제 범위, 민간 기관 주소 처리.

## 열어서 확인한 페이지 (이 세션, 렌더링)
- https://www.law.go.kr/법령/주민등록법/제16조 : 제1항 전입신고 14일 이내 확인. 기존 팩트 `move-in-report-14day-deadline`와 일치 → 재사용.
- https://www.law.go.kr/법령/주민등록법/제17조 : 전입신고가 있으면 병역법·민방위기본법·인감증명법·국민기초생활 보장법·국민건강보험법·장애인복지법에 따른 전출·전입신고를 한 것으로 본다. 시행 2025.7.22 표시본.
- https://www.law.go.kr/법령/주민등록법/제40조 : 제4항 신고 기간 내 미이행 시 5만 원 이하 과태료(정당한 사유 없으면), 제5항 시장·군수·구청장 부과·징수.

## 검색으로만 본 것 (전부 블로그·이사업체, 공식 아님)
- "정부24 전입신고 시 공공기관 주소 자동 연계(주민센터·세무·건강보험 등)", "주소변경 원클릭", "원스톱" 명칭 다수.
- 우편물 전입지 전송 서비스 항목이 전입신고 마지막 단계에 있고 세대주만 신청 가능, 동일 권역 3개월 수수료 면제 등 — 전부 블로그 주장.
- 은행·카드·통신·보험·학교·직장·쇼핑몰은 자동 변경 제외 — 블로그 다수 주장.
- 온라인 전입신고는 본인만, 미성년자·외국인은 방문 — 블로그 주장(확인 못 함).

## 기존 팩트 재사용·거부
- 재사용: `move-in-report-14day-deadline`.
- 거부 없음.

## 확인 못 한 것
- 정부24 원클릭·원스톱 서비스의 공식 메뉴명, 자동 반영 기관 목록, 동의 절차 (확인실패 `address-bulk-onestop-auto-unverified`).
- 민간 기관 주소 일괄 변경 공식 근거 (확인실패 `address-bulk-private-manual-blog`).
- 우편물 전입지 전송 대상과 수수료 (확인실패 `address-bulk-postal-forward-unverified`).
- 정부24 온라인 전입신고 가능 여부(기존 팩트 `move-in-report-online-channel`도 확인실패 상태).

## 집필 시 주의
- 법정 간주 범위(제17조)는 확정 사실로 쓰되, 은행·카드 등 민간 기관이 자동 반영된다는 식으로 넓히지 않는다.
- "전입신고 후 공공기관 연계"는 신청 화면의 동의 항목을 직접 확인하라는 안내로 쓴다. 목록을 나열하지 않는다.
- 과태료는 "5만 원 이하"로 쓴다. "5만 원 부과"로 확정하지 않는다.
- 주소만 바뀐 경우 주민등록증 재발급 대상이 아니라는 내용은 `id-card-reissue-address-not-listed`를 참조해 쓴다.
