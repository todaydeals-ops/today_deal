# 운전면허 시험 접수 — 조사 브리프

- 주제: 운전면허 시험 접수 (학과·기능·도로주행), 응시 자격, 수수료, 준비물, 접수 경로
- 조사일: 2026-10-27 (지시문 기준일)
- 대상 키워드: 운전면허 시험 접수, 운전면허 시험 신청 (wave/candidates.txt 표제어 기준)
- 팩트: `content/research/facts/신청_driver-license-test.json` (19건)

## 1. 기존 저장소 확인
- `facts/` 내 운전면허 관련 파일은 `신청_driver-license-renewal.json`(갱신 주제)만 있었다. 갱신 조문(제87조)은 시험 주제와 무관해 `declined_facts`로 남겼다.
- `신청_csat-application.json`, `신청_mobile-id.json`에서 운전면허 언급은 있었으나 시험 주제와 직접 겹치지 않아 재사용하지 않았다.

## 3. 법령 현행 여부
- law.go.kr 도로교통법 화면은 "시행 2027.4.14 · 법률 제22067호 · 2026.10.13 일부개정"으로 표시된다. 2027년 4월 이전 적용 본문과 같은지 확정하지 못했다. 응시 조문(제80·81·82조)의 개정 표기에는 2026년 개정이 없어 본문이 같다고 판단했다. 이 판단은 caution에 명시했다.

## 4. 확인 못 한 것 (글에 확정 표현 금지)
- **구형 시험장 금액 상충**: 검색 요약에 "도로주행 25,000원, 학과 7,500원" 같은 구형 금액이 있었으나 해당 페이지를 열지 못했다. 공단 현행 페이지 금액만 썼다(`driver-license-test-fee-old-venue-unverified`, 확인실패).
- **연습면허 기한 연결**: "연습면허 유효기간 안에 도로주행 합격" 문장은 검색 요약에만 있었다. 공단 페이지 본문으로 확인하지 못해 팩트에 넣지 않았다.
- **학과시험 접수 기준 날짜**: 1년 기한의 기산 기준을 응시원서 접수일로 보는 판단은 페이지 문구에서 추정이다. caution에 그렇게 적었다.
- **온라인 예약 가능 시험**: 학과시험은 인터넷 예약 불가, 기능·도로주행은 가능으로 준비물 가이드에 적혀 있다. 학과시험의 "PC학과시험(비문해자·청각장애인)" 세부 절차는 확인하지 않았다.
- **사진 규격·신분증 범위**: 별도 페이지(허용 사진 규격, 신분증 인정 범위)를 열지 않았다. 글에서는 그 페이지 확인을 안내한다.

## 5. 검색 사용
- 웹 검색 2회 (일반 1회, 공단 도메인 제한 1회). 검색 결과 링크는 열어서 확인한 것만 팩트에 넣었다.

## 6. 집필 시 주의 (2줄)
1. 금액(학과 10,000원, 기능 25,000원·14,000원·10,000원, 도로주행 30,000원, 신체검사 8,000원·7,000원)은 공단 페이지 기준이며 연도 표기가 없다. 글 상단에 "2026년 10월 27일 확인 기준"을 명시한다.
2. 학과시험은 인터넷 예약이 안 된다. "인터넷으로 접수"를 시험 전체에 일괄 적용하지 말고, 기능·도로주행만 인터넷 접수 가능으로 나눠 쓴다.
