## 1. 저장소 확인 (0단계)

- facts 전수 Grep: LG 김치냉장고 전용 팩트는 없었다. 관련 파일은 `lg_fridge-error-code.json`(LG 일반 냉장고), `winia_kimchi-fridge-selfcheck.json`(위니아 딤채), `samsung_kimchi-fridge-selfcheck.json`(삼성 김치플러스), `공통_as-safety-baseline.json`(공통 안전 기준선).
- 재사용 0건, 거부 6건. 거부 사유는 JSON의 `declined_facts`에 기록했다.
  - 일반 냉장고 에러코드 목록과 설치 간격 수치는 김치냉장고 공식 페이지와 칸 구성·코드 체계가 달라 옮기지 않았다.
  - 냉매 원칙(공통 안전 기준선)은 scope가 에어컨이라, 김치 페이지에서 직접 확인한 문장을 새 팩트로 두고 cautionSource로만 인용했다.
  - 삼성·위니아 팩트는 코드 체계가 달라 거부했다.

## 2. 힌트와 달랐던 점

- 주제 힌트의 "김치톡톡" 모델명은 LG 공식 자료에서 확인하지 못했다. 공식 페이지 3~4곳과 검색 결과에 해당 명칭이 나오지 않았다. 그래서 `lg-kimchi-model-name-kimchitoktok-unverified`(확인실패)로 남겼다. 글에서는 "김치톡톡 전용 코드"라고 단정하지 말고, 본인 모델명을 제품 뒷면·설명서에서 확인하도록 쓴다.
- 힌트의 "냉각 불량" 범위는 공식 페이지에서 CH·CL(냉각 성능 부족·내부 온도 이상)과 CF·FF·UF·LF·rF(팬 모터), dH·H1·H2(제상 불량)로 나뉜다. 세 축을 모두 팩트로 넣었다.
- 칸 위치 표기가 공식 페이지마다 다르다(FF를 중칸·상칸·냉동실로 적는 식). 칸 이름 대신 "표시창에 뜬 코드와 덜 닫힌 문"으로 안내하도록 `lg-kimchi-ff-lf-position-conflict`(논쟁)로 남겼다.
- LF·rF 검색 결과 요약에는 "8시간 이상 해동"이 있었으나, 원문을 열어 보니 "최소 24시간 이상"이었다. 8시간 기준은 쓰지 않는다.

## 4. 공통 안전 원칙

- 냉매 충전·보충은 자격 있는 기사만 한다는 원칙은 `공통_as-safety-baseline.json`의 `refrigerant-charge-professional-only`를 따른다. LG 김치 CH·CL 페이지도 냉매 부족·누출을 원인으로 든다. 따라서 가스 보충을 독자에게 권하지 않고 서비스 접수로 넘긴다.
- 성에 제거 시 뾰족한 칼·송곳 금지, 열기구(헤어드라이어) 금지는 공식 페이지 원문을 그대로 근거로 쓴다.

## 5. 집필 가이드(참고)

- 독자는 "김치냉장고가 안 시원하다", "에러가 떴다"로 검색해 들어온다. 순서는 보관 기능 확인 → 문 밀착·성에 확인 → 팬 에러면 24시간 해동 → CH·CL면 문 확인과 5분 전원 분리 → 여기까지 해봐도 안 되면 고객센터 1544-7777 또는 출장 서비스 예약 순으로 쓴다.
- 보증 기간 수치는 확인하지 못했으므로 쓰지 않는다.
