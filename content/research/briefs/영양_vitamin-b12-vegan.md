# 채식인의 비타민B12 섭취 조사 전문

## 조사 목표
- 비타민B12 흡수의 생화학적 기전
- 채식인의 결핍 위험과 진단 기준
- 강화식품 vs 미신적 식품 출처 구분
- 보충 전략 (강화식품, 보충제, 타이밍)

## 핵심 발견사항

### 1. B12 흡수 기전: 내재인자의 핵심 역할

**정상 흡수 경로**
```
음식의 B12 (단백질 결합)
    ↓
위: 내재인자(IF, parietal cell) 분비 + 음식 단백질 분해
    ↓
B12 ← 결합 → Haptocorin(HC)
    ↓
십이지장: 췌장 단백분해효소가 HC 분해
    ↓
B12 ← 새로 결합 → 내재인자(IF)
    ↓
소장 말단부(terminal ileum): cubam 수용체를 통한 내포작용
    ↓
혈중 B12 상승
```

**핵심 포인트**
- 내재인자가 없으면 → 음식 B12도, 보충제 B12도 흡수 안 됨
- 원인: 악성빈혈(자가면역), 위절제, 위축성 위염
- 대안: 주사 B12 또는 고용량 경구 보충

### 3. B12 유사물질(아날로그)의 함정

**스피룰리나의 진실**
- 측정 B12의 80% = 유사 B12(pseudovitamin B12)
- 실제 바이오이용률: 거의 0%
- 위험: 실제 B12와 경쟁하여 **흡수를 방해**

**발효식품의 함정**
- 템페, 김치, 사우어크라우트: B12 아날로그 함유
- 이들이 실제 B12의 흡수를 **차단**할 수 있음
- "발효 음식에 B12가 있다"는 마케팅 ≠ 실제 효과

### 4. 채식인의 실용적 B12 전략

**옵션 1: 강화식품 조합**
- 최소 2~3가지 강화식품을 **하루에 4시간 이상 간격으로** 섭취
- 예: 아침 강화 시리얼 + 점심 강화 음료 + 저녁 강화 영양효모
- 장점: 자연스러운 식사
- 단점: 매일 규칙적 섭취 필요, 흡수 불규칙

**옵션 2: 보충제 (권장)**
- 경구 보충제: 시아노코발라민(cyanocobalamin), 메틸코발라민 모두 효과
- 용량: 2.4mcg/일 (RDA) 이상
- 주기: 주 1~2회 고용량 또는 일일 저용량
- 장점: 흡수 효율 높음, 간편
- 비용: 시아노코발라민이 더 저렴

### 5. B12 결핍 진단 및 모니터링

**진단 지표 (기존 자료 재사용)**
- 혈청 B12: 정상 200~900 pg/mL
- 낮은 수치 + 신경 증상 → 메틸말론산(MMA) 추가 측정 (생리적 활성도 평가)

**채식인 권장 모니터링**
- **최소 연 1회** 혈중 B12 수치 확인
- 신경 증상(손발 저림, 어지러움, 인지 변화) 시 **즉시 의료 전문가 상담**
- 이유: 신경 손상은 돌이킬 수 없음

### 6. 보충제 형태 비교

**시아노코발라민 vs 메틸코발라민**
| 구분 | 시아노 | 메틸 |
|---|---|---|
| **효과** | 동등 | 동등 |
| **가격** | 저 (추천) | 고 |
| **임상 근거** | 높음 | 중간 |
| **바이오이용률** | 50~60% | 50~60% |

**결론**: 건강한 채식인에게는 **시아노코발라민이 비용-효과 최고**

## 집필 기준

### DO
✓ 강화식품과 미신 출처를 명확히 구분
✓ 내재인자 역할 간단히 설명
✓ 스피룰리나·발효식품의 바이오이용률 수치 제시
✓ 4시간 간격 복용의 중요성 강조
✓ 신경 증상 경고 명시

### DON'T
✗ "스피룰리나에 B12가 있다" (미신)
✗ "발효식품으로 충분하다" (미신)
✗ "활성형이 훨씬 낫다" (근거 부족)
✗ 신경 증상 무시·미루기 제시

## 핵심 메시지
> 채식인의 B12 결핍은 현실적 위험이다. 스피룰리나·발효식품은 **미신**이며, **강화식품**과 **보충제**만 신뢰할 수 있다. 하루에 여러 강화식품을 4시간 간격으로 섭취하거나, 보충제(시아노코발라민 권장)를 규칙적으로 복용해야 한다. 신경 증상이 나타나면 즉시 의료 전문가에게 상담받을 것.
