## 0. 저장소 대조 (웹 검색 전)

- `facts/samsung_tv-error.json`: 리모컨 관련 팩트 다수. 페어링 연식표(`tv-remote-pairing-model-year`)는 공식 원문 재확인 후 재사용.
- `facts/samsung_tv-error.json`의 `tv-remote-battery-check`, `tv-power-led-indicator-check`, `tv-cold-boot-restart`는 source_url(40598)을 재열람했을 때 해당 내용이 없었다. 재사용하지 않고 새 출처로 다시 확보했다. disputes 3건 신고.
- `facts/공통_as-safety-baseline.json`: `battery-swelling-stop-immediately`(리튬 배터리 부풀음 시 사용 중단)를 재사용.
- `facts/공통_tv-streaming-app-selfcheck.json`의 `streaming-remote-button-not-working`은 "배터리 확인 → 페어링 재시도" 순서로 방향은 맞으나, 본 조사에서 새로 확인한 페이지와 다르지 않으므로 중복 재사용하지 않았다(이번 글 본문에서 교차 참조 가능).

## 1. 힌트와 달랐던 점

- 총괄 힌트의 "페어링 재설정"은 실제로 **연식별 버튼 조합 + 시간**(2016~2025년형 기준 5초 이상)이 공식 페이지에 있었다.
- 같은 삼성 공식 도메인 안에서도 페어링 시간이 **5초(25844)** 와 **3초(1484964·118823)** 로 엇갈렸다. `논쟁`으로 등급을 두고 "3초로 안 되면 5초"로 순차 대안을 줬다.
- 콜드 부팅은 기존 팩트(30초 코드 분리)와 공식 1014650(60초, 2017년 이전·더 프레임)이 달랐다. 공식을 따랐다.
- "SmartThings 리모컨 등록 조건·네트워크 요건"은 검색 요약에만 있었고 원문에서는 확인하지 못했다. 팩트로 올리지 않았다.
- 리모컨 단품 무상수리 기준은 공식 페이지에서 확인하지 못했다(`확인실패`).

## 3. 집필 시 권장 흐름 (근거 있는 순서)

1. 증상 구분: LED 상태(1484964) → 꺼짐이면 블루투스 정상, 두 번 깜박이면 재연결 필요.
2. 배터리: 새 건전지 극성 확인, USB-C·태양광 충전(1484964). 잔량 메뉴(설정 → 전체 설정 → 일반 및 개인정보 → 리모컨 배터리 잔량).
3. 신호 확인: 스마트폰 카메라 적외선 점검(118823). 빛이 안 보이면 리모컨 불량 쪽으로 판단.
4. 페어링: 2016~2025년형은 복귀 + 재생/일시정지, 3초 시도 후 안 되면 5초(25844·1484964, 논쟁). 2015·2014·2013년형 조합은 `tv-remote-pairing-model-year` 참조.
5. 콜드 부팅: 일반 모델은 리모컨 전원 버튼 5초, 2017년 이전·더 프레임은 케이블 분리 60초(1014650).
6. 임시 대체: SmartThings 앱 모바일 리모컨(1582997). 위치 제약이 있을 수 있다는 안내 포함.
7. 막힘: 출장 접수. 보증 1년 내 성능·기능상 하자는 무상수리. 사용법·설치 요청은 별도 요금(1014650·118823 공통 문구).

## 4. 안전

- 리튬 배터리(충전식 리모컨 포함)가 부풀거나 과열되면 사용을 멈춘다. 누르거나 뚫지 않는다(`battery-swelling-stop-immediately`, Apple 지원 문서 근거를 공통 기준선에서 재사용).
- 리모컨을 임의로 분해하지 않는다. 단품 AS 기준은 확인하지 못했으므로 고객센터 확인 후 접수한다.

## 5. 검색 이력

- 웹 검색 4회, 페이지 열람(WebFetch) 7회.
- 열람 실패·요약 불일치: 25844의 2015년형 배터리 확인 방법, 1014650의 특정 모델 메뉴명은 원문에 명시가 없었다.
