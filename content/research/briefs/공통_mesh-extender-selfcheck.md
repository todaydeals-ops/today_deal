# 메시·증폭기 설치 최적화 및 성능 저하 원인 진단

## 조사 목표
메시 네트워크 또는 와이파이 증폭기가 오히려 성능을 저해하는 원인과 최적 배치 방법 파악

## 조사 결과

### 배치 최적화
- **메인 공유기**: 집 중앙(거실)에 설치
- **서브 공우기/증폭기**: 메인과 중간 거리에 배치
- **거리 기준**: 너무 가깝지도(간섭), 멀지도(신호 약함) 않아야 함

### 토폴로지 선택
- **성형(권장)**: 모든 서브가 메인에 직접 연결 → 홉 수 적음
- **체인형(비권장)**: 공유기들이 일렬로 연결 → 마지막 성능 저하

### 백홀 방식 선택
- **유선 백홀(권장)**: 메인-서브를 랜선으로 연결 → 최고 성능
- **무선 백홀(차선)**: 와이파이로만 연결 → 한 대역이 백홀 전용으로 할당되어 대역폭 손실

### 대역 분리
- **2.4GHz**: IoT 기기 (지원 확대)
- **5GHz**: 모바일 기기 (고속)
- **효과**: 각 기기가 최적 대역을 선택 가능

## 소스
- 메시 네트워크 구성 커뮤니티
- TP-Link 공식 메시 지원 페이지
- 메시 네트워크 성능 최적화 가이드

## 주의점
- 무선 백홀은 대역폭 손실이 크므로 회선 설치가 가능하면 유선 사용
- IoT 기기가 5GHz를 지원하지 않으면 2.4GHz도 활성화해야 함
