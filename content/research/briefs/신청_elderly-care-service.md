- 기준일: 2026-10-27 / 웹 검색 2회(주제 전용) 사용

## ★현행 여부 — 체계 개편 확인됨
- 힌트의 "노인맞춤돌봄서비스 신청(지자체 수행기관 직접 신청)"은 2026년 현행 체계와 맞지 않는다.
- 보건복지부 「지역사회 통합돌봄 이용안내」(https://www.mohw.go.kr/menu.es?mid=a60200000000)에서 확인한 구조:
  - 신청 창구: 신청자 주소지 읍면동 행정복지센터, 국민건강보험공단 지사 (방문·우편·팩스)
  - 흐름: 신청 → 사전조사 → 통합판정조사(또는 지자체 자체조사) → 개인별 지원계획 → 통합지원회의 → 서비스 제공 → 모니터링 → 종결
  - 노인맞춤돌봄은 '대부분의 연계 서비스'의 서비스 예시로 나오며, 연계방법은 "시군구 사업부서 또는 국민건강보험공단 지사로 의뢰"
- 법적 근거: 노인복지법 제23조의3은 2023.10.31 개정으로 삭제됨(https://www.law.go.kr/법령/노인복지법/제23조의3, 2026.10.02 시행 표기에서도 '삭제'). 현행 근거 조문은 이번에 확인하지 못했다.

## 확인 못 한 것 (확인실패로 남김)
- 2026년 대상 연령·소득 기준, 서비스 내용: 공식 원문 미확인. 블로그 요약("65세 이상 기초생활수급자·차상위·기초연금 수급 독거 어르신")은 공식이 아니므로 자격으로 단정 금지.
- "퇴원환자 돌봄군 신설 / 월 최대 44시간 / 3월 신설": 블로그에서만 나옴. 공식 미확인.
- 통합돌봄 근거법명('의료·요양 등 지역 돌봄의 통합지원에 관한 법률')과 "2026.03.27 전면 시행": 법령 검색 페이지는 본문 미표시. 블로그 보도에서만 확인. 날짜는 쓰지 말 것.
- 참고로 보건복지부 통합돌봄 누리집 메인에는 "지역사회 통합돌봄 시행 100일" 보도자료(2026.07.14) 목록이 있다(메인 목록 기준, 개별 페이지 미열람). 이것이 시행 시점을 간접 뒷받침하지만 정확한 시행일은 아니다.

## 출처 현황
- 개별 공식 문서 2곳 충족: (1) 보건복지부 이용안내 메뉴 페이지, (2) 국가법령정보센터 노인복지법 제23조의3 조문.
- 메인 루트(https://www.mohw.go.kr/integratedcare)는 출처로 쓰지 않음.
- 법령 검색 결과 페이지(lsSc.do)는 본문이 안 열려 출처로 쓰지 않음(확인실패 팩트의 근거 주소로만 기록).

## 막힌 것
- 복지로 노인맞춤돌봄 중앙 안내 페이지는 찾지 못했다(검색 결과에 블로그만 나옴). 다음 조사에서 복지로 중앙부처 서비스 상세 페이지를 찾아 대상·소득 기준을 확인해야 한다.

## 집필 시 주의 (2줄)
1. 신청은 "지자체 노인맞춤돌봄 직접 신청"이 아니라 "통합돌봄 신청창구(읍면동 행정복지센터·건강보험공단 지사) → 판정 → 연계"로 쓸 것. 노인복지법 제23조의3은 삭제 조문이므로 근거로 인용하지 말 것.
2. 대상 연령·소득·서비스 시간·퇴원환자 수치는 공식 확인 전까지 글에 쓰지 말고, "자격은 시군구 담당 부서나 복지로에서 확인하라"로 안내할 것.
