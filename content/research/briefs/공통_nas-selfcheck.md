# NAS(시놀로지·QNAP 등) 접속 안 됨·인식 불량·느림 자가점검

조사 주제: NAS 본체 접속 및 성능 자가진단 가이드
조사일: 2026-07-28
주 대상: Synology(시놀로지)와 범용 NAS 절차

---

## 1. NAS를 찾을 수 없을 때 (IP 주소 미확인)

### 1.1 Synology Assistant 사용 (가장 권장)
**공식 출처:** Synology 다운로드 센터  
Synology가 제공하는 무료 데스크톱 유틸리티인 Synology Assistant를 사용하면 로컬 네트워크에서 NAS 기기를 자동으로 검색하고 IP 주소·모델명·DSM 버전을 확인할 수 있다. Windows·macOS·Linux 모두 지원.

**절차:**
1. Synology 공식 웹사이트 다운로드 센터 → Utilities → Synology Assistant 다운로드
2. 설치 후 실행
3. 로컬 네트워크의 모든 Synology 기기가 자동으로 나열됨
4. 해당 NAS의 IP 주소 확인 후 DSM Manager 버튼으로 웹 인터페이스 접속

**주의:** Synology Assistant가 작동하지 않으면 다른 방법(아래 1.2)을 시도.

### 1.2 find.synology.com 웹사이트 사용
**공식 출처:** Synology 공식  
웹 브라우저에서 find.synology.com에 접속하면 브라우저 기반으로 로컬 네트워크의 Synology NAS를 검색할 수 있다. 보통 몇 초 이내에 결과가 표시된다.

**절차:**
1. 인터넷 브라우저 열기
2. find.synology.com 접속
3. 로컬 네트워크 검색 시작 (자동)
4. 발견된 NAS 선택 후 IP 주소 확인

### 1.3 라우터 관리자 페이지에서 확인
공유기의 관리자 페이지(예: 192.168.1.1)에 접속하여 연결된 기기 목록에서 NAS 기기명으로 검색. IP 주소를 직접 확인할 수 있다. 단, 공유기마다 UI가 다르므로 제조사 설명서 참조.

## 2. NAS 웹 인터페이스(DSM) 접속 안 될 때

### 2.1 기본 포트 확인
**공식 출처:** Synology DSM 설정 문서

Synology NAS의 기본 웹 인터페이스 포트:
- **HTTP (비보안):** 5000
- **HTTPS (보안):** 5001

예: http://192.168.1.100:5000 또는 https://192.168.1.100:5001

**절차:**
1. NAS의 IP 주소 확인 (위의 1.1~1.3)
2. 웹 브라우저에서 http://[NAS-IP]:5000 또는 https://[NAS-IP]:5001 입력
3. DSM 로그인 화면이 나타나는지 확인

### 2.2 브라우저 보안 경고 무시 (정상 현상)
**공식 출처:** Synology KB, DSM 보안 설정

HTTPS 포트(5001)로 접속할 때 브라우저에 "연결이 안전하지 않습니다" 또는 "인증서 경고"가 나타나는 것은 정상이다. IP 주소로 직접 접속할 때 발생하는 현상으로, SSL/TLS 인증서가 도메인명을 기준으로 발급되기 때문이다.

**해결:**
- 경고 창에서 "계속 진행" 또는 "예외 추가" 선택
- 도메인명을 할당하거나 자가 서명 인증서를 설정하면 경고 없음 (고급 설정)

### 2.3 포트가 변경되었을 가능성
Synology NAS의 포트는 수동으로 변경할 수 있다. 접속 포트를 변경했다면 새로운 포트 번호로 접속해야 한다.

**확인 방법:**
- Synology Assistant에서 해당 NAS 정보 확인 → 포트 번호 표시됨
- 변경된 포트 번호를 잊었다면 하드 리셋 필요 (모든 설정 초기화)

### 2.4 NAS의 네트워크 연결 확인
- 이더넷 케이블(랜선)이 NAS와 공유기에 제대로 연결되어 있는지 육안 확인
- NAS 전면의 네트워크 LED가 켜져 있는지 확인 (보통 녹색 또는 주황색)
- 공유기의 해당 포트 LED 상태 확인 (연결 중일 때 깜빡거림)

## 3. QuickConnect로 외부에서 접속하려고 할 때

### 3.1 QuickConnect란?
**공식 출처:** Synology 지식 센터

QuickConnect는 Synology가 제공하는 클라우드 기반 원격 접속 서비스로, 포트포워딩이나 DDNS 설정 없이 인터넷 어디서나 NAS에 접속할 수 있다. Synology 계정 기반이며 HTTPS/SSL 암호화를 통해 보안을 제공한다.

**주소 형식:** quickconnect.to/{사용자지정-아이디}

### 3.2 QuickConnect 활성화
**공식 출처:** Synology 지식 센터

**절차:**
1. NAS 웹 인터페이스(DSM) 접속
2. 메인 메뉴 → 제어판 → 외부 접근 → QuickConnect
3. "QuickConnect 활성화" 선택
4. Synology 계정으로 로그인
5. 커스텀 ID 설정 (예: mynas123)
6. 활성화 완료 후 quickconnect.to/mynas123으로 접속 가능

**주의:** 정품 등록이 필요할 수 있다.

### 3.3 QuickConnect 안 될 때
- 공유기가 UPnP를 차단하고 있지 않은지 확인
- NAS의 인터넷 연결 상태 확인 (공유기를 통한 인터넷 연결 필수)
- Synology 계정 정보가 맞는지 다시 확인
- DSM 재시작 후 재시도

---

## 4. DDNS/포트포워딩으로 외부 접속할 때 (수동 설정)

QuickConnect가 작동하지 않을 때 대안으로 포트포워딩과 DDNS를 수동으로 설정하는 방법이 있다. 다만 이 과정은 고급 설정이므로:

1. **공유기에서 NAS의 포트(5000 또는 5001)를 포트포워딩 설정**
2. **공유기 또는 Synology NAS에서 DDNS 활성화** (예: Synology의 DDNS 서비스 이용)
3. **DDNS 주소로 외부에서 접속**

세부 절차는 공유기·NAS 제조사별로 다르므로 각각의 설명서 참조 권장. QuickConnect가 더 간단하므로 QuickConnect 해결을 우선할 것.

## 5. NAS가 켜져 있는데 반응이 없을 때

### 5.1 전원 및 LED 상태 확인
- NAS 전면부 전원 LED가 켜져 있는지 확인 (보통 파란색 또는 초록색)
- 꺼져 있으면 전원 케이블 재확인 → 전원 스위치 ON
- 깜빡거리면 부팅 중일 수 있으니 1~2분 대기

### 5.2 하드 리셋 (초기화)
모든 방법을 시도했으나 접속 불가능한 경우 NAS를 초기화할 수 있다. 하드 리셋은 모든 설정을 공장 초기 상태로 되돌린다.

**주의:** 데이터는 유지되지만 네트워크 설정·사용자 계정·앱 설정 등이 모두 삭제됨.

**절차:**
1. NAS 전원이 켜진 상태에서
2. 전면부의 작은 리셋 홀(Reset)을 클립이나 핀으로 10초 이상 누르기
3. NAS가 재부팅될 때까지 대기
4. 재부팅 완료 후 Synology Assistant로 재검색

## 6. NAS가 인식되지만 일부 하드드라이브가 보이지 않을 때

### 6.1 하드드라이브 상태 확인
**공식 출처:** Synology 지식 센터 - "Synology NAS가 설치된 드라이브를 인식하지 못할 경우"

NAS 웹 인터페이스 → 저장소 관리자에서:
- 각 드라이브의 상태 확인 (정상·오류·미인식 등)
- 슬롯별로 드라이브가 인식되는지 확인

### 6.2 하드드라이브 재장착
1. NAS 전원 끄기
2. 케이스 열기 (또는 핫스왑 드라이브면 그냥 슬롯에서 뺐다 재삽입)
3. 해당 하드드라이브를 슬롯에서 완전히 빼기
4. 드라이브의 금속 핀 부분을 살짝 닦기 (먼지·산화 제거)
5. 슬롯에 다시 정확하게 끝까지 삽입
6. NAS 전원 켜기
7. DSM에서 드라이브 인식 확인 (약 1분 소요)

### 6.3 드라이브 교체
고장난 드라이브는 교체해야 한다. **RAID 구성인 경우, 고장난 드라이브를 제거하고 새 드라이브를 설치한 후 복구 절차를 거쳐야 한다.**

**주의:** 복구 중에 다른 드라이브에서도 오류가 발견되면 복구가 중단되고 볼륨이 읽기 전용이 되므로, 이런 경우 데이터 백업 후 스토리지 풀을 새로 구성해야 한다. **이 상황에서는 전문가 상담을 권장한다.**

### 6.4 데이터 손실 위험 (⚠️ 중대 경고)
**공식 출처:** Synology KB - "더 이상 액세스할 수 없는 Synology NAS에서 데이터를 검색하는 방법"

- **RAID 구성인 NAS에서 2개 이상의 드라이브가 동시에 고장나면 데이터 손실 위험**
- 복구 중에 새로운 오류가 발생하면 볼륨이 손상되어 복구 불가능할 수 있음
- 고장 신호(드라이브 오류 경고·비프음·접근 불가)가 나타나면 즉시 A/S 신청 권장
- 직접 드라이브를 임의로 제거·재정렬하면 데이터 손실 위험 증가

## 7. RAID 볼륨이 손상되었을 때

### 7.1 RAID 상태 확인
저장소 관리자에서 스토리지 풀·볼륨 상태를 확인:
- **정상(Normal):** 아무 문제 없음
- **저하됨(Degraded):** 1개 드라이브 고장, 복구 필요
- **손상됨(Damaged)/액세스 불가:** 2개 이상 드라이브 고장 또는 메타데이터 손상

### 7.2 RAID 복구 절차
고장난 드라이브를 교체한 후 DSM의 저장소 관리자에서 "복구" 버튼 클릭. 복구 시간은 드라이브 용량·드라이브 개수에 따라 수 시간~수 일이 걸릴 수 있다.

**주의:** 
- **복구 중에는 NAS에 과부하를 주지 말 것** (많은 데이터 접근 피하기)
- **복구 중에 다른 드라이브에서 오류 발생 시 데이터 손실 위험**
- 불안하면 복구 중단 후 전문가 데이터 복구 서비스 문의

### 7.3 데이터 손실 경고 (⚠️ 절대 주의)
**공식 출처:** Synology KB

- **포맷 버튼을 누르면 해당 볼륨의 모든 데이터가 영구 삭제됨**
- 복구 불가능한 상태에서만 포맷하도록 (데이터 복구 전문가 상담 후)
- 불확실할 때는 절대 포맷하지 말 것

## 8. 파일 전송 속도가 느릴 때

### 8.1 속도 저하의 주요 원인
**공식 출처:** Synology KB - "데이터 전송 속도가 낮을 때"

1. **하드드라이브 배드섹터:** 드라이브에 손상된 영역이 있으면 해당 파일 접근 시 속도가 급격히 떨어짐
2. **네트워크 연결 상태:** 이더넷 포트 접촉 불량·낮은 신호 강도
3. **RAID 구성:** RAID 5 또는 RAID 6은 단일 드라이브보다 쓰기 성능이 낮음 (계산 오버헤드)
4. **공유기 또는 라우터 문제:** 대역폭 제한·채널 혼잡

### 8.2 기본 점검
- 랜선이 양쪽 끝 모두 완전히 연결되었는지 확인
- 이더넷 포트 재연결 (랜선 분리 후 2초 대기 후 재삽입)
- NAS와 컴퓨터를 직접 랜선으로 연결하여 테스트 (공유기 우회)
- 저장소 관리자에서 RAID 상태 및 드라이브 상태 확인

### 8.3 배드섹터 확인 및 복구
1. DSM 저장소 관리자 → 해당 드라이브 우클릭 → "상태 정보"
2. 오류 표시나 경고 메시지 확인
3. 배드섹터가 의심되면 드라이브 건강 상태를 확인하거나 S.M.A.R.T 데이터 조회

배드섹터가 많으면 드라이브 교체가 필요할 수 있다.

## 9. NAS에서 비정상 소음이 날 때 (팬 소음·클릭음)

### 9.1 팬 소음 구분
**공식 출처:** Synology KB - "Synology NAS에서 비정상적인 소음이 발생합니다"

- **높은 주파수의 계속된 윙윙거림:** 팬이 고속 회전 중 (과열 신호일 수 있음)
- **간헐적인 딱딱거림·클릭음:** 하드드라이브 헤드 이상 신호 (고장 가능성 높음)
- **비프음(삐삐):** NAS 경고음 (오류 상태)

### 9.2 팬 속도 모드 조정
**공식 출처:** Synology KB - "Synology NAS에서 어떤 유형의 팬 속도 모드를 사용할 수 있습니까?"

DSM 제어판 → 하드웨어·전원 → 팬에서 모드 변경:

| 모드 | 냉각성 | 소음 | 추천 상황 |
|---|---|---|---|
| **최대 속도** | 최고 | 매우 큼 | NAS가 지속적으로 과열 경고 시 |
| **냉각 모드** | 높음 | 중간 | 24/7 운영·많은 데이터 전송 중 |
| **무음 모드** | 낮음 | 거의 없음 | 가끔 접근·백그라운드 사용 |
| **자동 모드** | 온도에 따라 조정 | 변함 | 기본값 (권장) |

### 9.3 과열 확인 및 해결
1. DSM 제어판 → 시스템 상태 또는 센서 모니터링에서 현재 온도 확인
2. 정상 범위: 보통 35~50°C (최대 60°C 이하)
3. 과열이 의심되면:
   - 팬 속도 모드를 "냉각 모드" 또는 "최대 속도"로 변경
   - NAS 주변의 환기 상태 확인 (막혀 있지 않은지)
   - 선풍기를 NAS 쪽으로 향하게 하여 보조 냉각
   - 계속 과열되면 필터 청소 또는 A/S 신청

### 9.4 이상한 클릭음이 날 때 (⚠️ 드라이브 고장 신호)
간헐적인 딱딱·클릭음이 나면 하드드라이브의 기계식 부품이 손상되고 있다는 신호다. 이 경우:

1. **즉시 NAS에 새로운 파일 저장 중단**
2. **기존 데이터 백업 시작** (외장하드·클라우드 등)
3. **고장 드라이브 교체 또는 A/S 신청**
4. **고장 드라이브를 임의로 제거하면 RAID 복구 불가능해질 수 있으므로 신중할 것**

## 10. 여전히 문제가 해결되지 않을 때

### 10.1 체크리스트
- [ ] IP 주소 확인 (Synology Assistant 또는 find.synology.com)
- [ ] 웹 접속 포트 확인 (기본: 5000 HTTP / 5001 HTTPS)
- [ ] 이더넷 케이블 재연결
- [ ] NAS 전원 재시작 (전원 끄기 → 30초 대기 → 켜기)
- [ ] 공유기·모뎀 재부팅
- [ ] 다른 컴퓨터/기기에서 NAS 접속 시도 (해당 기기만 문제인지 확인)
- [ ] DSM 업데이트 확인 및 설치
- [ ] 드라이브 상태 확인 (오류·미인식·배드섹터)

### 10.2 전문가 상담 추천
다음의 경우는 제조사 A/S 또는 데이터 복구 전문가 상담을 권장한다:

- **하드드라이브에서 클릭음·비프음이 계속 나는 경우** (기계 손상)
- **RAID 2개 이상 드라이브 동시 고장 상태**
- **모든 자가점검을 해봐도 인식되지 않는 경우**
- **중요 데이터가 있는데 접근 불가능한 경우**
- **초기화(하드 리셋) 후에도 웹 인터페이스 접속 불가**

## 참고: NAS와 공유기 혼동 주의

이 가이드는 **NAS 본체**(저장장치 기능)에 관한 것이다. 인터넷 속도 저하·와이파이 연결 문제는 공유기 문제일 수 있으므로, 공유기 자가점검 가이드를 별도로 참조할 것.
