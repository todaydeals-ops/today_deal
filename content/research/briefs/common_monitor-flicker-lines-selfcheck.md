# 모니터 깜빡임·줄 점검 조사 브리프 (monitor-flicker-lines-selfcheck)

- 조사일: 2026-11-03 / 분야: 디지털·IT / 코너: repair
- 원본 팩트: `content/research/facts/common_monitor-flicker-lines-selfcheck.json`
- 집필 글 슬러그: monitor-flicker-lines-selfcheck

## 점검 순서 (근거 기준)

1. **연결·케이블** — 케이블 양끝을 뽑았다 다시 꽂고, 손상이 있으면 정상 케이블로 교체 (Samsung US TSG10007367, 기존 HDMI 팩트 재사용)
2. **주사율·해상도** — 모니터와 PC가 둘 다 지원하는 최고 주사율, 네이티브 해상도 (Samsung US). Windows 11은 설정 > 시스템 > 디스플레이 > 고급 디스플레이 (MS ko-kr). 별표(*) 값은 해상도가 바뀐다.
3. **가변 주사율** — G-Sync/FreeSync를 켰다면 NVIDIA 제어판에서 끄고 확인 (Samsung US)
4. **Windows 그래픽 드라이버** — Win+Ctrl+Shift+B 재설정 → 작업 관리자 점검으로 드라이버/앱 구분 → 업데이트 후라면 드라이버 롤백 → 제거 후 재설치 (MS ko-kr)
5. **앱 충돌** — 특정 앱에서만 깜빡이면 업데이트하거나 하나씩 제거 (MS ko-kr)
6. **전원** — 다른 콘센트, 고전력 기기 회로 분리, 콘센트 문제면 전기 기술자 (Samsung US)
7. **모니터 메뉴(OSD) 판별** — 메뉴가 깨끗하면 모니터 정상, 원인은 케이블·PC. 메뉴까지 깨지면 모니터 쪽 (Samsung US, 기존 팩트 재사용)

## AS 기준

- 전원 버튼 무반응 + 화면 없음 + JOG 메뉴 안 뜸 → 출장서비스 예약 (삼성전자서비스 KR, solution/34586)
- 무상 보증 기간이라도 사용법·설치 등 고장이 아니면 별도 요금 (삼성전자서비스 KR)
- 메뉴가 정상이면 AS 전에 케이블·주사율 점검 결과를 먼저 준비
- **확인실패**: 모니터 품질보증기간과 화면 불량 교환 기준. 소비자분쟁해결기준 원문 PDF를 열었으나 판독하지 못했다. 블로그 비교표 두 곳은 서로 다른 무결점 기준을 제시하므로 인용하지 않는다. 글에서는 보증서·제조사 고객지원 확인으로 안내한다.

## 모델·연식 차이

- Windows 11만 DRR(동적 새로 고침 빈도) 지원, 디스플레이가 VRR과 최소 120Hz 필요 (MS)
- LS27R750UENXZA·LS32R750UENXZA는 Y 케이블(BN39-02467A) 교체로 해결될 수 있다고 삼성 미국 문서에 명시됨
- RTX 40 계열은 드라이버 535.98 이상 권고 (삼성 미국 문서. 최신 드라이버가 우선)

## 재사용·거부

- 재사용 6건: 공통_monitor-no-signal-selfcheck.json(입력 소스·케이블·전원 재시작·OSD 메뉴), 공통_hdmi-connection-selfcheck.json(케이블 교체·입력 선택)
- 거부 3건: TV 자가진단 경로, 셋톱박스 전원 전제, 게이밍 모니터 구매 후기 (모두 깜빡임 점검과 무관하거나 TV 전용)

## 힌트와 달랐던 점

- 총괄 힌트의 "전원"은 공식 문서에서 콘센트·회로 분리 점검으로 확인됐다. 모니터 전원 공급 장치 자체의 불량 판별 기준은 공식 문서에서 찾지 못해 넣지 않았다.
- 삼성 KR 공식 페이지 중 깜빡임 전용 안내는 찾지 못했다. 확인한 것은 '입력신호 없음' 페이지(solution/34586)뿐이며, 깜빡임 점검 근거는 삼성 미국 지원 문서로 채웠다. 미국 문서이므로 KR 독자에게는 "미국 삼성 지원 기준"임을 밝힌다.
- 삼성 PC 주사율 페이지(TSG10002787)는 모니터가 아니라 PC·노트북 대상이라 근거로 쓰지 않았다.
- 소비자분쟁해결기준의 모니터 수치는 이번에 확인하지 못했다. 블로그 수치를 쓰지 않았다.
