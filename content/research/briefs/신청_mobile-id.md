# 모바일 신분증 — 조사 브리프 (2026-10-27)

## 조사 범위
발급 방법, 준비물·수수료, 민간 앱 발급 현황, 재외국민 확대, 최근 공지.

## 열어서 확인한 페이지 (렌더링 완료, 이 세션)
- https://www.mobileid.go.kr/ → 리다이렉트 https://www.mobileid.go.kr/mip/hps/main.do : 메인. 민간개방(삼성월렛만 현재, 그 외 예정), 재외국민 신원확인증 시범 공관, 준비물 안내 링크 확인.
- https://www.mobileid.go.kr/mip/hps/issuReqstGuidance/issuReqstGuidanceMrc.do : 모바일 주민등록증 발급방법. 신청 경로(온라인·주민센터), 준비물(사진 1장 3.5×4.5cm·6개월 이내, 신분증, 수수료 1만 원), 태그 본인인증 절차 확인.
- https://www.mobileid.go.kr/mip/hps/bbsManage/selectBbs.do?...bbscttSn=10551 : 홍보자료 '모바일 신분증 민간개방' 게시일 2025-08-21 확인. 본문은 비어 있음.
- https://www.mobileid.go.kr/mid/index.do : 404(사용 안 함).

## 확인 못 한 것
- 민간 앱 추가 목록(은행 4곳 포함 11개 앱)은 블로그뿐. 공식 미확인 → 확인실패.
- 17세 이상 최초 IC 무료는 2024 입법예고 기사 기반. 현행 여부 미확인 → 확인실패.
- 주민센터 QR 발급·스마트폰 교체 절차의 세부 단계는 페이지에 있으나 이번 팩트로 추출하지 않음(다음 리서처가 필요하면 같은 URL 재확인).
- 웹 검색 1회: 결과 대부분 뉴스·블로그. 공식 페이지는 검색이 아니라 메인에서 링크를 따라가 확보.

## 집필 시 주의 (2줄)
1. 민간 앱은 "현재 삼성월렛, 나머지는 예정"으로만 쓴다. 블로그의 11개 앱 목록은 쓰지 않는다.
2. 수수료 1만 원은 공식 페이지 표기이며, 무료 발급 이야기는 현행 근거가 없으니 쓰지 않는다.
