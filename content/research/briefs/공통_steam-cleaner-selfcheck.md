# 스팀청소기 자가점검 — 스팀 안 나옴·물샘·물때 조사 원본

## 조사 배경
스팀청소기는 고온 고압으로 작동하기 때문에 스팀다리미·가습기와는 다른 고장 특성을 가진다. 특히 석회질, 물탱크 누수, 바닥재별 손상이 사용자 커뮤니티에서 빈번히 보고된다.

## 조사 범위
- **스팀 안 나옴:** 물 부족, 예열 부족, 노즐/배출구 막힘(석회질)
- **물 새는 현상:** 물탱크 설치 오류, 물 과다 주입, 호스 손상, 씰 링 손상
- **물때 제거:** 구연산 사용법(스팀다리미·가습기와 다른 농도), 식초 대체법
- **예열 오래 걸림:** 보일러 내 물 공급 문제
- **자동 차단:** 과열 방지(온도 센서), 물 부족 감지
- **바닥재 주의:** 원목·왁스 코팅·무광 대리석 손상 위험

## 핵심 발견

### 1. 스팀 안 나올 때 자가진단 순서
1. 물탱크 물 확인 (최소 표시선 이상)
2. 예열 대기 (제품마다 다름, 보통 5~15분)
3. 노즐/배출구 육안 확인 (흰색 물때가 보이는가?)
4. 물 세척 시작 (정수된 물로 초기 분사 테스트)

### 2. 물때는 스팀청소기마다 다른 농도
- **스팀다리미:** 물 1L + 구연산 10-20g (약한 농도)
- **가습기:** 물 1L + 구연산 10-20g (약한 농도)
- **스팀청소기(삼성 기준):** 물 1L + 구연산 100g (10배 강함)
→ 스팀청소기는 보일러 고온 고압으로 작동하므로 강한 석회질 제거가 필요함

### 3. 물 새는 주요 원인 3가지
1. 물탱크 설치 미흡 (뚜껑이 '딸깍' 소리까지 닫혀야 함)
2. 물 과다 주입 (2/3 선까지만 — 너무 많으면 작동 중 넘침)
3. 호스 손상 또는 씰 링 노후 (육안으로 확인 후 AS 필요)

### 4. 바닥재별 사용 제약 — 원목·왁스는 위험
- **원목 바닥:** 장시간 증기 노출 → 습기 침투 → 썩음·찌그러짐·솟아오름
- **왁스 코팅 바닥:** 고온 증기 → 코팅 손상·변색
- **무광 대리석:** 증기로 인한 변색 손상
→ 이 바닥재들에서는 스팀청소기 사용 자제 권장

### 5. 자동 차단 안전장치 작동
- **온도 140도 이상:** 보일러 전원 자동 차단
- **온도 145도 이상 + 물 부족:** 보일러+펌프 전원 차단, 경고음 발생
→ 정상 작동이므로 물탱크를 확인하고 물을 보충하면 재개됨

### 6. 예열 시간 차이
- 제조사·모델마다 30초~15분 편차 큼
- 예열이 오래 걸리면 보일러 내 물 공급 라인 막힘 의심 → 구연산 탈석회화 필요

## 스팀다리미·가습기와의 주요 차이
| 항목 | 스팀다리미 | 가습기 | 스팀청소기 |
|------|---------|------|---------|
| 온도 | 110~160도 | 60~100도 | 120도 이상 고온 |
| 압력 | 낮음 | 무압 | 고압 |
| 물탱크 | 소형(0.2~0.4L) | 중형(2~5L) | 대형(1~3L) |
| 구연산 농도 | 1:100 | 1:100 | 1:10 (10배 강함) |
| 석회질 축적 속도 | 중간 | 빠름(초음파 진동자) | 매우 빠름(고온) |

## 주의 사항
- 정수된 물 사용 권장 (수돗물 사용 시 석회질 가속화)
- 구연산 비율 준수 필수 (과다 농도 = 호스 손상, 저농도 = 효과 없음)
- 원목·왁스 바닥에서는 사용 금지
- 호스나 연결부 손상 시 감전·화상 위험 → 즉시 서비스센터 방문
- 강한 스팀 분사로 100도 이상 화상 위험 (보호장갑 필수)
