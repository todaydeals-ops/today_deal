# 한부모가족 지원 — 조사 전문 (2026-10-27)

## 1. 확인한 페이지 (이번 세션에 WebFetch로 직접 열어 본 것)
- 복지로 게재 정부 카드뉴스 "한부모가족 지원 확대"(등록 2025.12.29): https://www.bokjiro.go.kr/ssis-tbu/cms/pc/news/promotion/1309148_1118.html
  - 확인 내용: 18세 미만 자녀 1인당 월 23만 원, 미혼모·부/조손 5세 이하 및 청년 한부모(25~34세) 자녀 추가 월 10만 원, 기준 중위소득 65% 이하, 소득인정액 2인 273만·3인 348만·4인 422만 원 이하, 근로·사업소득 30% 공제, 대상은 18세 미만 자녀 양육 가구.

## 2. 기관명 주의
- 페이지 표기는 "성평등가족부 카드뉴스", 정보제공처는 "대한민국 행정부처"로 되어 있다. 배정 메모의 '여성가족부'와 다르다. 조직명 변경 여부는 이번에 확인하지 못했다. 글에서는 "카드뉴스 출처 표기 기준"으로 밝히고, 기관명은 공식 시행 문서로 한 번 더 확인할 것.

## 3. 확인 못 한 것
- 1인 가구 소득인정액: 카드뉴스에 없음.
- 추가 10만 원과 기본 23만 원의 중복 지급 여부: 카드뉴스에 없음. 지자체 기준 확인 필요.
- 신청 경로·기관·시기: 미열람 → 확인실패 팩트로 기록.
- 블로그에 있는 2025년 이전 금액(20만 원)·정확한 원 단위 기준선(2,729,540원 등): 공식 페이지에 없어 팩트로 쓰지 않음.

## 4. 검색 사용 (세션 전체 6회 중)
- 검색 1회: "2026년 한부모가족 지원 아동양육비 지원액 여성가족부". 공식 원문 검색 결과 없음, 블로그·지자체 자료. 복지로 카드뉴스 URL을 여기서 얻어 직접 열어 교차했다.

## 5. 집필 시 주의
- 금액 23만 원은 2026년 기준. 연도를 함께 쓸 것.
- 소득 기준은 65%(63%라고 쓴 블로그가 있으나 공식 페이지는 65%). 경계선이면 "지자체 확인"으로 넘길 것.
- 추가 지원 중복 여부는 단정하지 말고 "지자체 확인"까지만.
