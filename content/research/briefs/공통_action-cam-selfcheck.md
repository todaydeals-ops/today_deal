# 액션캠(고프로·오즈모류) 전원·녹화·배터리·방수 자가점검

**조사 기간**: 2026-07-21  
**대상**: 고프로 HERO·오즈모 액션 등 액션카메라  
**조사자 노트**: 웹 검색 6회, 공식 문서 + 사용자 커뮤니티  

---

## 1. 전원 불량

### 전원이 켜지지 않을 때 — 배터리·액세서리 격리 테스트

**공식 출처 (GoPro Support)**

GoPro가 켜지지 않으면:
1. **배터리 분리** → 카메라와 배터리를 각각 실온에서 식힌다 (배터리가 과열로 차단되었을 수 있음).
2. **설정 최소화** → Wi-Fi, GPS, 음성명령을 끈다.
3. **외부 액세서리 제거** → BacPac 배터리, 터치백스크린, 기타 모든 추가 액세서리를 분리한다.
4. **재장착 & 전원 테스트** → 배터리를 다시 넣고 전원 버튼을 누른다.

**근거**: GoPro Community의 "Camera Will Not Power On" 공식 지원 문서에서 명시. 블랙박스(제1 소스)와 동일한 순서.

**주의**: BacPac 같은 외부 배터리 액세서리가 내부 배터리와 충돌하면 전원 차단이 발생할 수 있다 (제품 특화 고장).

## 2. 녹화 안 됨

### 문제의 대부분은 SD카드 속도

**공식 출처 (Kingston Technology)**

4K 촬영에는 **V30(Video Speed Class 30, 최소 쓰기 속도 30MB/s) 이상의 SD카드가 필수**다.

Kingston의 공식 가이드에서:
- V10 = 10MB/s (1080p 영상)
- V30 = 30MB/s (4K 30fps 표준)
- V60 = 60MB/s (4K 60fps, 고급 코덱)
- V90 = 90MB/s (8K, 전문가용)

**사용자 보고 (커뮤니티)**

실제 녹화 중단 사례:
1. "다른 카드로 바꿔보세요" → 카드 자체 불량
2. "카메라 내에서 포맷하세요" → 파일 시스템 손상
3. "저해상도로 먼저 확인" → 높은 비트레이트에서만 끊김

**주의**: V30 표기가 있어도 카드 내부 손상이나 포맷 오류가 있으면 막힐 수 있다. 특히 고해상도·고프레임(4K 60fps)에서는 V30도 한계. V60 권장.

## 3. 과열로 꺼짐 — 정상 보호기능

**사용자 커뮤니티 종합 보고**

고프로가 "자동으로 꺼진다"는 불만은 실제로는 **과열 보호 메커니즘**이다.

발열이 쌓이는 조건:
- 4K 고화질 촬영
- HyperSmooth(손떨림 보정) ON
- GPS 활성화
- Wi-Fi 활성화
- 화면(백라이트) 켜짐
- 무풍 환경(자연 대류 냉각 불가)

**특히 고프로 HERO 12·13의 알려진 문제**:
- 4K 60fps를 30분 이상 못 찍고 발열로 꺼진다 (사용자 다중 보고).
- HDR·5.3K 같은 처리량 큰 조합에서 누적 발열.

**근거**: Yellowit(기술 리뷰) + SLR Club(사용자) 다중 출처 일치.

**조치**: 이는 고장이 아니라 보호 기능이므로, 카메라를 실온에서 식힌 후 사용을 재개하면 된다.

## 4. 배터리 저온 급감 — 정상 현상

**공식 출처 (LG Chem, 배터리 화학)**

리튬이온 배터리는 저온(특히 영하)에서:
- 내부 전해질이 얼면서 이온 이동이 느려짐
- 순간적으로 내부 저항 상승
- 순간적 전압 강하 → "배터리가 떨어짐"으로 표시

**중요**: 이것은 배터리 손상이 **아니다**. 온도가 올라가면 다시 회복된다.

**사용자 보고에서 검증된 회복 방법**:
1. **보온 케이스** → 배터리를 파우치/헝겊으로 감싸 온도 유지
2. **내의 호주머니** → 촬영 직전까지 체온으로 데우기
3. **충전 타이밍** → 새벽 한파가 아닌 오후 상대적 고온 시점에 충전

**절대 금지**: 드라이어, 난로 같은 급속 가열. 배터리 손상 초래.

**주의**: 극저온(-20℃ 이하)에서는 배터리 용량 50% 이상 급감이 정상이며, 이는 화학적 한계다.

## 5. 렌즈 김서림 & 방수 하우징

### 5-1. 김서림 방지 — GoPro 공식 액세서리

**제품**: GoPro "Anti-Fog Inserts" (공식 액세서리)

방수 하우징에 카메라를 담아 수중 사용 시, 하우징 내부의 **온도·습도 차이**로 렌즈 안쪽에 응결이 생긴다.

**해결책**: 하우징 내부 양쪽 빈공간에 미리 김서림 방지 삽입물을 끼운다.
- 일회용이므로 습한 환경에서는 여분 준비 필수.

### 5-2. 방수 하우징 누수 — 패킹 점검

**실측 커뮤니티 보고**

누수 90%는 고무 패킹(O-ring 가스켓) 문제:
- 마르거나 갈라짐
- 이물질(모래, 소금기) 부착
- 사용 전후 미점검

**필수 확인 사항**:
1. 사용 전 → 패킹에 균열, 먼지 없는지 목시 점검
2. 담수 후 → 패킹 건조
3. 주기적 교체 → 마모 시 즉시 교체 (특히 60m 이상 깊이 사용 시)

**주의**: 미세한 모래 알갱이 하나도 누수의 원인이 될 수 있다.

## 6. 앱 연동 (Wi-Fi 끊김)

**공식 출처 (GoPro Support - Quik)**

GoPro Quik 앱과의 Wi-Fi 연결이 끊기는 문제:

**1차 조치**:
- 카메라의 Wi-Fi 끄기 → 다시 켜기
- 앱 강제 종료 → 재시작

**2차 조치**:
- 기기(스마트폰)의 Bluetooth, Wi-Fi 끄기 → 다시 켜기
- 카메라의 Bluetooth, Wi-Fi도 함께 끄기 → 다시 켜기

**환경 요인**:
- 2.4GHz 간섭 (다른 기기, 무선 라우터)
- 펌웨어 버전 호환성 (카메라 펌웨어 구식)
- 앱 버전 오래됨

**주의**: 자주 끊기면 카메라 펌웨어를 최신으로 업데이트하거나, 앱을 재설치해야 한다.

## 7. 손떨림 보정 (HyperSmooth & EIS)

### 7-1. 기술 개요

**고프로의 전자식 손떨림 보정**: HyperSmooth (HERO 7 이후)

자동초점 메커니즘을 이용해 프레임을 실시간 보정. 광학식 손떨림 보정(OIS)와 달리 **소프트웨어 기반**이므로 배터리 소비가 크다.

**설정 계층**:
1. OFF → 손떨림 보정 미적용
2. ON → 일반적 손떨림 보정
3. AUTOBOOST → 최고 레벨 보정 (가장 배터리 소비, 발열)

### 7-2. 환경별 추천

**삼각대 사용** → OFF (고정 자체가 손떨림 보정)

**일반 촬영** → ON (배터리 절감)

**산악, 울퉁불퉁한 길** → ON 또는 AUTOBOOST (필요에 따라)

### 7-3. 야간 촬영의 한계

**중요**: 저조도 환경에서 HyperSmooth는 **제대로 작동하지 않는다**.
- 빛이 부족하면 초점 추적 자체가 불안정
- 화면이 심하게 흔들리거나 잔상 증가

**해결책**: 야간 촬영이 필요하면:
1. 손떨림 보정을 OFF 또는 ON(낮음)으로 설정
2. 헤드램프, 보조 조명 사용
3. ISO 높임 (노이즈 대신 안정성 선택)

## 8. 펌웨어 업데이트

**절차** (블랙박스와 유사, 단 자동 업데이트 지원)

### 수동 업데이트
1. 제조사 웹사이트에서 다운로드
2. 메모리카드에 업로드
3. 카메라에서 업데이트 실행

### 자동 업데이트
- GoPro 공식 앱을 통해 직접 업데이트 가능 (블랙박스보다 편함)

**필수 사전 점검**:
- 배터리 충분 충전
- 메모리카드 충분한 용량 (50MB 이상)
- **업데이트 중 전원 차단 금지** (부트로더 손상 위험)

## 정리: 자가점검 체크리스트

| 증상 | 1차 조치 | 2차 조치 |
|---|---|---|
| 전원 안 켜짐 | 배터리 분리 냉각 → 재장착 | 액세서리 모두 분리 재시도 |
| 녹화 안 됨 | SD카드 V30 등급 확인 | 다른 카드 시도 + 포맷 |
| 과열 꺼짐 | 정상 보호 기능 | 카메라 냉각 후 재사용 |
| 배터리 저온 급감 | 정상 현상, 온도 회복 기다리기 | 보온 케이스로 온도 유지 |
| 렌즈 김서림 | 방수 하우징 전에 방지 삽입물 끼우기 | 하우징 내부 건조 유지 |
| 방수 누수 | 패킹 균열·오염 점검 | 패킹 교체 |
| Wi-Fi 끊김 | 앱·카메라 Wi-Fi 재활성화 | 펌웨어·앱 버전 업데이트 |
| 야간 촬영 흔들림 | 손떨림 보정 ON → OFF 시도 | 보조 조명 추가 |
