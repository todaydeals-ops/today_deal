## 과제 전제와 다른 점
- 과제에는 "운영 기관(한국정보통신진흥협회 등)"으로 적혀 있었으나, 스마트초이스 페이지 기준 **통신 미환급액 조회의 운영 기관은 한국통신사업자연합회(KTOA)**다.
- KAIT는 **유료방송 미환급액** 조회·환급·기부를 맡는다. 두 기관을 한 서비스로 쓰면 틀린다.
- 팩트 `telecom-smartchoice-operator`의 caution에 이 차이를 명시했다.

## 주제별 정리

### 1. 조회 경로
- 메뉴: 환급/혜택 > 통신 미환급액 조회 > (서비스 안내 / 통신 미환급액 조회 / 환급신청 결과 조회) → `telecom-menu-path`.
- 환급신청은 로그인 후 이용 → `telecom-refund-requires-login`.
- 로그인 수단·인증 방식은 확인 못 함 → `telecom-auth-docs-unverified`.

### 2. 미환급금이 생기는 경우
- 페이지의 '환급대상 서비스 예시': 할인조건에 따른 과납, 이중납부, 보증금 미수령 → `telecom-refund-examples`.
- 원문에 이 예시가 조회 서비스와 직접 연결된다는 설명은 없다(caution에 명시).
- 블로그식 "해지 후 잔액", "요금제 변경 과납" 등의 세부 원인 목록은 공식 확인 못 함 → 팩트 미등록.

### 3. 환급 신청 방법
- 구체 단계·환급 방식(입금 등)·처리 기간 → 확인실패 `telecom-apply-steps-unverified`, `telecom-deadline-unverified`.
- 소멸시효 문구("놓치면 소멸")는 근거가 없어 쓰지 않는다.

### 4. 유료방송 미환급액
- KAIT 운영, 별도 메뉴, kait-tvrefund.kr에서 환급·기부 신청 → `telecom-paid-broadcast-kait`.
- 본문은 열지 못했으므로 유료방송 절차는 확인 전까지 쓰지 않는다.

## 주의 (집필)
- 통신 미환급 = KTOA(스마트초이스), 유료방송 미환급 = KAIT(kait-tvrefund.kr). 섞지 말 것.
- 환급 단계는 창작 금지. "로그인 후 통신 미환급액 조회 메뉴에서 진행" 수준까지만.
