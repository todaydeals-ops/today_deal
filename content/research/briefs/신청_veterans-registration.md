# 신청 — 국가유공자 등록 신청 (veterans-registration)

- 조사일: 2026-10-27 · 팩트: `content/research/facts/신청_veterans-registration.json`

## 현행 여부
- 국가유공자 등 예우 및 지원에 관한 법률 제6조 열람본 표기: **시행 2026.9.8, 법률 개정 표기**. 현행.
- 국가보훈부 등록신청 페이지(key=106) 열람 시점 2026-10-27 기준 게시 내용 확인. 폐지 신호 없음.

## 열어 본 출처 (이번 세션 직접 열람)
1. https://www.law.go.kr/법령/국가유공자등예우및지원에관한법률/제6조 — 등록 신청 주체·등록 결정 절차(제1~5항), 소관 부서 연락처 표기(등록관리과 044-202-5431)
2. https://mpva.go.kr/mpva/contents.do?key=106 — 국가유공자 및 가족 등록신청 페이지: 신청대상·접수기관·처리기간·구비서류(본인·유족·유형별)·신청방법(방문 또는 우편)

공식 개별 문서 **2곳**(법령 조문 1, 국가보훈부 개별 신청 안내 1). 집필 게이트 기준 충족. 다만 등록 신청 안내 페이지 1곳에 내용이 집중되어 있어 **두 번째 출처는 법령이고 실무 안내는 1곳**이라는 점을 집필 시 기억할 것.

## 검색으로만 본 것
- 접수·처리 절차 흐름(등록신청 → 요건 확인 의뢰 → 보훈심사 → 결과 통보 → 신체검사 → 상이등급 → 범죄사실 조회 → 결정 통보) — 공식 페이지 흐름도 이미지만 있어 텍스트로 확인 못 함. 글에 단계명을 쓰지 말 것.
- "참전유공자 배우자는 2026.3.17부터 신청 가능" — 공식 확인 못 함. 쓰지 말 것.
- 정부24·민원24 온라인 신청 — 팩트 `veterans-registration-online-unverified`(확인실패). 페이지 민원신청방법은 "방문 또는 우편".

## 재사용·거부
- 재사용: 없음 (장애·보훈 관련 기존 팩트와 대상 제도가 달라 재사용하지 않음)
- 거부: 없음

## 확인 못 한 것
- 법 제6조 단서 1~3호(본인 직접 신청 불가 사유) 세부
- 등록증(국가보훈등록증) 발급 절차 — 메뉴명만 확인
- 유형별 요건(4조 각 호) — 이번 세션에서 열지 않음
- 처리기간 20일·14일의 법적 근거 조문(시행규칙·지침 여부) — 페이지 표기만 확인

## 집필 시 주의
1. 처리기간은 유형에 따라 20일 또는 14일이고, 확인·심의·신체검사 기간은 빠진다. "20일이면 끝"으로 쓰지 말 것.
2. 접수는 주소지 관할 보훈청 보상과. 044-202-5431은 법령 페이지의 소관 부서 번호이지 접수창구 번호로 단정하지 말 것.
3. 구비서류는 공통분 + 유형별 추가분을 같이 안내해야 반려를 줄인다.
