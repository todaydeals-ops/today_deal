- 조사일: 2026-10-27 · 근거 힌트: 국민건강보험공단
- facts: `content/research/facts/신청_insurance-certificate.json`

## 1. 저장소 확인
- facts 원본 확인. 건강보험 자격확인서·자격득실 관련 기존 팩트는 `신청_health-insurance-refund.json`(환급금), `신청_copay-cap-refund.json`(상한제)에 있으나 주제 맥락이 달라 재사용 안 함.
- 거부(declined): `health-refund-hotline-1577-1000` — scope가 환급금 문의로 한정. 대표번호는 공단 메인에서 새로 확인.

## 3. 명칭 차이
- 검색어는 "건강보험 자격확인서"지만 공단 메뉴 항목명은 "자격득실확인서"다. 글에서는 공단 명칭을 기준으로 쓰고 검색 표현은 병기만.
- "자격확인서"라는 별도 문서가 공단에 존재하는지는 확인하지 못했다(확인실패 아님, 미확인 — 글에 단정하지 말 것).

## 4. 확인 못 한 것 (확인실패)
- 온라인 발급 절차(로그인 후 메뉴, 출력·팩스 방식, PDF 암호 설정): 블로그 요약에만 있음. 공식 본문은 로그인 벽으로 확인 불가.
- 수수료 무료 여부: 블로그만. 공식 확인 실패.
- 정부24·주민센터·고객센터 팩스 경로: 블로그 요약만. 정부24 공식 페이지는 열지 못함.
- 블로그가 말한 "The 건강보험 앱/건강보험25시 앱" 명칭은 기존 팩트 `health-refund-app-name-conflict`에 이미 충돌로 남아 있다. 이번 주제에서는 앱 명칭을 쓰지 말 것.

## 5. 집필 시 주의
- 발급 경로는 "공단 홈페이지 메뉴의 자격득실확인서(로그인 필요)"까지만 단정. 그 다음 단계는 "발급 화면에서 안내에 따라 진행, 막히면 1577-1000"으로 연결.
- 제출처(금융기관·회사 등)가 요구하는 옵션(주민번호 표시·전체 이력 포함 등)은 블로그 주장뿐이므로 쓰지 말고, "제출처 요구 양식을 먼저 확인"으로.

## 6. 웹 검색 사용
- WebSearch 1회(발급 방법), 블로그 요약만 확보 → 전부 확인실패 또는 메뉴 존재 확인으로 축소.
- WebFetch 1회: 공단 메인에서 발급 페이지 링크 추출(개별 URL 확보용). 해당 페이지는 로그인 리다이렉트.
