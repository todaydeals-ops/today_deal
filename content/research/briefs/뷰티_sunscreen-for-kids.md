# 아이 선크림 조사 브리프

## 조사 배경
부모들의 "아이도 성인용 선크림 써도 되나", "6개월 아기 햇빛 나갈 때는 뭘 바르나" 같은 질문에 대해 FDA·AAP 공식 기준과 성분 선택 로직을 구조화.

## 핵심 발견

### 1. 나이별 권고 ★안전 이슈
- **6개월 미만**: 선크림 금지. 햇빛 회피 + 보호 의류 우선
  - 이유: 미성숙 피부 + 높은 흡수율
  - 필요 시 의사 상담 필수
- **6개월 이상**: SPF 15+ broad-spectrum (성인 기준과 동일)

### 2. 안전 성분 (광물질 우선)
- **GRASE 지정**: 산화아연, 이산화티탄 (최대 25%)
- 입자 크기가 커 피부 표면에만 남음 → 혈중 흡수 없음
- 아토피·습진 아이: 산화아연 항염증 작용 추가 혜택

### 3. 피해야 할 성분
- **PABA**: 알레르기 위험
- **향료**: 민감 반응 (향료 프리 제품 선택)
- **옥시벤존**: 호르몬 우려

### 4. 아이 피부 특성
- 만 5세 전: 성인 수준 미달
- 더 얇은 표피, 불완전한 장벽
- 화학 자차는 투과 위험 높음
- → 광물질 선택이 안전성의 기초

### 5. 사용 기준
- **도포량**: 성인 기준 2mg/cm² (동전 크기, 얼굴·목·팔)
- **재도포**: 2시간마다
- **수영 후**: 60분 이내 재도포
- **시즌**: 연중 사용 권고 (겨울도 노출 있음)

### 6. 부모 체크리스트
- "mineral sunscreen" 표시 확인
- 성분 목록에서 zinc oxide / titanium dioxide 확인
- 향료 없음(fragrance-free) 선택
- 1~2세: 아이용 전문 제품, 5세 이상: 성인용도 검토 가능

## 기대 활용
집필 시 안전 프레이밍:
- 과도한 주의 vs 합리적 기준 균형
- "6개월까지는 못 써" → 선택지 차단 아닌 "그 대신 이렇게"
- 광물질 선택이 "자연 = 안전"이 아니라 "크기·투과성의 과학"임을 설명
