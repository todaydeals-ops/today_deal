# 조사: 레스베라트롤 국소 도포 — 경피 흡수 과제와 항노화 근거

## 조사 배경

레스베라트롤의 국소 도포 효능과 제한사항, 특히 경피 흡수의 어려움과 제형 기술의 역할.

## 조사 결과 요약

### 1. 임상 효능 (국소 도포)

**시험 1**: 레스베라트롤 + 바이칼린 + 비타민E 야간 포뮬레이션, 12주
- 세밀한 주름(fine lines): 통계적 유의 개선
- 피부 탄력성(elasticity): 개선
- 탄성(firmness): 개선
- 색소 침착(hyperpigmentation): 감소
- 피부 거칠기(roughness): 개선

**시험 2**: 경구(75mg) + 국소(1.5%) 병용, 8주, 40세 이상 여성 (134명, RCT)
- 경구 + 국소 병용: 주름 감소 11.9%
- 위약 병용: 주름 감소 6.3%
- **병용 효과 > 단독**
- 부가 발견: 국소 사용자 그룹은 피부유분(sebum) 증가 (보습 효과 추정)

### 2. 경피 흡수의 어려움

**문제점**:
- 레스베라트롤은 소수성(lipophilic) 분자
- 수용성 낮음 → 피부 투과 능력 제한적

**포뮬레이션 기술의 중요성**:
- **포스파티딜콜린 기반 에토솜(ethosome)**: in vitro 경피 투과 입증
- **나노 리포솜**: 효과적, 다만 비용·안정성 고려 필요
- **단순 세럼**: 효과 제한적 (투과 도달 어려움)

**결론**: 제형 기술이 없으면 국소 효과 기대하기 어려움

### 3. 항산화 및 분자 메커니즘

**항산화 기전** (이중):
- 자유 라디컬 중화
- 내재적 항산화 능력 증가 (upregulation)

**추가 활성**:
- 미토콘드리아 생성 촉진
- 항염증
- 항당뇨병 활성
- 항암 활성 (in vitro)

**유전자 발현 변화** (고농도, 안정화 포뮬레이션):
- HO1(헤모옥시게나제-1) ↑
- VEGFA(혈관내피성장인자) ↑
- COL3A1(제3형 콜라겐) 변화

**주의**: 유전자 발현 변화가 임상 효과(주름 개선)와 직결되는지는 추가 연구 필요

### 4. 규제 및 실제 제품

**경구 vs 국소**:
- 경구(캡슐): 식이보충제 범주 → 효능 보증 없음
- 국소(크림/세럼): 화장품 또는 기능성화장품 → 더 엄격한 기준

**제품 선택 시**:
- 나노 기술 또는 에토솜 언급 여부 확인
- 레스베라트롤 농도 표기
- 개봉 후 유효 기한 확인 (산화 위험)

## 집필 시 주의점

1. **기대치 관리**: "레스베라트롤 = 만능 항노화제" 아님 → 경피 흡수 기술에 따라 효과 편차 큼
2. **제형의 중요성**: 같은 성분이라도 포뮬레이션이 효과를 좌우
3. **병용 전략**: 경구 + 국소 조합이 효과 입증 (다만 경구는 규제 약함)
4. **단독 선택은 신중**: 나노 기술 없는 단순 레스베라트롤 세럼은 효과 기대 낮을 수 있음

## 확인실패 / 미확인

- 국내 기능성화장품에서의 레스베라트롤 규제 지위
- 시판 제품의 포뮬레이션 기술 표시 기준 (제조사마다 상이)

## 웹 검색 횟수

2회 (총 예산 6회 중 사용)
