# 임차권등기명령 — 조사 브리프

- 주제: 임차권등기명령 신청 (보증금 미반환 시 임차인 절차)
- 조사일: 2026-10-27
- 대상 키워드: 임차권등기명령 신청 (candidates.txt 기준, 근거 힌트 "대법원")
- 팩트: `content/research/facts/신청_lease-registration-order.json` (10건)

## 1. 기존 저장소 확인
- `facts/`에 임차권등기명령 팩트는 없었다.
- `신청_fixed-date-lease.json`(확정일자), `신청_lease-renewal-right.json`(계약갱신청구권)은 제목만 확인했다. 이번 주제에 재사용할 항목은 없어 `reused_facts`는 비워 두었다. 집필 시 확정일자 글과 연결할 때 교차 확인이 필요하다.

## 2. 확인한 페이지 (실제로 열었다)
| 페이지 | 확인 내용 |
|---|---|
| law.go.kr 주택임대차보호법 제3조의3 | 관할, 신청 요건, 기재사항 개요, 집행 후 대항력·우선변제권, 후순위 임차인, 비용 청구, 기각 항고 |
| law.go.kr 임차권등기명령절차에관한규칙 제1~3조 | 신청서 기재 9개 항목, 도면 첨부, 인지 2,000원 |

## 3. 법령 현행 여부
- 주택임대차보호법 제3조의3 본문은 법령 페이지 현행 본문으로 열었다. 항별 개정 표기가 다르다(제1항 2013.8.13, 제3항 2023.4.18 등). 항 단위로 개정 표기를 확인해 쓴다.
- 규칙 제2조 개정 표기는 2002·2007년이다.

## 4. 확인 못 한 것 (글에 확정 표현 금지)
- **대법원 공식 안내 페이지**: 검색으로 대법원·법원 공식 절차 안내를 찾지 못했다. 나온 것은 법률 블로그뿐이라 절차 흐름(전자소송 제출 가능 여부, 처리 기간, 첨부서류 목록)은 확정하지 못했다(`lro-official-procedure-page-not-found`, 확인실패).
- **비용 항목**: 등록면허세 6,000원, 지방교육세 1,200원, 신청수수료 3,000원, 송달료 31,200원은 블로그 설명뿐이다. 지방세 항목은 지방세법 원문을 열지 않았다. 확인실패로 두었다(`lro-fee-blog-claim-unverified`).
- **첨부서류 목록**: 규칙 제3조 본문을 열었으나 세부 목록은 옮기지 않았다. 블로그의 "임대차계약서·주민등록초본·등기부등본·미반환 증빙" 목록은 공식 확인 전이다.
- **처리 기간 "2주 이상"**: 블로그 요약에만 있다. 쓰지 않는다.
- **항고 기간**: 제3조의3 제4항은 항고 가능만 말하고 기간은 없다. 기간은 민사집행법 원문 확인 전까지 쓰지 않는다.

## 5. 검색 사용
- 웹 검색 1회 (일반). 대법원 도메인 검색은 하지 않았고, 규칙은 법령정보센터에서 직접 열었다.

## 6. 집필 시 주의 (2줄)
1. 관할은 "임차주택 소재지를 관할하는 지방법원·지원 또는 시·군법원"으로 쓴다. 신청 요건은 "임대차가 끝난 뒤 보증금이 돌려받지 못한 경우"로 한정한다.
2. 등기 효과는 "등기가 완료된 뒤"에 생기며, 이미 취득한 대항력·우선변제권은 유지된다는 점을 함께 쓴다. 비용과 처리 기간은 "관할 법원 안내 확인"으로 넘긴다.
