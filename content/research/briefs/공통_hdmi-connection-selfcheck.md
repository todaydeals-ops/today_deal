# HDMI 연결 안 됨·신호 끊김·소리만 안 남 자가진단 조사

## 조사 배경
HDMI는 영상과 음성을 하나의 케이블로 전달하는 표준이지만, TV·모니터·게임기 등 여러 기기가 연결되는 만큼 신호 문제가 자주 보고된다. 특히 "화면은 나오는데 소리만 안 나온다"는 증상이 많다.

## 주요 자가진단 방법

### 1. 공식 자가진단 도구 활용
- **삼성 TV**: 리모컨 [홈] → [설정] → [일반설정] → [고객지원] → [기기관리] → [자가진단] → [HDMI 점검]
- 진단 시간: 약 2분
- 외부 기기가 켜진 상태에서 진행해야 정확함

### 2. 케이블 교체 테스트 (우선순위 1순위)
- HDMI 신호 문제는 90% 이상이 **케이블** 자체의 문제
- 여분의 HDMI 케이블이 있다면 **무조건 교체**해 테스트
- 정품 HDMI 2.1 이상 권장

### 3. 입력 소스 확인
- 모니터/TV가 여러 HDMI 포트를 가지면, 연결된 포트와 선택한 입력 소스가 **정확히 일치**해야 함
- TV 리모컨의 "입력" 또는 "Source" 버튼으로 올바른 포트 선택

### 4. 외부 기기 전원 상태
- HDMI 신호를 보내는 기기(셋톱박스, 게임 콘솔 등)가 **켜져 있어야** 신호를 감지
- 기기를 켠 후 1~2분 대기 후 진단 시작

## 소리만 안 나는 경우 추가 확인 사항
1. TV의 음성 출력 설정에서 사운드바나 외부 스피커 선택 여부
2. HDMI ARC/eARC 포트 연결 확인 (사운드바의 경우)
3. TV 측 음소거 상태 확인

## 현장 조사 결과
- 삼성, LG 공식 가이드 모두 **케이블 교체 테스트**를 가장 중요한 진단 순서로 강조
- 인증되지 않은 저가 HDMI 케이블은 신호 손실 빈번
- 대부분의 신호 복구는 케이블 교체 또는 입력 소스 변경으로 해결됨
