## 집필 방향 (권고)

1. 코드 표는 쓰지 않는다. "화면에 뜬 코드 → 모델명 확인 → 앱의 사용설명서에서 같은 코드 찾기"로 쓴다.
2. 가스 냄새가 나면 가장 먼저 공통 안전 팩트(가스 차단, 환기, 전기기구 금지, 신고)를 따른다. 점검은 그 다음이다.
3. AS 경로: 대성IoT보일러 앱의 자동 A/S 접수 → 홈페이지 1:1 문의 → 설명서·보증서에 적힌 번호 순으로 안내한다.
4. 재조사 조건: 대성쎌틱 공식 사용설명서 PDF 또는 모델별 에러코드 페이지를 찾으면 코드표를 재확인한다.
