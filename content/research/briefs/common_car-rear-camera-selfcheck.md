# 후방카메라 화면이 안 나오거나 흐릴 때 점검 — 조사 원본

- 팩트 파일: `content/research/facts/common_car-rear-camera-selfcheck.json`
- 웹 검색: 6회 사용(한도 이내)

## 1. 기존 팩트 저장소 확인

- `facts/` 전체에서 후방카메라·후진·rear camera 키워드 검색. 자동차 후방카메라를 직접 다룬 기존 팩트는 없었다.
- `공통_dashcam-selfcheck.json`의 블랙박스 후방 카메라 케이블 분리 테스트(`dashcam-reboot-camera-cable-isolation-test`)는 애프터마켓 블랙박스 구조라 거부했다(declined_facts 기록).
- `common_car-windshield-fog-selfcheck.json`, `common_car-aircon-selfcheck.json` 등 자동차 팩트는 주제가 달라 재사용하지 않았다(reused_facts 비움).
- 공통 안전 기준선(`공통_as-safety-baseline.json`)에도 후방카메라 항목은 없다.

## 2. 조사 힌트 대비 달랐던 점

- 힌트는 "렌즈 오염/습기·퓨즈·커넥터·기어 연동·AVN 설정"이었다. 공식 원문으로 확인된 것은 **기어 R 연동(기아)**, **렌즈 세척 세제 제한(현대)**, **결로·렌즈 청소 절차(테슬라)**, **가림 경고등(현대)**까지다.
- **퓨즈, 커넥터, AVN 설정**은 공식 원문에서 찾지 못했다. 커뮤니티·블로그 후기에서만 나왔고, 그 자료는 2장의 배제 규칙 때문에 팩트 JSON에서 뺐다(아래 3장).
- 공식 매뉴얼은 **화면 흐림의 점검 순서**를 제시하지 않았다. 점검 순서는 후기 조합으로만 만들 수 있다.

## 3. 배제 처리한 후기 단서 (집필 참고용, 팩트 JSON 미포함)

`scripts/lib/source-deny.mjs`의 `커뮤니티 게시판` 규칙(bobaedream·clien·ruliweb 등)과 `건강 매체·Q&A 커뮤니티` 규칙(a-ha.io)에 걸려, 아래 4건은 팩트 JSON에서 뺐다. 감사 결과 배제 0건을 맞추기 위한 조치다. 총괄이 후기 수집 정책을 바꾸면 그때 팩트로 옮긴다.

## 4. 확보한 공식 근거 (팩트 JSON에 들어간 것)

1. **기아 — 후방 카메라 사용하기(선택사양)**: 시동 상태에서 R에 넣으면 전원이 자동으로 켜지고, R에서 다른 위치로 옮기면 작동이 멈춘다. 시동 OFF 시 전원 조건은 원문에 없음.
   - https://ownersmanual.kia.com/ivi/STD_GEN5/AVN/AUS/Korean/rearcamera.html (직접 열어 확인)
2. **기아 — 사용설명서(Features 2)**: 화면만 보고 판단하지 말 것. 광각렌즈 때문에 화면 거리와 실제 거리에 차이가 있다. 어린이가 뒤에 있다고 생각되면 즉시 정지.
   - https://ownersmanual.kia.com/ivi/STD_GEN5_WIDE/AVNT_CV/KOR/Korean/002_Features_2.html (직접 열어 확인)
3. **현대 — 광각-후방 카메라 렌즈 청소**: 순한 비누·중성 세제 + 물로 씻기. 산성·알칼리성 세제 금지. 눈·비·이물질이 묻으면 주차 충돌방지 보조가 정상 작동하지 않는다.
   - https://ownersmanual.hyundai.com/full_webhelp/DN8HEV/2026/ko_KR/id6f8c73b8aef.html (직접 열어 확인. 차종 표기는 페이지에 없음)
4. **현대 — 주차 충돌방지 보조 가림 경고**: 카메라·초음파센서가 가려지면 해당 방향에 통합 경고등(X). 클러스터 유틸리티 정보 뷰 > 서비스 메시지에서 확인.
   - 같은 URL (직접 열어 확인)
5. **테슬라 사이버트럭 — 카메라 청소**: 물 분사 후 극세사로 닦고 완전 건조. 화학·마모 클리너 금지. 습하면 주 1회, 건조하면 월 1회 이상.
   - https://service.tesla.com/docs/Public/diy/cybertruck/ko_kr/GUID-2A841BB4-5730-4CA0-AC86-AA752510828F.html (직접 열어 확인)
6. **테슬라 — 결로 시 카메라 차단 경고**: 외부 주차 시 결로로 카메라 차단 경고 + 셀프드라이빙 일부 제한. 프리컨디셔닝, 성에 제거 기능, 송풍구를 도어 필러 쪽으로.
   - 같은 URL (직접 열어 확인)

## 6. 안전 주의 정리 (집필 시 반드시 유지)

- 배선을 잡아당기거나 피복을 벗기거나 트림·내장재를 뜯는 것은 하지 않는다. 정비소 영역이다.
- 열풍 드라이기로 렌즈를 말리지 않는다. 렌즈와 플라스틱이 손상될 수 있다.
- 연마제·사포·치약으로 백화를 긁지 않는다. 공식 매뉴얼은 중성 세제만 쓰라고 한다.
- R 연동 확인을 위해 차를 움직일 때는 평지, 넓은 공간, 브레이크 확실히. 차가 움직이면 즉시 P.
- 후진 시에는 화면을 믿지 말고 미러와 직접 확인한다(기아 공식 원칙).
- 커넥터 분리·재체결까지는 본인이 해볼 수 있다. 약품 사용은 차종 지침 확인 후에만.

## 7. 막힌 점·미확보

- **퓨즈 위치·번호, 커넥터 위치, AVN 외부입력 전환 절차**: 공식 원문을 찾지 못했다. 후기 출처도 1건은 404였다(m.todaysppc.com 게시글, 열 수 없음 — 사용 안 함).
- **AS 접수·보증 기준**: 공식 근거를 찾지 못했다. 집필 시 "보증 기간과 접수 경로는 차량 구매처·서비스센터에 확인"으로만 쓴다.
- **차종 표기**: 현대 DN8HEV 페이지는 차종명이 없다. 현대 쪽 팩트는 "광각-후방 카메라 장착 차량" 범위로만 쓴다.
- **시동 OFF 시 카메라 전원**: 기아 원문에 없다. 단정하지 않는다.

## 8. 권장 집필 구조(참고)

1. 증상 구분: 화면이 아예 안 나옴 / 흐림·뿌옇 / 늦게 나오거나 떨림 (기아 R 연동으로 정상 작동 조건 먼저)
2. 흐림: 외부 오염 (중성 세제 세척, 테슬라식 물 분사 + 극세사) → 결로 (성에 제거, 프리컨디셔닝) → 내부 습기 (말리기, 정비소)
3. 안 나옴: 후진등 확인 → 정차 R 반응 확인(안전 주의) → 커넥터 재체결 → 정비소
4. 정비소 기준: 후진등은 켜지는데 화면만 없음, 커넥터 재체결 후에도 동일, 주름관 흔들 때 깜빡임, 렌즈 내부 습기가 반복됨
5. 착지: 여기까지 해보고 안 되면 정비소에서 카메라·AVN·배선을 나눠 측정받는다
