# 신청 — 국민연금 가입내역·예상연금액 조회 (pension-record-lookup)

- 조사일: 2026-10-27 · 팩트: `content/research/facts/신청_pension-record-lookup.json`
- 성격: 신청이 아닌 **조회** 항목. 기한·환급이 없어 틀리면 "조회 경로 착오"가 주된 사고다.

## ★출처부족 주의
- 공식 개별 주소는 공단 전자민원 **메뉴 페이지 2종**(menuId MN24001715, MN24001727)이다. 둘 다 열람했다.
- 다만 이 두 페이지는 메뉴 목록과 "인증 필요" 표기뿐이고, **조회 화면 절차·인증 수단은 로그인 뒤라 확인하지 못했다.** 집필 게이트 기준으로는 2곳이지만 내용 밀도가 낮다. 보강이 필요하면 총괄이 판정할 것.
- 정부24 쪽 공식 문서(PTR000050236)는 자동접속 차단 응답으로 열람 실패.

## 현행 여부
- 공단 전자민원 메뉴 2종 모두 2026-10-27 열람 시 존재. 폐지 신호 없음.

## 열어 본 출처
1. https://www.nps.or.kr/elctcvlcpt/comm/getOHAC0000M3.do?menuId=MN24001715 — 가입내역·예상연금 메뉴 묶음. 가입내역조회, 예상연금액 조회, 예상연금 모의계산, 장애·유족 예상연금 조회 등 항목과 인증 여부 확인
2. https://nps.or.kr/elctcvlcpt/comm/getOHAC0000M3.do?menuId=MN24001727 (minwon 주소 리다이렉트 결과) — 가입내역조회 신청자격("가입자 또는 가입자였던 자"), 예상연금액 조회("본인이 만 60세 이후 받을 예상연금액") 확인

## 검색으로만 본 것
- "공동인증서로 로그인" 방식 — 공식 메뉴 페이지에 인증 수단이 적혀 있지 않음 → 쓰지 말 것
- "정부24에서도 같은 조회 가능" — 팩트 `record-lookup-gov24-path-unverified` (확인실패)
- "현재 소득으로 60세까지 납부한다고 가정" — 팩트 `record-lookup-expected-assumption-unverified` (확인실패)
- 모바일 앱 '내 곁에 국민연금'의 조회 메뉴 — 공식 확인 못 함, 팩트 없음

## 재사용·거부
- 재사용: `basic-pension-apply-channels` — 국민연금공단 고객센터 1355 번호. 기초연금 주제에서 확인한 번호를 공단 대표 문의처로 재사용. 가입내역 전용 번호로 쓰지 말 것.
- 거부: `national-pension-claim-with-basic-pension`(수급 중 기초연금 병행 — 조회 주제와 무관)

## 확인 못 한 것
- 가입내역조회 화면에 표시되는 항목 목록(보험료·가입기간 등) — 로그인 뒤 화면
- 인증 수단별 절차
- 가입 상실·납부예외 상태일 때 예상연금 계산 방식

## 집필 시 주의
1. 독자에게 "조회 결과는 계산 가정에 따른 예상치"라고 안내하되, 가정 내용을 공식처럼 쓰지 말 것.
2. 정부24 경로를 쓰려면 먼저 공식 페이지를 다시 열어 확인할 것(이번에는 차단됨).
