# BCAA vs EAA 조사 전문

## 조사 목표
- BCAA와 EAA의 구성 차이 및 기능
- 단백질 섭취 수준에 따른 효율 비교
- 운동 시나리오별 최적 선택 기준
- 비용-효과 분석

## 핵심 발견사항

### 1. 기본 차이: 완전성 vs 부분 집합

| 구분 | BCAA | EAA |
|---|---|---|
| **아미노산 수** | 3개 | 9개 |
| **포함 성분** | 류신, 이소류신, 발린 | 류신, 이소류신, 발린 + 메티오닌, 라이신, 트레오닌, 트립토판, 히스티딘, 페닐알라닌 |
| **기전** | mTOR 활성화만 | mTOR 활성화 + 전체 근단백질 합성 완성 |
| **제한 아미노산** | 부재 시 비효율 | 모두 포함 |

### 2. 근단백질 합성의 생화학

**류신의 역할**
```
류신 → mTORC1 신호 시작 ✓
그러나 전체 근단백질 합성 완성에는 다른 필수 아미노산 필요
```

**EAA의 우월성**
- mTORC1 활성화 (류신)
- + 단백질 합성 프레임워크 (메티오닌, 라이신 등)
- = 완전한 근단백질 합성 응답

**임상 증거**
- EAA 섭취 후 류신의 60%가 근 단백질 합성에 보유
- EAA가 근 단백질 **분해 억제**도 더 효과적
- BCAA만으로 분해 억제 입증 안 됨

### 3. 단백질 섭취 수준에 따른 효율

**시나리오 1: 단백질 충분 (1.6~2.0g/kg 이상)**
```
식이 단백질: 충분한 모든 필수 아미노산
+ BCAA 보충 = 추가 이득 거의 없음 (근 합성 이미 최대화)
+ EAA 보충 = 약간의 추가 이득 (비용 대비 효율 낮음)

권장: BCAA 또는 무시
→ BCAA가 비용 저렴하면 에너지원용으로만 사용
```

**시나리오 2: 공복 운동 또는 저단백 식이 (<1.6g/kg)**
```
식이 단백질: 불충분
+ BCAA 보충 = 제한됨 (다른 필수 아미노산 부족)
+ EAA 보충 = 효과 있음 (근단백질 합성 가능)

권장: EAA
→ 공복 운동 중 또는 저단백 식이에서만 의미 있음
```

**시나리오 3: 최고 효과 원함 + 예산 충분**
```
권장: EAA
→ 조건 없이 가장 완전한 아미노산 프로필
```

### 4. 운동 시나리오별 선택

| 상황 | 1순위 | 2순위 | 이유 |
|---|---|---|---|
| **고단백 식이 + 저항운동** | 전체 단백질 | BCAA | 비용 효율 최고 |
| **공복 운동** | EAA | BCAA | 필수 아미노산 필요 |
| **저단백 제한식** | EAA | 전체 단백질 | 불충분한 식이 보완 |
| **운동 중 에너지** | BCAA | - | 빠른 흡수, 에너지 공급 |
| **최고 품질 추구** | EAA | 전체 단백질 | 완전한 프로필 |

### 5. 비용-효율 분석

**BCAA (3개 아미노산)**
- 가격: 저 (보편적)
- 대상: 단백질 충분자
- 사용: 운동 중 에너지, 편의성
- ROI: 단백질 부족 시 낮음

**EAA (9개 아미노산)**
- 가격: 중~고 (BCAA보다 2~3배)
- 대상: 공복/저단백 섭취자
- 사용: 완전 근단백질 합성
- ROI: 저단백 식이에서 높음

**전체 단백질 (우유/유청)**
- 가격: 저 (가장 저렴)
- 대상: 모든 운동선수
- 사용: 근력·회복
- ROI: 가장 높음 (비용 대비 단백질)

### 6. 마케팅 오해 해제

| 광고 문구 | 실제 | 평가 |
|---|---|---|
| "BCAA는 근 분해를 막는다" | 입증 안 됨 | ✗ 거짓 |
| "류신으로 충분하다" | 다른 필수 아미노산도 필요 | ✗ 과장 |
| "EAA가 항상 낫다" | 단백질 충분 시 추가 이득 거의 없음 | ✗ 조건부 참 |
| "BCAA는 쓸모없다" | 에너지원·편의성은 있음 | ✗ 거짓 |

## 집필 기준

### DO
✓ "단백질이 충분하면 BCAA 추가는 비효율" 명확히
✓ 공복/저단백 시나리오에서 EAA 우월성 강조
✓ 류신의 역할과 한계 설명
✓ 비용-효과 기준 제시

### DON'T
✗ "BCAA가 최고"
✗ "류신만으로 충분하다"
✗ "항상 EAA를 사라" (비용 고려 안 함)
✗ "근 분해를 완벽히 막는다"

## 핵심 메시지
> BCAA는 운동 중 에너지와 편의성이 장점이지만, **단백질을 충분히 섭취하는 운동선수에게는 추가 이득이 거의 없다.** EAA는 더 완전하지만 **공복/저단백 상황에서만 가치**가 있다. 최고의 근 합성은 **충분한 전체 단백질 + 저항운동**으로 달성되며, BCAA/EAA는 보조 수단이다.
