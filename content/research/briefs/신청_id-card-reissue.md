# 주민등록증 재발급 — 조사 브리프 (2026-10-27)

## 조사 범위
재발급 사유, 재발급 신청 경로(온라인 포함), 수수료(IC칩 유무별), 사진·본인확인, 철회 기간, 처리 기간, 분실 신고 절차.

## 열어서 확인한 페이지 (이 세션, 렌더링 또는 원문 확인)
- https://www.law.go.kr/법령/주민등록법/제27조 : 제1항(재발급 사유 분실·훼손, 성명·생년월일·성별 변경, 대통령령 사유), 제2항(공무원 회수 및 본인 재발급 신청), 제3항(수수료·무료 예외) 확인. 시행 2025.7.22.
- https://www.law.go.kr/법령/주민등록법시행령/제40조 : 제1항(신청, 전자민원창구 포함), 제2항(철회 시한), 제3항 제1호(주소 외 사항 변경이 재발급 사유), 제4항·제5항(사진 1장, 본인확인, 지문 대조). **시행 2026.10.29 개정본 표시.** 10.29 이전 신청과 구 조문 차이는 확인하지 못함.
- https://www.law.go.kr/법령/주민등록법시행규칙/제17조 : 제1항(IC칩 없는 주민등록증 5천 원), 제2항(IC칩 내장 1만 원, 2024.12.20 신설), 제3항(IC칩 결함 시 5천 원), 제5항(철회 시 환불). **시행 2026.10.2(행정안전부령 제648호) 표시.**
- https://www.mobileid.go.kr/mip/hps/issuReqstGuidance/issuReqstGuidanceMrc.do : 재사용 팩트(준비물 사진·수수료 1만 원, 온라인 또는 주민센터 신청)와 일치 확인 — 이번 세션 직접 열람은 아니고 기존 팩트 재사용.
- https://www.law.go.kr/법령/주민등록법/제17조 (주소 관련 재확인, 이사 주제 참조).

## 검색으로만 본 것 (공식 아님)
- 블로그·언론: 정부24 온라인 재발급 가능(2021 언론 보도로는 분실 외 훼손·기재변경 등으로 확대). 수수료 5천 원·1만 원 설명 다수(시행규칙과 일치).
- 블로그: 처리 기간 "약 2주" / "방문 2~3주" (엇갈림, 공식 확인 실패).
- 블로그: 정부24 분실신고 24시간 가능, 즉시 사용 차단, 주민센터 '분실 사실 증명서' 임시 사용 (공식 확인 실패).

## 기존 팩트 재사용·거부
- 재사용: `mobile-id-issue-ic-card-route`(IC 주민등록증 신청 경로), `mobile-id-ic-card-fee-and-photo`(준비물·1만 원). 모두 같은 "IC 주민등록증 발급" 맥락.
- 거부: `resident-cert-fee-400-per-copy`(등·초본 수수료, 다른 민원), `mobile-id-age17-free-ic-unverified`(17세 최초 발급 무료, 재발급과 층위가 다름).

## 확인 못 한 것
- 정부24 메뉴 경로와 온라인 재발급 화면 자체. 공식 페이지 열람 실패(주민등록증 재발급 서비스 페이지 URL 미확보).
- 처리 기간(공식).
- 분실 신고 즉시 차단 효과(공식).
- 시행령 2026.10.29 이전 구 조문의 내용.

## 집필 시 주의
- 주소가 바뀌었다고 재발급 대상이라고 쓰지 않는다(`id-card-reissue-address-not-listed`). 법 제27조 제2항 제2호 "주요 기재내용 변경"과 혼동 금지.
- 수수료는 IC칩 유무로 나눠 쓰고, 무료 예외는 시행규칙 조문 범위에서만 쓴다.
- 온라인 경로는 "전자민원창구"라는 법 표현으로 쓰고, 정부24 메뉴명은 확인 후 쓴다.
- 분실 시에는 지체 없이 공식 신고 창구에서 신고하라고 안내한다(차단 효과를 단정하지 않는다).
