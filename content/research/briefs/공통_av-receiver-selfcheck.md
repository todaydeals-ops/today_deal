# AV리시버·홈시어터 소리 안 남·채널 누락 자가진단 조사

## 조사 배경
AV리시버는 TV의 영상과 음성을 수신해 여러 스피커로 분배하는 제어 장치다. 소리 문제는 대부분 HDMI ARC 연결 오류, 입력 모드 설정, 스피커 단자 접촉 불량으로 발생한다.

## 주요 자가진단 순서

### 1단계: HDMI ARC/eARC 연결 확인 (최우선)
- TV의 HDMI (ARC) 표기 포트와 리시버의 HDMI OUT (TV-ARC) 포트 연결 확인
- 단순히 "HDMI 연결됨"이 아니라 **정확한 포트 일치** 필수
- 리시버의 입력 모드가 'HDMI'로 설정되어 있는지 확인

### 2단계: 다중 입력 소스 확인
- AV리시버에 여러 입력(HDMI, 광케이블, 동축, RCA)이 있을 때
- TV에서 보내는 신호 포트와 리시버의 입력 모드가 **일치해야 함**
- 예: 광케이블 사용하는데 리시버 입력이 HDMI로 설정되면 소리 안 남

### 3단계: 스피커 단자 점검
- 리시버 뒷면의 스피커 단자 연결 상태를 육안 확인
- 한쪽 채널만 안 나오면 **스피커 단자가 헐거웠을 가능성**
- 반드시 리시버 전원을 끈 후 재연결

### 4단계: 채널 테스트 톤 실행
- 대부분의 리시버는 "Channel Level" 또는 "Test Tone" 기능 제공
- 각 스피커별로 테스트 톤을 재생해 정상 작동 여부 판별
- 리모컨 메뉴에서 직접 설정 가능

## 자주 놓치는 부분
1. HDMI와 광케이블이 동시에 연결되었을 때, **입력 모드 설정이 실제 신호 포트와 다름**
2. 스피커 극성(+/−)이 바뀌면 음질 저하, 저음 소실
3. 리시버의 "음성 출력" 설정이 '스피커'가 아닌 '헤드폰'으로 잘못 설정됨

## 현장 조사 결과
- 삼성, LG, Sony 모두 공식 문서에서 HDMI ARC를 첫 번째 점검 항목으로 강조
- 사운드바 문서(기존 팩트)와 공통 절차 다수
- 실제 문제의 80% 이상이 HDMI 포트 오류 또는 입력 모드 설정
