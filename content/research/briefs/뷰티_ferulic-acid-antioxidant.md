# 조사: 페룰산 — 비타민C 세럼에 함께 들어가는 이유

## 조사 배경

페룰산의 역할: 비타민C+E 조합의 화학적 안정성 향상과 광보호 효율 극대화.

## 조사 결과 요약

### 1. 페룰산의 주 역할

**역할 1 - 화학적 안정화**:
- L-아스코르브산 15% + 알파-토코페롤 1% 용액에서 두 비타민의 산화 속도 감소
- 제품의 유통기한 및 보관 안정성 개선

**역할 2 - 항산화 시너지**:
- 페룰산 자체가 자유 라디컬을 소거 (free radical scavenging)
- 비타민C, E의 항산화 능력 추가 강화

### 2. 광보호 효율 증대

**임상 데이터 (solar-simulated UV irradiation)**:
- C(15%) + E(1%)만: **4배 보호**
- C(15%) + E(1%) + 페룰산: **8배 보호** ← **2배 증대**

**평가 기준**:
- 자외선 홍반(erythema) 감소
- 선번(sunburn cell) 형성 억제

**메커니즘**:
- 분자 레벨: 카스파제-3, 카스파제-7 유도 억제
- DNA 손상: 티민 이량체(thymine dimer) 형성 차단

### 3. 표준 포뮬레이션

**입증된 조합**:
- L-아스코르브산: 15%
- 알파-토코페롤: 1%
- 페룰산: (농도 명시 안 함, 문헌상)

**pH 범위**: 일반적으로 pH 3 ~ 3.5

### 4. 안정성 향상의 의미

**제품 선택 시 체크**:
- "Vitamin C + E + Ferulic Acid" 표기 확인
- 페룰산 없는 C+E 조합보다 효과/보관 우수
- 개봉 후 갈변(oxidation) 속도 느림

## 집필 시 활용 포인트

1. **포뮬레이션 트리오**: "페룰산은 왜 들어가는가" → "안정화와 광보호 배수 증가" 설명
2. **광보호 기대치**: CEF(Vitamin C + E + Ferulic) 세럼 사용자에게 "4배 → 8배 보호" 전달
3. **선스크린 필수**: 이 조합만으로는 SPF 역할 못함 → 자외선 차단제 병용 명시
4. **보관 조건**: 페룰산 포함 제품도 개봉 후 냉장, 밀폐 보관 권장

## 확인실패 / 미확인

- 페룰산의 정확한 농도 기준 (문헌에 명시 없음)
- 국내 기능성화장품에서의 페룰산 규제 지위 (별도 조사 필요)
