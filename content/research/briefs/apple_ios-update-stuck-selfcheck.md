# 아이폰 iOS 업데이트가 멈추거나 실패할 때 — 조사 전문

- 슬러그: ios-update-stuck-selfcheck / 코너: repair / 분야: 디지털·IT
- 조사일: 2026-11-03
- 저장: `content/research/facts/apple_ios-update-stuck-selfcheck.json`

## 1. 조사 범위와 힌트 대조

총괄 힌트: "Apple 지원 공식 문서 기준 업데이트 중 멈춤/실패 대처, 백업 먼저, 컴퓨터로 업데이트, 복구 모드는 마지막".

공식 원문 확인 결과 힌트와 다른 점은 다음과 같다.

- **백업 먼저는 무선 업데이트 문서에 없다.** 108905(무선 업데이트 문제 해결)에는 백업 문장이 없다. 백업 먼저는 컴퓨터 업데이트 문서(108964, 109046)에서만 확인된다. 글에서 "무선 업데이트 전 백업 필수"처럼 쓰면 원문보다 강하게 말하는 것이다.
- **복구 모드 데이터 문장이 기존 팩트와 다르다.** 기존 `apple_device-recovery.json`의 `iphone-recovery-mode-data`는 "업데이트를 선택하면 데이터를 유지한다"를 118106에서 가져온 것으로 표기했으나, 118106 원문에는 그 문장이 없다. "복원은 전체 삭제"만 확인됐다. 기존 팩트는 수정하지 않고 disputes로 신고했다.
- **Windows 앱 이름.** 108964는 iTunes로 업데이트하라고 하고, 검색 요약에는 Apple Devices 앱 언급이 섞여 있었다. 원문 확인은 못 했으므로 확인실패로 남겼다.

## 2. 조사 순서와 근거

1. 기존 팩트 저장소 확인: `apple_device-recovery.json`(복구 모드·기종 분기), `공통_as-safety-baseline.json`(배터리·초기화 기준). 이 주제에 바로 맞는 iOS 업데이트 팩트는 없었다.
2. 웹 검색 3회(support.apple.com 도메인 제한): 무선 업데이트 문제, 컴퓨터 업데이트 절차, 오류 문서 목록.
3. 원문 WebFetch: 108905(무선 업데이트 6개 원인), 118106(복구 모드), 109046(Finder), 108964(iTunes Windows), 108308(오류 분류). iph3e504502 가이드는 목차만 열려 본문을 쓰지 않았다.
4. 공식 문서 2~3번 찾기에서 멈추고 후기 수집은 하지 않았다. 공식 문서만으로 단계 구성이 충분했다.

## 3. 단계별 정리 (원문 순서)

### 1단계: 기본 조건
- 기기 모델이 해당 iOS를 지원하는지 Apple 호환 목록으로 확인(108905).
- 저장공간: 설정 > 일반 > iPhone 저장공간에서 "사용하지 않는 App 내려놓기" 또는 앱 수동 삭제(108905).

### 2단계: 무선 업데이트 재시도
- 다운로드 느림: Wi-Fi 연결, 다른 다운로드 피하기(108905).
- "업데이트를 다운로드하려면 Wi-Fi 연결이 필요" 등 서버 오류: 같은 네트워크에서 재시도 → 다른 네트워크 또는 컴퓨터 → 여러 네트워크에서 반복되면 업데이트 삭제(108905).
- 설치 중: 전원 연결 유지. 배터리 방전 시 충전 후 기기를 켜서 완료되도록 함(108905).
- 계속 실패: 저장공간에서 업데이트 삭제 → 설정 > 일반 > 소프트웨어 업데이트에서 재다운로드(108905).

### 3단계: 컴퓨터로 업데이트
- 백업: iCloud 또는 컴퓨터(108964, 109046).
- 핫스팟 주의: 컴퓨터가 업데이트할 아이폰의 핫스팟에 붙어 있으면 다른 와이파이나 이더넷으로 전환(108964, 109046).
- Mac(Catalina 이상): Finder 절차 6단계(109046).
- Windows: iTunes 절차 8단계(108964). 기기 버튼 위치는 원문에 없음.
- 오류 시: USB 케이블(기기 구매 케이블 또는 Apple 인증), 키보드 아닌 본체 포트, 다른 컴퓨터, 보안 프로그램 확인(108308). 4005·4013·4014는 재시도 우선.

### 4단계: 복구 모드 (마지막)
- 조건: Apple 로고가 여러 분 진행 바 없이 떠 있음, 컴퓨터가 인식 못 함, "컴퓨터에 연결" 화면(118106). 원문은 먼저 컴퓨터로 업데이트를 시도하라고 함.
- 복원은 iOS 재설치와 전체 데이터 삭제(118106).
- 다운로드 15분 초과 시 "컴퓨터에 연결" 화면에서 빠질 수 있음 → 다운로드 완료 대기 후 반복(118106).
- 기종별 진입 방법은 `apple_device-recovery.json`의 `iphone-force-restart-generation-split` 참조.

## 4. 확인실패·미확인 항목

- Windows에서 Apple Devices 앱 사용 여부(확인실패).
- 복구 모드로도 실패할 때 Apple 지원 접수 경로와 보증 기준(확인실패). 글에서는 "위 단계 후 Apple 지원 또는 공식 서비스 문의"라는 일반 안내만 쓴다.
- 복구 모드 "업데이트" 선택지의 데이터 처리(원문 부재, 기존 팩트 dispute).

## 5. 집필 시 주의

- 독자는 "멈춤"에서 가장 먼저 강제 재시작을 할 가능성이 크다. 원문은 설치 중 전원 유지를 안내하며, 진행 바가 있으면 기다리는 쪽이다. 강제 재시작 금지를 원문 문장처럼 인용하지 말 것.
- 데이터 손실은 복원에서만 확인된다. 백업은 컴퓨터 경로와 복구 경로에서 강조하고, 무선 경로에서는 원문 근거 없이 "백업 필수"로 쓰지 말 것.
- 15분 수치는 Apple 원문 수치이며 인용 출처를 붙인다.
