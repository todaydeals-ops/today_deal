- 0단계: facts 디렉토리를 Grep 으로 검색해 히터·냄새 관련 기존 팩트를 찾고 원본 JSON을 읽었다. 공통_as-safety-baseline.json, 공통_electric-heater-selfcheck.json, common_heater-safety-winter-guide.json 확인.

## 2. 열람한 공식 원문
- LG전자 스스로해결 [LG 에어컨 냄새] 난방 초기에 타는 냄새가 나요 — 열람 완료. 에어컨 난방 열판 먼지, 전기히터 장착 모델은 순간 연기와 함께 타는 냄새 가능, 지속·심화 시 서비스 점검. 즉시 차단 기준과 청소 절차는 없음.
- 삼성전자서비스 스스로해결 비데 — 열람 완료. 신규 가동 시 열로 인한 일시적 냄새, 플라스틱 냄새 심하면 사용 중지·플러그 분리, 타는 냄새·단내 심하면 점검.
- 삼성전자서비스 스스로해결 건조기(초기 구입 후 타는듯한 냄새) — 열람 완료. 차단기 차단·전원 꺼짐·퍽 소리 동반 시 엔지니어 점검, 신제품 냄새는 휘발.
- 인천공단소방서 겨울철 3대 겨울용품 안전수칙 (2021-02-22) — 열람 완료. 플러그·전선 손상 확인, 가연물 제거, 외출 시 플러그 뽑기. 수치 없음.
- 소방청 보도자료 (2021-05-12) — 열람 완료. 전기히터 언급 없음. 냉·난방용품 장기 사용 자제·외출 시 플러그 뽑기 문구는 기존 팩트와 일치.
- 한국소비자원 2020 전기장판 주의보 — 열람 완료. 전기장판만 다룸. 전기히터 내용 없음(기존 팩트와 일치).

## 3. 열람하지 못했거나 근거로 쓰지 않은 것
- 소방당국 보도자료 여러 건(지역 소방서 언론 기사): 검색 요약에서 "먼지가 타며 냄새, 연기나 불꽃이 보이면 대피"라는 내용이 보였으나 원문을 열지 못해 팩트로 넣지 않았다.
- wikidocs 블로그: 403으로 원문 열람 실패, 제외.
- milemoa 커뮤니티 후기(기존 burning-smell-dust-combustion): 원문 재확인 못 함. 해당 팩트는 declined 처리하고 disputes에 tier 과대 표기를 신고했다.
- nosearch.com 출처 팩트 3건(기존 heater-power-check-order, overheat-cutoff-mechanism, overheating-dust-accumulation): 비공식 사이트라 declined.
- 청소 절차: LG·삼성·인천소방서 원문에 난방기 먼지 청소 방법이 없다. 확인실패로 남겼다.

## 4. 힌트와 달랐던 점
- 총괄 힌트의 "소방청·한국소비자원 공식 기준"은 히터 전용 원문으로는 확보하지 못했다. 소방청 2021 보도자료와 한국소비자원 2020 주의보는 히터 냄새 기준을 담고 있지 않다.
- 히터 자체의 공식 원문은 LG 에어컨 난방(전기히터 장착 모델) 1건뿐이다. 나머지 즉시 차단·타는 냄새 신호는 삼성 비데·건조기 원문을 유형으로만 참고했고, caution에 대상 제품이 다르다고 명시했다.
- 즉시 중단 신호: 원문에서 확인된 건 "플라스틱 냄새 심하면 사용 중지·플러그 분리"(비데), "차단기 차단·전원 꺼짐·퍽 소리 동반 시 점검"(건조기). 연기 지속 시간 기준은 없다.

## 5. 글 집필 시 권장 흐름 (상담가 톤)
1. 처음 켰을 때 먼지 냄새는 흔한 현상이라 보통 환기하며 지켜보면 줄어든다고 쓴다. 몇 분·몇 시간 숫자는 쓰지 않는다.
2. 플라스틱·전선 타는 냄새, 연기 지속, 차단기 차단, 퍽 소리가 나면 즉시 전원을 끄고 플러그를 뽑는다. 근거는 삼성 비데·건조기 원문(유형 참고)으로 밝힌다.
3. 사용 전 플러그·전선 피복 확인, 주변 가연물 제거, 외출 시 플러그 뽑기는 인천공단소방서 원문을 출처로 쓴다.
4. 청소는 전원을 끄고 식힌 뒤 먼지를 털어내고 환기하는 일반 원칙 수준으로만 쓴다. 원문 절차처럼 쓰지 않는다.
5. 점검이 필요한 경우 제조사 서비스센터 접수로 연결한다. 보증·접수 경로 수치는 이번 조사에서 확보하지 못했다.
