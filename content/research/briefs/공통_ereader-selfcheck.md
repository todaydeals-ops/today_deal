# 이북리더(크레마·킨들·리디페이퍼) 작동 불량·충전·동기화 자가점검 — 조사 전문

**조사 일시:** 2026-07-21  
**조사 범위:** 크레마(K-EPUB), 아마존 킨들, 리디페이퍼(리디북스)  
**기대 독자:** 이북리더 자가점검을 원하는 사용자

## 1. 크레마 (K-EPUB Crema) 자가점검

### 강제 재시작
**웹 검색:** `dmitory.com/novel` 사용자 팁에서 확인  
**방법:** 전원 버튼을 길게 누르면 메뉴(종료, 재시작, SD카드 업그레이드, 취소) 표시 → 재시작 선택

**주의:**
- 5초 이상 지속해야 할 수 있음
- 메뉴가 나타나지 않으면 버튼을 뗀 후 화면을 다시 확인할 수도 있음

### 충전기 사양
**웹 검색:** 사용자 커뮤니티 (dmitory.com)에서 권장 사항 확인  
**권장:** 5V 1A 저속 충전기, 또는 컴퓨터/노트북 USB에서 충전

**주의:**
- 고속 충전기(2A 이상) 금지 — 배터리·기기 손상 위험
- 비정품 저가 충전기도 같은 사양이라도 내부 품질이 낮을 수 있음

### 펌웨어 업데이트
**웹 검색:** 사용자 팁에서 확인  
**권장:** WiFi 연결 후 업데이트 알림이 나타나면 반드시 완료

**주의:**
- 업데이트 중 기기 전원 차단 절대 금지
- 배터리 50% 이상 확보 권장

## 2. 아마존 킨들 (Amazon Kindle E-ink) 자가점검

### 강제 재시작 (Hard Power Reset)
**웹 검색:** 다중 출처 (mspoweruser.com, pcguide.com, thetoolstrunk.com)에서 일관되게 확인

**방법:** 전원 버튼을 **40초 동안** 길게 누른다
- 킨들 로고가 나타나거나 화면이 깜빡이면 재시작 시작됨
- 40초는 최소값이며 더 길게 눌러야 할 수도 있음

**주의:**
- 저장되지 않은 책갈피는 손실될 수 있지만, 클라우드 동기화되어 있으면 복구 가능
- 강제 재시작은 30초 이상 누르는 것이 일반적 재부팅과의 차이

### 하드 리셋 (완전 초기화)
**웹 검색:** 공식 문제 해결 가이드 (thetoolstrunk.com, pcguide.com)에서 확인

**방법:** 강제 재시작 후에도 전원이 켜지지 않으면 하드 리셋
- 기기 메모리를 완전히 초기화하고 초기 설정 상태로 복원
- 이후 30분 이상 충전 후 재시도

**주의:**
- 로컬 저장 데이터(문서, 메모)는 복구 불가능
- 킨들 스토어에서 구매한 책은 클라우드에 저장되어 로그인 후 재다운로드 가능

### USB 케이블 점검
**웹 검색:** 공식 문제 해결 안내 (pcguide.com)에서 확인

**확인 사항:**
- USB 케이블 물리적 손상 여부
- 다른 정상 케이블로 시도
- 킨들 기기 USB 포트의 먼지·보풀 확인

**주의:**
- 포트 청소 시 물이나 금속 도구 금지
- 극세사 천으로만 가볍게 닦기

## 3. 리디페이퍼 (RIDI Paper) 자가점검

### 모델별 리셋 절차
**웹 검색:** 리디북스 고객센터 공식 문서 확인  
**출처:** `ridihelp.ridibooks.com/support/solutions/` 문서

#### RIDI Paper 4
1. 전원에 5분 이상 연결
2. 전원 버튼 10초 이상 눌러 부팅

#### RIDI Paper / Paper Light
1. 전원에 5분 이상 연결
2. 전원 버튼 10초 이상 눌러 종료
3. 전원 버튼 5초 눌러 재시작

#### RIDI Paper Pro
1. 위의 절차 적용 가능
2. 또는 SD카드 슬롯 아래 물리 리셋 버튼 사용 가능

### 터치 반응 문제

#### 화면 전체가 터치되지 않는 경우
**절차:**
1. 전원 버튼 짧게 눌러 슬립 모드 진입 확인
2. 슬립 모드로 변경되지 않으면 → 기기가 먹혔거나 배터리 부족
3. 전원 끄고 다시 켜서 재시작
4. 재시작 후에도 터치 불작동 → 하드웨어 결함 가능성 높음

**A/S 신청:** 리디북스 고객센터 1644-0331

#### 화면의 일부만 터치되지 않는 경우
- 하드웨어 터치 센서 불량
- 소프트웨어 조치로 복구 불가능
- A/S 신청 필수

## 4. 공통 E-ink 이북리더 자가점검

### 화면 잔상 (Ghosting) — 정상 특성
**웹 검색:** 밀리의 서재 E-ink 가이드 (`install.millie.co.kr/guide/eink-guide_210201.pdf`), 전자책 단말기 기술 정보 (나무위키)

**설명:**
- E-ink는 기술적으로 페이지 전환 시 이전 이미지가 일부 남는 특성이 있음
- 이는 기기 불량이 아니라 정상적인 디스플레이 기술 특성

**해결 방법:**
- 새로고침(Full Refresh) 기능 사용
- 이북리더 설정의 '새로고침 모드' 조절

### 새로고침 모드 조절
**출처:** 밀리의 서재 E-ink 가이드

**설정 효과:**
- 새로고침 빈도 높음 → 잔상 감소 ↔ 페이지 전환 느림
- 새로고침 빈도 낮음 → 페이지 전환 빠름 ↔ 잔상 증가

**주의:** 제조사·모델별로 메뉴명과 위치가 다를 수 있음 (디스플레이, 화면 설정 등)

### 책 다운로드 및 계정 동기화
**웹 검색:** 밀리의 서재 E-ink 가이드에서 확인

**절차:**
1. 서점 앱(크레마 서비스, 킨들 스토어, 리디북스)에서 계정 로그인
2. 책 선택 → 다운로드 버튼 클릭
3. 다운로드 후 기기에 저장됨
4. 같은 계정으로 다른 기기에서도 같은 책 목록 조회 가능

**주의:**
- 새 책 다운로드는 WiFi 필수
- 다운로드는 WiFi 환경에서만 가능할 수 있음

### WiFi 동기화
**웹 검색:** 밀리의 서재 E-ink 가이드

**원칙:**
- 책 목록과 읽은 진행 상태 동기화는 WiFi 필수
- WiFi 미연결 상태에서는 미리 다운로드된 책만 읽을 수 있음

### WiFi 연결 문제 해결
**방법:**
1. 라우터 재시작
2. 이북리더의 저장된 네트워크 제거 후 다시 연결
3. 이북리더 재시작

**주의:**
- 이북리더는 2.4GHz WiFi만 지원하는 경우 많음
- 라우터에서 2.4GHz 대역 활성화 확인 필요

### 색온도 조절
**웹 검색:** 밀리의 서재 가이드

**기능:** 백라이트의 색상을 조절하여 읽기 환경에 맞게 설정
- 조명 아이콘 누르기
- 따뜻한/차가운/은은한 온도 선택 또는 수동 조절

**권장:**
- 밤: 따뜻한 색온도 (블루라이트 감소 → 수면 방해 줄임)
- 낮: 차가운 색온도 (화면 더 밝게 느껴짐)

### 배터리 빠른 소모 원인
**웹 검색:** 전자책 단말기 사용자 커뮤니티

**주요 원인:**
1. WiFi 항상 켜기
2. 백라이트를 높은 밝기로 지속 사용
3. 펌웨어 업데이트/인덱싱 작업 진행 중
4. 불안정한 WiFi 신호로 인한 재연결 반복
5. 오래된 배터리 열화

**해결:**
- WiFi 필요 시에만 켜기
- 백라이트 밝기 낮추기
- 펌웨어 업데이트 후 몇 시간 방치 (백그라운드 인덱싱 완료 기다리기)

### 저장공간 부족
**방법:**
1. 더 이상 읽지 않는 책 삭제
2. 캐시 파일 정리
3. 불필요한 문서 제거

**주의:**
- 구매한 책을 삭제해도 클라우드에는 저장됨
- 대부분 서점에서 다시 다운로드 가능

### 물 노출 시 조치
**웹 검색:** Apple Support (전자기기 공통 원칙)

**절차:**
1. 즉시 전원 끄기
2. 수건으로 외부 닦기
3. 통풍이 잘되는 곳에서 **최소 24시간** 자연 건조
4. 완전히 건조된 후 전원 켜기

**주의:**
- 급하게 전원을 켜거나 충전하면 단락·배터리 손상 위험
- E-ink 이북리더는 대부분 완전 방수가 아님
- 2인치 이상 물에 노출 시 서비스센터 점검 필수

### 펌웨어 업데이트의 중요성
**출처:** 제조사 일반 안내

**효과:**
- 배터리 관리 최적화
- 안정성 개선
- 버그 수정

**절차:**
1. WiFi 연결 상태에서 설정 메뉴 확인
2. 업데이트 있으면 설치
3. 업데이트 중 기기 전원 차단 절대 금지
4. 배터리 50% 이상 유지

## 5. 조사 과정에서 발견한 주요 사항

### 각 제조사별 강제 재시작 방법의 차이
- **크레마:** 전원 버튼 길게 누르면 메뉴 출현 → 선택
- **킨들:** 전원 버튼 40초 정확히 누르기
- **리디페이퍼:** 모델별로 방법 완전히 다름 (5분 선충전, 버튼 길이 등)

이북리더는 태블릿이나 스마트폰과 달리 기기별 버튼 배치가 다르고, 리셋 절차가 매우 상이하므로 정확한 기기 모델 확인이 필수다.

### E-ink 특성의 정상화
전자책 리더의 가장 흔한 "불만" 중 하나인 화면 잔상은 완전한 불량이 아니라 기술적 특성이다. 이를 이해하면 불필요한 A/S 신청을 줄일 수 있다.

### 크레마의 충전기 사양 명시의 필요성
공식 문서를 찾지 못했으나, 사용자 커뮤니티에서 "5V 1A"가 일관되게 권장되고 있다. 이는 리튬 배터리의 안전 충전 기준과도 일치한다.

### 리디페이퍼의 모델별 차이
리디페이퍼는 모델에 따라 리셋 절차가 완전히 다르다는 점이 중요하다. 잘못된 절차를 따르면 기기가 부팅되지 않을 수 있다.

### 물 노출 시 조치
이북리더는 스마트폰보다 방수 기능이 약하므로, 우발적 물 노출 후 정확한 대처가 중요하다.

## 7. 미해결 항목 및 재조사 필요 영역

1. **크레마의 공식 설명서:** K-EPUB 웹사이트 직접 접근 불가 (연결 오류)
   - 사용자 후기로 대체함

2. **각 이북리더의 배터리 성능 상태 조회 방법:**
   - 아이패드/갤럭시탭에서는 배터리 건강 메뉴가 있으나, 이북리더는 미조사
   - 자가점검 범위 외로 판단

3. **물 노출 저항 등급(IP 등급) 명시:**
   - 이북리더별로 방수 기능이 다르지만, 공식 스펙을 모두 확인하지 못함
