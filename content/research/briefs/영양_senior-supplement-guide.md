# 노년층 영양제 안전 가이드: 약물 상호작용과 신기능 저하

## 조사 범위
- 노년층의 다약제(polypharmacy) 현황
- 나이와 신기능 저하의 관계
- 약물-영양제 상호작용 위험
- 부모님께 추천할 때 필수 체크리스트

## 신규 팩트 요약

### 1. 노년층 다약제 현황 (신규 수치 확보)
- **정의**: 5개 이상 약물 동시 복용
- **65세 이상**: 44% 다약제 복용
- **80세 이상**: 50% 근처
- **영향**: 약물 부작용 위험 3~10배 높음

### 2. 신기능 저하 (나이와의 연관)
- **기본 기전**: 신장 기능은 나이와 함께 저하
- **약물 배출 영향**: 신장 배출 약물/영양제 축적 위험
- **만성신질환(CKD) 겹치면**: 부작용 위험 3배 추가 증가

### 3. 영양제와 약물의 일반적 상호작용 (기존 파일 보강)
- **항응고제 + 비타민 K 고함량** → 항응고제 효과 상쇄 (혈전 위험)
- **갑상선약 + 칼슘/철분** → 갑상선약 흡수 방해 (최소 2~4시간 간격)
- **항생제 + 프로바이오틱스** → 항생제가 유익균 사멸 (2시간 이상 간격)
- **지용성 비타민 고함량 + 신기능 저하** → 축적 독성 위험

### 4. 노년층 특화 고려사항 (신규)
- **신기능 검사 먼저**: creatinine, eGFR 확인 필수
- **간단한 복용 계획**: 인지 저하 고려 → 하루 1~2회, 단순한 스케줄
- **전문가 검증 필수**: 담당의·약사와 현재 약물 목록 함께 리뷰
- **상한섭취량(UL) 엄격히**: 젊을 때보다 더 보수적

### 5. 실제 상담 시나리오

**"부모님이 뼈에 좋다며 칼슘제 먹고 싶다"**
- 먼저: 현재 복용 약물 목록 확인 (갑상선약? 항생제?)
- 간격: 다른 약과 최소 2시간 떨어뜨림
- 형태: 구연산칼슘이 나음 (위산 불필요)
- 용량: 500mg 초과 금지, 하루 1회 또는 2회 분할
- 신기능: creatinine, eGFR 정상 범위 확인

**"고혈압약 먹으니 영양제를 더 먹으면 낫지 않을까?"**
- 절대 금지: 전문가 상담 없이 자의 추가 금지
- 이유: 약물 상호작용으로 오히려 혈압 급격한 변화 가능

**"매일 복용이 복잡해서 건너뛴다"**
- 해결: 약국에서 일주일 단위 알약 관리 상자(pill organizer) 준비
- 간병인 감시: 복용 확인 누군가 담당

## 집필 관점
- **타겟**: "부모님 영양제 고르는 자녀" 또는 "노년층 본인"
- **톤**: 위험 경고가 아니라 "이 순서대로 체크하면 안전해요"
- **체크리스트**:
  1. 현재 약물 목록 의사/약사에 보여주기
  2. 신기능 검사(creatinine, eGFR) 확인
  3. 간격 규칙 정하기 (2~4시간 이상)
  4. 복용 계획 간단하게 (하루 1~2회)
  5. 3개월 후 의사와 다시 검토
