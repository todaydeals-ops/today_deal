- 재사용: 없음
- 거부: 없음

## 현행 여부
- 자동차리콜센터 리콜대상확인 페이지(car.go.kr/ri/recall/list.do) 조회 시점 2026-10-27 운영 중.
- 자동차관리법 제31조(제작 결함의 시정 등): `[시행 2026. 10. 2.]` 표시 → 현행.
- 시행 예정 개정 없음으로 판단(확인 범위 내).

## 운영 기관
- 리콜대상확인 페이지 하단 표기: **한국교통안전공단 자동차안전연구원**(경기도 화성시 송산면), 대표 080-357-2500.
- 제도 주체는 국토교통부(보도자료에서 "자동차리콜센터에서 리콜대상 여부 확인 가능"으로 안내). 힌트 "자동차리콜센터"는 맞음.
- 힌트 정정 없음. 법 근거는 제31조(힌트에 조문 번호 없음).

## 확인 못 한 것
- **회원가입 불필요, 앱에서 리콜 확인 가능** — 검색 요약에만 있음(정책뉴스 newsId=148888319 제목만 봄). `확인실패`로 기록.
- 긴급리콜 차대번호 공공데이터(data.go.kr 15150243) — 검색 목록에만 있음. 열지 않음.
- 차대번호를 모를 때 확인하는 방법 — 조사 범위 밖.
- 자동차관리법 제30조(자기인증) — 리콜 조문이 아니라 열었으나 팩트화하지 않음.

## 주의 (집필자용)
- **운영 기관 표기는 한국교통안전공단.** "국토교통부 운영"으로만 쓰면 페이지 표기와 어긋남. 제도(법·명령)는 국토교통부.
- **조회 가능 시간은 평일 업무시간.** 주말·야간에는 안 될 수 있음.
- **조치여부는 이전 분기까지 반영.** 방금 한 수리가 안 보일 수 있음 → 대리점 기록 확인 안내.
- **환경부 리콜은 이 서비스 대상이 아님.**
- **리콜 의무 조문은 '공개와 시정조치'를 정함.** 자동 수리를 보장하는 조문이 아님. 수리 일정·비용은 제작사 안내를 따르도록 쓸 것.
- 보도자료의 리콜 대수·차종 수치는 발표 시점 기준. 현재 수치로 바꿔 쓰지 말 것.
