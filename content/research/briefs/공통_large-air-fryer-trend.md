# 대용량·오븐형 에어프라이어 트렌드 조사

## 배경
"에어프라이어는 작은 거 아닌가?" → 최근 5L~12L 대용량과 오븐 구조의 제품이 급증. 비스포크 큐커, 디시(DICI), 자일렉(Zillec) 등 고가 오븐형도 시장 진입. 트렌드랩에서 실제 구매 타겟의 의사결정 기준을 조사.

## 핵심 조사 결과

### 1. 용량·구조별 특징
**바스켓형 (3~7L)**
- 가정용 냉동식품·간식·닭날개 조리
- 바스켓 분리 세척 가능 → 청소 편함
- 예열 3~5분 (필립스는 불필요 권장)
- 가격 5~30만원대

**오븐형 (7~12L 이상)**
- 통닭, 피자, 홈베이킹 가능
- 선반/트레이 등 부품 많음
- 도어·벽면 기름 때는 닦음만 가능 → 청소 번거움 (최대 불만)
- 가격 20~100만원대

### 2. 가열 방식의 실제 차이
**비스포크 큐커 (삼성)**
- 직화열풍: 음식 표면 중심으로 먼저 익힘
- 에어프라이어 모드는 전자레인지 동시 작동 → 일부 식품에서 딱딱하게 굳어지는 사례 보고
- 제과제빵 예민한 요리에는 비추천 (냉각팬이 자동 작동)

**LG 디오스 광파오븐**
- 광파 + 열풍: 균등하고 빠른 가열
- 조리 모드 수가 압도적으로 많음

### 3. 예열·조리시간
- **예열**: 두 종류 모두 3~5분 권장 (일부 제조사는 불필요라 명시)
- **조리시간**: 오븐 기준 대비 온도 20도 낮추고 시간 20% 단축
- 오븐형이 "예열 길다"는 평은 과장 — 체감상 큰 차이 없음

### 4. 전기료 비교
- **소비전력**: 5L 바스켓 1700W ↔ 12L 오븐형 1800W (용량 차이 대비 거의 비슷)
- **실제 전기료**: 표기 전력의 절반 수준만 소비
- **사용시간**: 대부분 30분 이내 → 월 누적 부담 미미
- **결론**: 전기료는 오븐형 선택 제약 요소 아님

### 5. 청소 및 유지보수
**바스켓형**
- 바스켓 분리 → 물 세척 가능 → 10분 이내 완료
- 바스켓 이중 분리 가능하면 더 편함

**오븐형 (최대 불만점)**
- 내부 벽면: 닦음만 가능, 물 세척 불가
- 열선 주변: 기름 때 정리 어려움
- 도어 유리: 별도 유리 전용 세정제 필요
- 예상 시간: 30분 이상 소요
- 정기 청소 권장: 기름 요리 자주 시 2주, 일반 사용 1개월

### 6. 듀얼바스켓 기능 (2개 바스켓 동시 조리)
- **장점**: 생선 + 치킨 동시 조리 시 냄새 분리 가능
- **온도·시간 개별 조절**: SMART FINISH로 완성 시간 맞출 수 있음
- **에너지 효율**: 2회 조리하는 것보다 전력 절감
- **현실적 한계**: 2개 바스켓이 정확히 다른 요리를 필요로 하는 경우가 일상에서 얼마나 자주 있는가?

### 7. 4인 이상 가정의 실제 필요성
**오븐형이 유리한 경우**
- 통닭 조리 (바스켓형은 통닭 들어가지 않음)
- 홈베이킹 정기적 시 (온도·습도 제어 필요)
- 한 끼 5인분 이상 동시 조리
- 로스팅·피자 등 다양한 요리

**바스켓형도 충분한 경우**
- 매일 냉동식품, 간식 수준
- 통닭은 1년에 몇 번 수준 → 오븐 이용 가능
- 4인 가족이라도 일일 조리 2회 분산 가능

## 판매 제약 요소 (구매 의사결정)

| 요소 | 중요도 | 실제 임팩트 |
|---|---|---|
| **청소 번거로움** | ⭐⭐⭐⭐⭐ | 최대 불만 — 포기 요인 |
| **가격** | ⭐⭐⭐⭐ | 20~100만원 편차 — 선택의 폭 |
| **주방 공간** | ⭐⭐⭐⭐ | 오븐형은 큰 박스 — 배치 필수 |
| **예열·조리시간** | ⭐⭐ | 과장된 불만 — 실제는 비슷 |
| **전기료** | ⭐ | 거의 제약 요소 아님 |
| **조리 기능 다양성** | ⭐⭐⭐⭐ | 통닭·베이킹 필요시만 중요 |
| **듀얼바스켓** | ⭐⭐ | 마케팅 용어 — 실제 활용도 낮음 |

## 최종 판별 기준: "가족 많거나 통닭·오븐요리 하면 유리, 1~2인엔 과하고 청소 부담"

### 오븐형 추천 (7L~)
- 4인 이상 가정
- 통닭 정기적 조리
- 베이킹·로스팅 습관
- 주방 공간 여유 있음
- 정기 청소(1~2주) 받아들이는 용의

### 바스켓형 충분 (3~5L)
- 1~2인 가정
- 냉동식품·간식 중심
- 청소 편의성 최우선
- 주방 공간 제약
- 용량 부족 시 2회 조리 가능

### 비스포크 큐커 추가 고려
- 제과제빵 예민한 경우 미추천 (냉각팬 자동 작동)
- 전자레인지 동시 작동으로 일부 식품 문제 (딱딱하게 굳음)
- 프리미엄 가격 대비 실제 성능 "애매하다"는 사용자 평가 다수
