# 유치원 입학 신청 — 조사 전문 (2026-10-27)

## 1. 현행 여부 판정
- "처음학교로" 단독 창구는 현행이 아니다. 2024년 11월 정책브리핑 기사(공식)에 따르면 어린이집 입소·유치원 입학 신청은 통합 창구 **유보통합포털(enter.childinfo.go.kr)** 로 이뤄졌다. 이 판정은 status 팩트로 남겼다.
- 주의: 이 기사는 2024년 11월 게재분이며 2025학년도 기준이다. 2026년 10월 현재 같은 창구인지는 2026년 교육부 보도자료가 "유보통합포털 통합 검색·찜하기"를 언급하므로 연속성이 확인된다(같은 창구로 판단).

## 2. 2027학년도 일정 (확인된 것)
- 교육부 보도자료(2026.10.15, "어린이집·유치원 입소·입학 신청, 더 쉽고 편리해진다") — 원문 URL(moe.go.kr boardSeq=107428)은 WebFetch 시 "페이지를 찾을 수 없음" 응답. KDI 경제교육·정보센터 게재본(https://eiec.kdi.re.kr/policy/materialView.do?num=288141)을 열어 **본문을 직접 확인**했다.
  - 게재 본문: "11.2.(월)부터 시작되는" 2027학년도 신학기 입소·입학 신청.
  - 0~5세 학부모 선제 알림, 유보통합포털 통합 검색·찜하기, 행정정보 연계 최대 20종 서류 온라인 제출.
- 2차 출처(육아크루 블로그, 2026.10.18 작성): 자녀 등록·찜하기 10월 28일(수) 시작, 연계 서류 어린이집 6종·유치원 14종. → **공식 원문에서 못 찾음**, 확인실패로 기록.

## 3. 확인 못 한 것 (확인실패)
- 2027학년도 유치원 우선모집·일반모집·추가모집 기간: 공식 공고 미열람. 검색 결과 없음.
- 교육청별 모집요강: 미열람(지역별 상이).
- 찜하기 시작일(10.28): 블로그 단일 출처.
- 서류 6종/14종 분할: 블로그 단일 출처.

## 4. 참고만 한 과거 일정 (재사용 금지)
- 2024년 11월 정책브리핑 기사: 2025학년도 유치원 우선모집 11월 1~5일, 일반모집 11월 20~22일(온라인접수). 과거 학년도라 2027학년도 날짜로 쓰면 안 된다.
- 블로그 검색결과의 "2026학년도 우선 11.3~5 / 일반 11.17~21" 기재도 연도 표기가 섞여 있어 쓰지 않음.

## 5. 검색 사용 (세션 전체 6회 중)
- 검색 1회: "처음학교로 2027학년도 유치원 모집 일정" — 블로그 중심, 공식 원문 없음.
- 검색 2회: "2027학년도 유치원 입학 유보통합포털 신청 일정 교육부 보도자료" — 정책브리핑 2024 기사 확인, 2026.10.15 보도자료 존재를 2차로 확인.
- 검색 3회: 교육부 보도자료 2026.10.15 키워드 — KDI 게재본 URL 획득.

## 6. 집필 시 주의
- 신청 창구는 유보통합포털. 2027학년도 입소·입학 신청 시작은 11월 2일(월). 찜하기 10월 28일은 "공식 원문 미확인 · 공지 확인 필요"로만.
- 유치원 우선·일반 모집 날짜는 "교육청 모집 공고에서 확인"으로 안내하고, 2024년 날짜를 옮겨 쓰지 말 것.
- 죽은 교육부 원문 링크는 글 출처에 쓰지 말 것. KDI 게재본을 쓰되 원문 재확인 후 교체.
