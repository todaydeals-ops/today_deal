# 세탁기 급수 불량 자가점검 조사 (washer-no-water-supply-selfcheck)

- 코너: repair / 분야: 가전
- 조사일: 2026-11-03
- 팩트 파일: `content/research/facts/common_washer-no-water-supply-selfcheck.json`
- 기존 팩트 재사용: 0건 (세탁기 급수 관련 기존 팩트 없음. 재사용 후보는 모두 제품군이 달라 declined)

## 1. 조사 범위와 결과 요약

힌트로 받은 범위(수도 잠김, 급수호스 꺾임, 필터 막힘, 동파, 수압, 점검 순서, 동파 대처, 제조사 기준, AS 기준)를 공식 문서 위주로 확인했다.

- 급수 불량 원인과 점검 순서: 삼성전자서비스 공식 페이지 2건(41652, 41702)과 LG전자 공식 IE 안내 1건을 직접 열어 확인.
- 겨울철 해동: 삼성전자서비스 해동 안내(1840480) 직접 확인. LG 해동 절차는 LG IE 안내 본문(호스 50도 이하)만 직접 확인했다. LG 세탁통 해동(50~60도, 1~2시간)은 2013년 경향신문 보도 인용이라 `후기`로 표기했다.
- AS 기준: 삼성 41702(출장 예약·요금), LG IE 안내(단수 시 유상, 고객센터 1544-7777)를 직접 확인.

## 2. 힌트와 달랐던 점

1. **LG IE "8분 기준"은 원문에서 확인되지 않았다.** 검색 요약에는 "8분이 지나도 물이 안 차면 IE"라고 나왔지만, 같은 주소 원문을 열어 보니 시간 기준 문구가 없었다. 팩트에 넣지 않았다(lg-ie-meaning의 caution에 기록).
2. **4C/4E 설명 페이지가 한 곳이 아니다.** 검색 요약은 41652에도 4C/4E가 있다고 했지만, 원문에는 없었다. 4C/4E 의미는 41702에서 확인했다.
3. **해동 온도가 제조사마다 다르다.** 삼성은 수도 밸브 수건과 배수 호스를 50~60도, LG는 호스를 50도 이하로 안내한다. 두 기준을 모두 적고 tier를 `논쟁`으로 뒀다. 독자에게는 "50도 이하로 시작 → 안 녹으면 설명서 기준"으로 쓸 수 있다.
4. **삼성 세탁조 온수량이 같은 페이지 안에서 두 기준이다.** 배수부 해동은 "세탁조 용량의 약 3분의 1", 잔수부 해동은 "약 10리터"로 적혀 있다. 두 값을 모두 기록하고 모델 용량 확인을 caution에 넣었다.
5. **LG 수압 기준(30~1000 kPa)은 팩트에 넣지 않았다.** 검색 발췌에서 나왔지만 LG 설명서 PDF 본문을 읽지 못했다(바이너리로만 반환). 출처를 열어 읽지 못한 수치라 인용하지 않는다. 수압 항목은 "정확한 수치는 제품 설명서의 사용 수압 항목 확인"으로 쓰는 것이 맞다.
6. **삼성 가이드의 "급수·배수 호스 3m 이내" 문구**는 검색 요약에만 있고 원문에서 확인하지 못해 제외했다.
7. **Miele 세탁기 설명서의 최소 100 kPa**는 국내 브랜드가 아니고 원문을 열지 않아 제외했다.

## 4. 확인하지 못한 것 (확인실패 처리하지 않고 본문에서 제외)

- LG 세탁기 사용 수압 범위(30~1000 kPa) 원문 확인 실패: PDF 본문 미확인.
- LG 해동 절차의 현행 원문: LG 현행 공식 페이지에서 찾지 못했다. 2013 보도 인용만 남았다.
- 급수 솔레노이드 고장 시 서비스 안내: 검색 요약에만 있고 원문에서 확인하지 못했다.

## 5. 집필 시 주의

- 독자는 "수도꼭지 → 호스 꺾임 → 냉온수 연결 → 거름망 → 해동 → AS" 순서로 따라가면 된다. 각 단계 끝에 "여기서도 안 되면 다음 단계"를 붙인다.
- 해동 온도는 두 제조사 기준을 같이 쓰고 "설명서 우선"을 명시한다. 한쪽 숫자만 단정하지 않는다.
- 요금·보증은 "구입일 증빙과 센터 안내에 따라 다르다"로 쓰고 금액을 단정하지 않는다.
- 연락처는 발행 직전 공식 페이지에서 한 번 더 확인한다(삼성 1588-3366, LG 1544-7777).
