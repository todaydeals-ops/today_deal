# 관절 건강 영양제 비교: 글루코사민, 콘드로이틴, MSM, 보스웰리아, 콜라겐

## 조사 범위
- 5가지 성분의 생화학적 기전 정리
- 각각의 임상 근거 수준 비교 (특히 GAIT 시험 관련)
- "예방"과 "진행 지연"의 구분
- 선택 가이드

## 신규 팩트 요약

### 1. GAIT 시험 요약 (이미 기존 파일에 있으나 재확인)
- **규모**: 1,583명, 24주, 무릎관절염 (최대 규모 NIH 시험)
- **결과**: 
  - 글루코사민 64% vs 위약 60% → 유의 차이 없음
  - 콘드로이틴 65% vs 위약 60% → 유의 차이 없음
  - 병용 66% vs 위약 60% → 유의 차이 없음
  - **예외**: 중등도-심한 통증 부분군에서 병용이 유의성 보임 (사후분석 = 확인 필요)

### 2. 각 성분별 근거 수준 정리

| 성분 | 기전 | 임상 근거 | 비고 |
|------|-----|---------|------|
| 글루코사민 | 연골 기질 합성 | GAIT 음성 | 형태(황산염 vs 염산염) 차이 미미 |
| 콘드로이틴 | 단백질분해 억제 | GAIT 음성(부분군만+) | 기전 이론적 |
| MSM | 황 공급원 | 소규모 연구만 | 대규모 RCT 없음 |
| 보스웰리아 | 항염증 성분 | 일부 양성 | GAIT 미포함, 직접 비교 근거 없음 |
| 콜라겐 | 구조 단백질 | 피부 효과만 주로 | 관절/피부 효과 분리 필요 |

### 3. 주요 해석
- **"효과 없다" ≠ "피해 없다"**: GAIT는 1차 분석에서 통계적 차이 없었으나, 부분군(중등도-심한 통증)에는 가능성 있음
- **부분군 분석의 한계**: 사후 분석이므로 재확인 필요. 모든 무릎관절염 환자에게 효과 있다는 보장 아님
- **MSM/보스웰리아**: 근거 미약하지만 안전성은 높음

### 4. 집필 관점
- "뭐 먹을까?" → "먹어보고 3개월 후 판단" (GAIT 결과상 기대치 낮춤)
- "병용이 더 나은가?" → "일반인엔 아니지만, 중등도-심한 통증 있으면 시도 가능"
- "최신 성분(콜라겐, 보스웰리아)은?" → "연구 더 필요. 안전하면 해봐도 됨"
