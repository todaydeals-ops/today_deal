# 혼인신고 — 조사 전문 (2026-10-27)

## 1. 확인한 페이지 (이번 세션에 실제로 열어 본 것)
- 민법 제812조 — https://www.law.go.kr/법령/민법/제812조 (본문 확인: 제1항 신고로 효력, 제2항 쌍방+성년 증인 2인 연서 서면)
- 가족관계등록법 제23조 — https://www.law.go.kr/법령/가족관계의등록등에관한법률/제23조 (제1항 서면·말, 제2항 본인 불출석 시 신분증 또는 인감증명서, 둘 다 없으면 수리 금지)
- 가족관계등록법 제36조 — 열었으나 혼인신고와 무관(외국 서류 송부). 팩트로 쓰지 않음.

## 2. 실패한 것
- 가족관계등록법 제33조: 두 차례 렌더링했으나 본문 0자. 혼인신고 조문으로 단정하지 말 것. 확인실패.
- 온라인(전자문서) 혼인신고 가능 여부: 대법원 공식 안내를 찾지 못함(검색 결과는 법무사·지자체·블로그). 확인실패.

## 3. 검색 사용 (세션 전체 6회 중)
- 검색 1회: 혼인신고 방법·온라인 신고 키워드. 결과는 비공식 블로그·법률 요약 사이트뿐이었음. 그중 korea.legal(제23조 요약)은 원문을 직접 열어 교차했음.
- 블로그의 "증인 없으면 수리 거부" 같은 주장은 조문으로 확인되지 않아 팩트에 넣지 않음.

## 4. 법정 기한
- 이번 조사에서 혼인신고 기한 조문을 확인하지 않았다. 기한(예: 신고 기간) 문장은 쓰지 말 것.

## 5. 집필 시 주의
- "신고해야 효력이 생긴다"까지가 확실. 예식·동거와 법률상 혼인을 섞지 말 것.
- 증인 2인은 서면 신고 요건. 구두 신고와 섞지 말 것.
- 온라인 신고 경로는 확인 전까지 쓰지 말고, 쓸 땐 대법원 페이지를 새로 열어 확인할 것.
