## 1. 기존 팩트 재사용 (0단계)

`content/research/facts/` 에서 프린터·Wi-Fi·공유기 관련 팩트를 먼저 읽었다.

- 재사용 10건: HP 무선 재연결·WPS·USB/Wi-Fi 확인·콜드 리셋·고객센터, Canon Wi-Fi 기본 확인(2.4GHz 주의 포함)·WPS, 2.4GHz 간섭(TP-Link 공식), 공유기 재부팅 우선·통신사 공유기 초기화 상담.
- 거부 4건: 오프라인 표시 해제, 드라이버 재설치, 프린트 헤드·카트리지 청소. 모두 연결이 된 뒤의 단계이거나 인쇄 품질 문제라 이번 글의 범위와 다르다.
- 공통 안전 기준선(`공통_as-safety-baseline.json`)은 이 주제와 직접 겹치지 않아 재사용하지 않았다.

## 2. 새로 확보한 근거 (웹 검색 4회, 페이지 열기 5회)

| 출처 | 확인 | 내용 |
|---|---|---|
| HP코리아 — "연결하려는 무선 네트워크 이름(SSID)이 검색되지 않습니다" (cs-apj-static.ext.hp.com) | 열어 확인 | 2.4GHz 전용 프린터가 많음, 듀얼밴드 공유기의 5GHz 쪽만 방송될 때 발생, 컴퓨터와 프린터를 둘 다 2.4GHz에 연결 또는 공유기 제조사 문의, 네트워크 이름 알림 확인 |
| Epson 공식 매뉴얼 — 프린터가 무선 라우터를 찾거나 연결할 수 없는 경우 (files.support.epson.com) | 열어 확인 | 대역별 SSID 분리, 듀얼 밴드 모드, 숨김 SSID 직접 입력, 거리·간섭원 회피, MAC 필터링, 비밀번호·보안 방식, 고정 IP(EpsonNet Config) |
| HP코리아 — HP 프린터 IP 주소가 변경되었을 때 새 IP 갱신 (cs-apj-static.ext.hp.com) | 열어 확인 | 공유기 재부팅·교체 후 IP 변경, 길잡이 유틸리티에서 IP 갱신·테스트·저장·재시작, 제어판·보고서로 IP 확인 |

검색 결과에만 나오고 열지 못한 페이지:
- support.hp.com/kr-ko/document/c03311525 (IP 주소 확인 방법): 두 번 시도했으나 시간 초과로 열리지 않았다. 169.254.x.x, 0.0.0.0 같은 "IP 할당 실패" 주소 판정 문구는 이 페이지 출처였으므로 팩트에서 뺐다.
- Canon 공식 페이지: 검색으로 찾지 못했다. Canon 커뮤니티 글(Smart Connect 단일 이름 끄기 제안 등)은 공식 문서가 아니고 열어 확인도 못 해서 팩트로 넣지 않았다.

## 3. 공통 점검 순서 (집필 참고 — 근거 기반)

1. 프린터 전원 재시작, 공유기 재부팅 (기존 팩트, 콜드 리셋은 HP 공식)
2. 프린터 Wi-Fi 표시등·무선 메뉴 확인, 같은 공유기에 연결돼 있는지 (HP·Canon 공식)
3. 공유기 대역 확인: 2.4GHz 이름이 방송되는지, 5GHz 쪽만 보이면 2.4GHz에 연결 (HP·Epson 공식)
4. 2.4·5GHz 이름이 같으면 분리, 숨김 SSID면 직접 입력, 이름 알림·MAC 필터 확인 (Epson·HP 공식)
5. 비밀번호 보안 방식과 정확한 입력 (Epson 공식)
6. 프린터를 공유기 가까이, 전자레인지·2.4GHz 무선전화에서 떨어뜨리기 (Epson 공식)
7. 연결은 됐는데 인쇄가 안 되면 IP 변경 여부 확인 후 PC 쪽 프린터 주소 갱신 (HP 공식)
8. 그래도 안 되면 WPS 방식 (HP·Canon 공식), 마지막으로 공유기 초기화는 통신사 공유기면 고객센터 먼저 (기존 팩트)

## 4. 공백과 한계

- **AS 접수 기준·보증 조건**: 공식 출처에서 확인하지 못해 팩트를 만들지 않았다. HP 한국 고객센터 연락처는 기존 팩트(`hp-customer-center-korea`)를 재사용한다.
- **엡손 IP 자동 할당 실패 판정**: 확인 못 해서 넣지 않았다.
- **캐논 공식 단계**: 캐논 공식 연결 문서를 찾지 못해 캐논 쪽은 기존 팩트(Wi-Fi 기본 확인·WPS)에 의존한다. 캐논 커뮤니티 글은 참고만 하고 사용하지 않는다.
- **후기 자료**: 이번 조사에서 `evidence: 후기`로 넣은 팩트는 없다. 모든 팩트가 공식 문서에서 확인된 것이다.

## 5. 힌트와 달랐던 점

- 힌트는 "2.4GHz/5GHz, 공유기, IP, 드라이버"였다. 공식 문서에서는 대역과 SSID 문제, IP 변경이 중심이었고, 드라이버는 연결 이후 단계로 나와 범위에서 뺐다.
- 힌트에 없던 SSID 분리, 이름 알림, MAC 필터, 숨김 SSID, 비밀번호 입력 순서가 공식 근거로 확인돼 추가했다.
