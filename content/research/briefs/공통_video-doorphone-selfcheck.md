# 비디오 인터폰·월패드·도어폰 자가점검 조사

**조사일**: 2026-07-21  
**조사범위**: 화면 안 나옴·벨 안 울림·통화 소리 안 됨·화면 흐림·문 열림 버튼 작동 안 됨·부재중 녹화·세대/공동현관 구분·관리사무소 연동

---

## 1. 화면 안 나올 때 자가점검 순서

### 1-1. 전원 스위치 확인 (코콤 공식)
비디오 인터폰 화면이 나오지 않을 때 첫 점검은 인터폰 옆면 또는 하단의 전원 스위치를 확인하는 것이다. 전원이 꺼져 있으면 켜고, 켜져 있으면 한 번 껐다가 다시 켜본다.

**출처**: [코콤(KOCOM) FAQ](https://www.kocom.co.kr/bbs/board.php?tbl=faq)

### 1-2. 분전반 차단기 확인 (코콤·코맥스 공식)
집의 분전반(차단기)에서 비디오 인터폰 관련 차단기가 내려가지 않았는지 확인해야 한다. 내려가 있으면 올려주고, 내려져 있었으면 차단기를 한 번 완전히 내렸다가 다시 올려 재부팅한다.

**출처**: [코콤·코맥스 기술 자가점검](https://poledit.co.kr/%EC%BD%94%EC%BD%A4-kocom-%EC%9D%B8%ED%84%B0%ED%8F%B0-%EA%B3%A0%EC%9E%A5-as-%EA%B3%A0%EA%B0%9D%EC%84%BC%ED%84%B0/)

**주의**: 아파트 월패드는 배선이 공용설비이므로 집 내 차단기는 확인 가능하지만, 공동 배선 차단기(분전함)는 관리사무소에 신고하여 점검해야 한다.

### 1-3. 본체 연결 상태 확인 (코콤 공식)
인터폰 본체와 벽 연결 부위를 점검하여 본체가 벽에서 흔들리지 않는지, 케이블이 느슨하지 않는지 확인한다.

**출처**: [코콤(KOCOM) FAQ](https://www.kocom.co.kr/bbs/board.php?tbl=faq)

## 2. 벨이 안 울리거나 신호가 안 들릴 때

### 2-1. 세대 인터폰 vs 공동현관 카메라 구분 필수
- **세대 인터폰** (월패드 화면): 각 세대 내부 설치, 세대주 책임
  - 자가점검: 세대 차단기, 음량 설정 확인 가능
- **공동현관 카메라** (현관 그레이 박스): 공용설비, 관리사무소 책임
  - 배선 문제: 관리사무소 신고 필수

**출처**: [공동주택 정보통신설비 유지보수 및 관리 규칙](https://gyeongju.go.kr/design/downfiles/gyeongju/equipment/equipment05_260102.pdf)

### 2-2. 벨 신호 안 들릴 때 자가점검
세대 인터폰의 벨만 안 들리면:
1. 세대 내 차단기 확인 → 내려가 있으면 올려주기
2. 인터폰 음량 설정 확인 (다음 섹션 참조)
3. 기기 재시작 (전원 끄고 30초 후 켜기)

현관 카메라 신호가 안 들리면 → **관리사무소에 신고** (배선은 공용설비)

## 3. 통화 소리 안 들릴 때 해결 방법

### 3-1. 통화 중 음량조절 (코콤 공식)
비디오 인터폰 통화 중 음성이 작거나 안 들리면, **통화 중 우측 하단에 있는 통화음량조절버튼(+/-)으로 즉시 조절**할 수 있다.

**출처**: [코콤(KOCOM) FAQ](https://www.kocom.co.kr/bbs/board.php?tbl=faq)

### 3-2. 전체 시스템 음량 설정 (코콤 공식)
통화음이 전체적으로 작으면:
1. 인터폰 메뉴 진입
2. 설정(Settings) → 음성(Sound) → 시스템 음량(System Volume)
3. 볼륨을 중간 이상으로 조정

**출처**: [코콤(KOCOM) 설정 가이드](https://www.kocom.co.kr/bbs/board.php?tbl=faq)

**주의**: 음량이 '무음'으로 설정되어 있거나 '진동 모드'에 있을 수도 있으니 확인할 것.

## 4. 화면이 흐리거나 지지직거릴 때

### 4-1. 렌즈 청소 (표준 카메라 관리법)
화면이 흐리거나 화면에 때가 묻어 보이면 **부드러운 천(극세사, 안경닦이 등)으로 렌즈와 투명 커버를 부드럽게 닦는다**. 대부분의 흐림 문제는 렌즈 먼지로 인해 발생한다.

**출처**: [Sony 카메라 렌즈 청소 가이드](https://www.sony.co.kr/electronics/support/articles/00027109)

**주의**: 벤젠, 나프타, 알코올, 화학 세제, 살충제 등을 사용하면 렌즈 코팅이 손상되므로 사용 금지. 물을 조금 묻힌 천 또는 마른 극세사 천만 사용할 것.

### 4-2. 카메라 모듈 오작동 (코콤 공식)
화면의 일부가 지지직거리거나 색상이 이상하거나 영상이 계속 끊기면, **카메라 모듈의 설정값 오작동**이 원인일 수 있다. 이는 렌즈 청소로 해결되지 않으므로 기술 서비스 센터에 문의해야 한다.

**출처**: [코콤(KOCOM) FAQ](https://www.kocom.co.kr/bbs/board.php?tbl=faq)

## 5. 문 열림 버튼이 작동하지 않을 때

### 5-1. 기본 점검 (사용자 경험)
1. 세대 내 차단기 확인
2. 통화 상대가 제대로 올렸는지 확인 (일부 기기는 상대가 '문열기' 권한 없을 수 있음)
3. 문 열림 버튼을 다시 눌러보기
4. 인터폰 재부팅 (전원 끄고 30초 후 켜기)

위 모든 조치 후에도 작동하지 않으면 기술 서비스를 신청한다.

**출처**: [코콤·코맥스 사용자 경험 보고](https://poledit.co.kr/%EC%BD%94%EB%A7%A5%EC%8A%A4-commax-%EC%9D%B8%ED%84%B0%ED%8F%B0-%EA%B3%A0%EC%9E%A5-as-%EA%B3%A0%EA%B0%9D%EC%84%BC%ED%84%B0/)

### 5-2. 배선 문제 가능성
문 열림 버튼은 전동 개폐기(모터)를 제어하는 회로이며, 세대 내부 배선도 있지만 공동현관의 개폐기와 연동되므로 **공용 설비 측 배선 문제일 수도 있다**. 자가점검 후 해결 안 되면 관리사무소에도 함께 신고하면 관리사무소가 공동현관 개폐기와 배선을 확인할 수 있다.

## 6. 부재중 녹화 기능

### 6-1. 설정 위치 (제조사별 다름)
비디오 인터폰의 부재중 녹화(부재중 방문자 영상 기록) 기능은 인터폰 앱 또는 기기 설정 메뉴에서 활성화할 수 있다. 그러나 **기능과 저장 시간은 제조사와 모델에 따라 크게 다르다**.

**확인 방법**:
1. 인터폰 기기 설정 메뉴에서 '녹화' 또는 'Recording' 항목 찾기
2. 인터폰 앱의 설정 탭에서 '부재중' 또는 '방문 기록' 관련 옵션 찾기
3. 제품 매뉴얼의 '녹화 설정' 섹션 참조

**출처**: [코콤(KOCOM) 매뉴얼](https://www.kocom.co.kr/bbs/board.php?tbl=faq&mode=&page=1&category=%EB%A7%A4%EB%89%B4%EC%96%BC)

### 6-2. 저장 공간 및 주기 (일반 원칙)
부재중 녹화 영상은 저장 용량(클라우드 또는 로컬 메모리)에 따라 보관 기간이 제한된다. 제조사에 따라 7일~30일 등으로 자동 삭제될 수 있으므로, 중요한 영상은 정기적으로 확인하고 별도로 백업할 것을 권장한다.

## 7. 세대 인터폰 vs 공동현관 구분 (중요)

### 7-1. 세대 인터폰 (월패드)
- **위치**: 각 세대 거실 벽면
- **기능**: 방문객 확인, 통화, 문열기, 조명·온도 제어 등
- **책임**: 세대주 (자가점검·수리 가능)
- **자가점검 가능**: 전원, 차단기, 음량, 메뉴 설정, 렌즈 청소

### 7-2. 공동현관 카메라
- **위치**: 아파트 현관 입구 (공동 영역)
- **기능**: 방문자 영상 송출
- **책임**: 관리사무소 (공용설비)
- **자가 조치 불가**: 배선, 카메라 각도, 영상 수신 신호

### 7-3. 로비폰 (경비실 폰)
- **위치**: 경비실
- **기능**: 방문자 응대, 영상 수신
- **책임**: 관리사무소
- **자가 조치 불가**: 모든 기술 문제

**출처**: [공동주택 정보통신설비 관리 규칙](https://gyeongju.go.kr/design/downfiles/gyeongju/equipment/equipment05_260102.pdf)

### 7-4. 신고 팁
- **문제 신고 시 구분하기**:
  - "월패드 화면이 안 나옵니다" → 세대 문제, 세대주가 차단기·전원 확인
  - "현관 카메라 영상이 안 보입니다" → 공동시설 문제, 관리사무소 신고 필수
  - "벨이 자주 안 울립니다" → 세대 음량인지 공동 배선인지 구분 → 각각 신고

## 8. 관리사무소 연동 및 주소 설정

### 8-1. 세대·경비 주소 설정 중요 (코콤 공식)
월패드 비디오폰이 경비실 로비폰과 제대로 연동되려면 각 세대의 **주소(동-호수)** 와 **경비실 주소**가 정확하게 설정되어야 한다.

**설정 예**:
- 세대 주소: (동수)-(호수)-00 형식 (예: "101-1801-00")
- 경비실 주소: 경비실의 2자리 코드 (기본값 10, 드물게 20·50·75 등)

**출처**: [코콤(KOCOM) 월패드 연동 설정](https://blog.0xcc2c.com/103)

### 8-2. 경비실 주소 확인 방법
월패드 연동이 안 되거나 벨 신호가 안 들리면:
1. **로비폰(경비실 폰)에서 경비실 주소 확인** (기기 설정 메뉴)
2. **자기 월패드의 경비실 주소 설정값 확인** (일반적으로 홈네트워크 메뉴)
3. 두 값이 일치하는지 확인

만약 주소가 틀려 있으면:
- 옛날 건물: 설정을 수동으로 수정
- 최근 신축: 관리사무소에 정확한 주소 설정값을 문의하고 재설정 요청

**출처**: [코콤 월패드 설정 가이드](https://blog.0xcc2c.com/103)

**주의**: 경비실 주소 설정은 제조사와 아파트마다 다를 수 있으므로, 비슷한 기종을 쓰는 다른 세대 월패드를 확인하거나 관리사무소에 물어보는 것이 가장 확실하다.

## 9. 전기 안전 경고 ⚠️

비디오 인터폰은 **전기 배선으로 연결되어 있다**. 무단으로 분해하거나 케이블을 임의로 조작하면 **감전 위험**이 있다.

### 9-1. 자가 점검의 범위 (안전)
✅ 안전한 자가점검:
- 전원 스위치 끄고 켜기
- 차단기 확인 및 올려주기
- 렌즈·화면 청소
- 메뉴 설정 조정 (음량, 주소 등)

❌ 절대 금지:
- 본체 뜯기 또는 분해
- 케이블 임의로 연결·해제
- 내부 회로 수정 시도

### 9-2. 기술 서비스 연락처
문제가 자가 점검으로 해결되지 않으면, 공식 서비스 센터를 통해 전문가를 호출해야 한다:

- **코콤(KOCOM)**: 1577-0051
- **코맥스(COMMAX)**: 1599-8866

**출처**: [전기 안전 표준](https://www.se.com/kr/ko/faqs/FA242537)

## 정리: 문제별 대응 플로우

| 증상 | 우선 자가점검 | 해결 안 되면 |
|---|---|---|
| 화면 안 나옴 | 전원, 차단기, 연결 확인 | 기술 서비스 |
| 벨 안 울림 (세대) | 차단기, 음량 | 기술 서비스 |
| 벨 안 울림 (현관) | - | 관리사무소 신고 |
| 통화 음성 안 들림 | 우측 하단 음량 버튼, 시스템 음량 | 기술 서비스 |
| 화면 흐림 | 렌즈 청소 | 기술 서비스 (모듈 고장 가능) |
| 문 열림 안 됨 | 차단기, 상대 확인, 재부팅 | 기술 서비스 + 관리사무소 |
| 부재중 녹화 안 함 | 앱·메뉴 설정 확인 | 기술 서비스 |
| 경비실과 연동 안 됨 | 주소 설정 확인 | 관리사무소 + 기술 서비스 |
