# 삼성페이·애플페이 결제가 안 될 때 점검 순서 — 조사 브리프

- 글 slug: mobile-payment-nfc-selfcheck / 코너: repair / 분야: 디지털·IT
- 조사일: 2026-11-03
- 팩트 파일: content/research/facts/common_mobile-payment-nfc-selfcheck.json (새 팩트 17건, 재사용 2건, 거부 1건, 분쟁 0건)

## 1. 힌트와 달랐던 점

- **삼성페이는 현재 Samsung Wallet 이름으로 안내된다.** 삼성전자서비스 FAQ(2026-10-16 게시)는 "Samsung Wallet"을 기본 결제 앱 이름으로 쓴다. 글에서는 "삼성페이(현 Samsung Wallet)"로 병기한다.
- **Apple 공식 한국 페이지에는 "결제가 안 될 때" 절차가 없다.** HT204506(Apple Pay 설정 및 사용)에는 요구 사항, 잠금 설정 연계, 국내 카드 추가 방식, 카드 추가 문제 시 발급사 문의까지만 있다. 결제 거절 점검 순서는 공식에서 찾지 못했다.
- **중복 결제**는 Apple 공식(104954, 영문 페이지)에서 "거래 화면 금액이 최종 청구액과 다르게 보일 수 있음 · 카드사에 문의"로 확인된다. 중복 결제를 어떻게 확정하는지(승인 취소 절차 등)는 공식 근거를 확보하지 못했다.
- **미결제 잔액(Apple ID 청구 문제)** 이 결제를 막는다는 내용은 공식에서 확인하지 못했다. 개인 블로그 후기 한 건에서만 보였고, 그 블로그 본문에도 해당 내용이 없었다. 따라서 팩트로 채택하지 않았다.
- **NFC 안테나 위치**는 공식 본문에 글로 적혀 있지 않다. 설정 화면의 안내 이미지로 확인하라는 문장만 있어 확인실패 팩트로 남겼다.
- **"카드 모드" 권장**과 **결제 시 LTE/5G 필수**는 커뮤니티 답변 요약에서만 보였다. 원문을 열어 확인하지 않았으므로 팩트로 넣지 않았다.

## 2. 재사용·거부

- 재사용: `iphone-reset-all-settings-data-kept`(모든 설정 재설정 시 Apple Pay 카드 초기화, Apple 126643), `iphone-restart-steps-face-id`(Face ID 기종 재시작 절차, Apple 118259). 두 팩트는 `apple_iphone-wifi-bluetooth-selfcheck.json`에 있고 출처 도메인 검증을 통과한 것이다.
- 거부: `iphone-restart-before-reset`(Wi-Fi·블루투스 전반 장애용 재설정 권고). 결제 거절 글에서는 전체 재설정이 Apple Pay 카드를 지우는 과한 조치라서 쓰지 않는다.

## 4. 증상별 점검 순서 (집필 참고용, 근거 기준)

1. **기기 쪽 빠른 점검**: NFC 껐다 켜기 → 기본 월렛 앱이 Samsung Wallet(또는 Apple Pay)인지 확인 → 자석·비정품 커버 제거 → LED 커버가 켜져 있으면 끄기.
2. **단말기 쪽 확인**: 비접촉 표시가 있는 단말기인지 확인. 미국 자료 기준이지만, NFC·MST 미지원 단말기에서는 기기 문제가 아니다. 국내 단말기 지원 여부는 확인하지 않았다.
3. **카드 등록 확인**: 국내 카드는 카드사 앱을 통해서만 추가된다(Apple 공식). 추가가 안 되면 발급사 문의. 잠금 설정을 바꾸면 카드가 지워진다는 점을 먼저 알린다.
4. **잠금·계정 상태**: 기기 암호·Face ID 설정 확인. iCloud 로그아웃이나 암호 제거가 있었다면 카드를 다시 넣어야 한다.
5. **재시작과 SIM 재장착**: 재시작(Face ID 기종 절차는 재사용 팩트). 삼성 공식 FAQ는 SIM 재장착 후 재시작을 권한다.
6. **중복 결제 확인**: 지갑 앱에서 카드 → 최근 거래 확인 → 카드사 승인 내역·명세서와 대조 → 중복이 맞으면 카드사에 이의 신청. 재결제는 하지 않는다.
7. **AS 기준**: 위 단계로 안 되면 삼성 고객센터 1588-3366(삼성전자서비스 FAQ 기준) 또는 Apple 지원 문의. 보증 기간 판정은 이 자료로 확인하지 않았다.

## 5. 확인실패·한계

- `samsung-antenna-position-unverified`: 기종별 안테나 위치 텍스트를 확보하지 못했다.
- Apple 결제 실패 절차는 공식에 없다. 글에서 Apple 쪽 단계는 "공식에 명시된 것만" 쓰고, 나머지는 카드사 확인으로 연결한다.
- 후기 자료는 이번 팩트 파일에 넣지 않았다. 개인 블로그(yellowit) 후기는 본문에서 워치 전용 실패·카드 재등록 사례를 확인했지만, 공식 근거로 충분해 채택하지 않았다.
