# 선크림 제형 비교 조사 브리프

## 조사 배경
독자가 선크림 구매 시 "크림이 강하고 젤은 약하다", "스프레이가 편하다"는 오해를 바로잡기 위해 제형별 성능 차이를 실측 데이터로 검증.

## 핵심 발견

### 1. SPF 성능: 제형은 무관
- **도포량 2mg/cm² 기준**: 제형 무관 동일 SPF 성능
- 크림 SPF 50 = 젤 SPF 50 (모두 UVB 98% 차단)
- ★마케팅 주장이 아닌 ISO 표준 기준

### 2. 제형별 특징
#### 크림형
- 높은 오일 함량 → TEWL 억제 → 건성 피부 장점
- 유지 시간 길음 → 재도포 간격 3~4시간
- 건성/민감 선택지

#### 젤형
- 낮은 오일 → 빠른 흡수, 매트한 마감
- TEWL 억제 효과 낮음
- 유효 성분 빠른 흡수/휘발
- 지성 피부 선택지

#### 스틱형
- **도포량 조절 난제** (많은 사용자가 과소 도포)
- 실제 SPF 표시값 대비 20~30% 낮을 수 있음
- 편의성과 효율성 트레이드오프

#### 스프레이형
- **고르지 않은 분사** (일부 과다, 일부 과소)
- 평균 SPF 25~35% 감소
- FDA도 '균등 도포 의문' 제기

### 3. 유기 vs 무기 내구성
- 유기(화학) 자차: 물·발한에 더 강한 결합력
- 무기(광물) 자차: 빠르게 떨어짐
- 수영·물활동 환경에서 유기 우위

### 4. 재도포 주기 차이
- 크림: 3~4시간
- 젤/스프레이: 2~3시간
- 제형에 따라 재도포 계획 필요

## 기대 활용
집필 시 프레이밍:
- "어떤 제형이 더 강한가" → ❌ SPF 기준 동일
- "당신의 피부와 생활방식에 맞는 제형은" → ⭕ 유지 시간·도포 난이도·흡수감
- 스틱/스프레이 선택 시 "충분한 양을 의식적으로 바르기" 강조
