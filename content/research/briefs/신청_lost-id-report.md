## 2. 기존 팩트 재사용과 정리

- 재사용 5건: 재발급 사유(주민등록법 제27조 제1항), 수수료 두 건, 신청 채널, 사진·본인확인. 이번 정부24 재발급 안내 페이지에서 수수료 두 건을 다시 확인했고 일치했다.
- 기존 확인실패 두 건(블로그 처리기간 2~3주, 블로그 24시간 분실신고·즉시 차단)은 이번에 공식 확인 여부를 따졌다. 처리기간은 공식 "총 14일"로 대체(새 팩트). 24시간·즉시 차단은 공식 페이지에서 확인되지 않아 새 확인실패 항목으로 남겼다.

## 3. 충돌·주의

- 처리기간 즉시는 근무시간 내 3시간 기준이다. 야간·주말 처리 방식은 이 페이지에 없다.
- 분실신고가 카드 효력을 정지시키는지는 공식 원문에서 확인하지 못했다(확인실패). "분실신고 후 재발급 흐름"만 확정적으로 쓴다.
- 분실 처리 확인 방법(정부24 진위확인, ARS 1382)은 검색 요약뿐이라 확인실패. 번호를 글에 쓰지 않는다.
- 운전면허·여권 분실 신고는 이번 조사 범위 밖이다.

## 4. 집필 시 권장 톤

- "주민등록증을 잃어버렸다면 정부24에서 분실신고를 먼저 하라. 수수료가 없고 근무시간 안에 바로 처리된다. 재발급이 필요하면 공식 기준 총 14일을 잡으라"는 순차 안내.
- 분실 신고를 해 두면 신분증 악용을 막을 수 있으므로 적극 권한다. 효력 정지 여부는 단정하지 않는다.
- 대리인 신고 불가(온라인) 조건과 대신 신고할 수 있는 범위(세대원 등)를 "누가 대신 신고할 수 있는지" 질문으로 풀어준다.

## 5. 못 한 것

- 분실신고 후 효력 정지 여부 — 확인실패.
- 분실 처리 확인 방법 — 확인실패.
- 야간·주말 신고 처리 방식 — 공식 페이지 미기재.
