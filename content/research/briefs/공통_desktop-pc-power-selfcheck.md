# 데스크톱 PC 전원이 안 켜짐 — AS셀프체크 조사보고

## 조사 범위

이 조사는 **전원 자체가 들어오지 않는 물리적 하드웨어 문제**에 집중한다. Windows 부팅 실패(OS 미로드) 또는 BIOS 화면 이상과는 별도 영역이다. 

- 전원이 전혀 켜지지 않는 경우
- 전원이 켜졌다 바로 꺼지는 부트루프
- 전면 버튼 반응이 없는 경우

## 확인 순서

### 1단계: 외부 전원 차단 여부 확인

가장 기본적이면서 가장 흔한 원인들:

**파워서플라이 후면 스위치 (O/I)**
- 파워서플라이 후면에 'I' (켜짐) / 'O' (끔) 스위치가 있다
- 'O' 상태면 내부 모든 부품에 전력이 공급되지 않는다
- 이것이 체크 포인트 1순위. 재부팅이나 정전 후 실수로 꺼졌을 가능성이 높다

**PC 전원 케이블 연결**
- 케이블 양쪽 끝(파워서플라이, 콘센트)이 완전히 꽂혀 있는지 확인
- 클릭 소리가 날 때까지 밀어 넣을 것
- 물리적 손상, 탄 냄새, 단열 벗겨짐이 있으면 즉시 중단

**멀티탭 상태 확인** (멀티탭 사용 중인 경우)
- 멀티탭 자체의 전원 스위치가 켜져 있는지
- 과부하 차단 버튼(보통 빨간색)이 튀어나와 있지는 않은지
- 튀어나왔다면 버튼을 눌러 리셋 시도
- 자주 튀어나오면 멀티탭이나 연결된 기기의 정격을 초과하고 있는 것

### 2단계: 내부 케이블 연결 확인

케이스를 열고 내부를 확인할 때 정전기 방지가 필수다(손목 스트랩 착용).

**24핀 ATX 전원 커넥터**
- 파워서플라이에서 메인보드로 가는 주요 전원 케이블
- 메인보드의 24핀 슬롯에 완전히 연결되어야 함
- 케이스 조립 후 이동할 때 느슨해질 수 있음

**8핀 CPU 보조 전원**
- 파워서플라이에서 CPU로 가는 12V 전원
- 메인보드 상단에 위치 (조립 시 놓치기 쉬움)
- 이것이 분리되면 전원이 안 켜지거나 켜졌다 바로 꺼짐(부트루프)

**전면 패널 전원 버튼 헤더 (JFP1)**
- 케이스 전면의 전원 버튼이 메인보드에 연결되는 곳
- 메인보드 매뉴얼에서 JFP1 또는 PANEL 포지션 확인
- Power Switch 핀(보통 1,2번)에 케이블이 정상 연결되었는지 확인

**전면 버튼 케이블 불량 시 대체 방법**
- 전원 버튼 케이블을 분리한 후
- 금속 도구(드라이버, 클립)로 Power Switch 핀 2개를 일시 단락
- PC가 켜진다면 버튼 케이블이 문제

### 3단계: 메인보드 대기 상태 확인

**대기 전원 LED 확인**
- 메인보드에 작은 녹색 또는 주황색 LED가 있음 (5V 대기 전원 표시)
- 이 LED가 꺼져 있으면 파워서플라이의 24핀 공급 문제
- 켜져 있으면 메인보드는 전력을 받는 중

### 4단계: RAM 및 CPU 쿨러 확인

**RAM 재장착**
- 모든 RAM 분리 → 한 개씩 권장 슬롯에 재삽입
- '딸깍' 소리가 날 때까지 밀어 넣을 것
- RAM 금색 접촉부에 먼지가 있으면 부드러운 에어로 불어 제거 (강하게 닦지 말 것)

**CPU 쿨러 확인**
- 쿨러가 메인보드에 제대로 체결되어 있는지
- 미체결이나 써멀 구리스 건조 → 부팅 중 과열 보호 작동 → 전원 차단
- 쿨러를 재장착했다면 새로운 써멀 구리스를 소량 발라야 함

### 5단계: BIOS 설정 초기화

**CMOS 배터리 제거**
- 메인보드의 원형 건전지(CR2032) 3~10분 제거 후 재삽입
- BIOS 설정 전부를 초기 상태로 리셋
- 최근 BIOS 변경이나 오버클럭 설정 후부터 문제가 시작된 경우 효과적
- 전원 완전 분리 후 작업, 정전기 방지 필수

**CMOS 클리어 점퍼 사용**
- 일부 메인보드는 'CMOS_CLR' 점퍼 제공
- 매뉴얼에서 위치 확인 후 핀을 다른 위치로 이동
- 30초 정도 유지 후 다시 복원

### 6단계: 파워서플라이 독립 테스트 (클립 테스트)

**언제 필요한가**
- 위의 모든 단계를 확인했는데도 전원이 안 켜지는 경우
- 파워서플라이 고장 여부를 최종 확인하는 방법

**절차**
- 파워서플라이를 PC에서 분리
- 24핀 커넥터의 녹색 와이어(Power Good)와 검은색 와이어(GND)를 금속 클립으로 단락
- 파워서플라이 후면 스위치를 'I'로 킴
- 파워서플라이의 팬이 회전하면 최소한 작동 중인 것

**주의**
- 전기적으로 위험하니 신중하게 진행
- 팬 회전해도 모든 전압이 정상이라는 보장은 아님
- 테스트 후 PC에 재연결하기 전 전원 완전 차단

## 부트루프(켜졌다 바로 꺼짐) 증상의 원인

전원은 켜지는데 수 초 후 바로 꺼진다 → 자동 재시작 → 반복:

1. **파워서플라이 불안정** - 가장 흔한 원인
2. **CPU 8핀 보조 전원 미연결**
3. **RAM 접촉 불량**
4. **CPU 쿨러 미체결 또는 써멀 구리스 건조** (부팅 중 과열 보호)
5. **BIOS 오버클럭 설정 이상** (CMOS 초기화로 해결 가능)

대응 순서: 파워 24핀/8핀 재확인 → RAM 재장착 → 쿨러 재체결 → CMOS 초기화

## 절대 금지

**파워서플라이 내부 분해 금지**
- 고전압 커패시터로 인해 전원 차단 후에도 치명적 감전 위험
- 내부 문제는 교체 또는 전문 서비스센터에서만 처리

## 중요 안전 사항

- **정전기 방지**: PC 내부 작업 시 손목 스트랩 필수
- **전원 완전 분리**: 작업 전 파워서플라이 후면 스위치를 'O'로, 멀티탭도 끔
- **부품 직접 접촉 최소화**: RAM의 금색 접촉부, CPU 핀 등

## 글쓰기 시 주의

1. **순차 대안 톤** — "먼저 파워 스위치를 확인하세요. 켜져 있다면 다음으로 케이블을 확인하세요" 식으로 단계를 밟도록 유도
2. **근거 약한 항목** — RAM 접점 청소는 `tier: 논쟁`이므로 "사용자들이 많이 보고한 방법"으로 표현, 강제하지 말 것
3. **위험 명시** — 파워서플라이 내부 분해는 절대 금지를 강하게 표현
4. **독자 대면** — "여기까지 확인했는데도 안 되면 전문가 서비스를 권합니다" 식으로 막다른 곳에 두지 않기
